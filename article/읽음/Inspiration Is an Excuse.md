# Inspiration Is an Excuse: Practical Tools for Game Designers
**저자:** Alvaro Salvagno
**출처:** [Game Developer](https://www.gamedeveloper.com/design/inspiration-is-an-excuse-practical-tools-for-game-designers-)
**분류:** 아이데이션 / 실용 도구
**게시일:** 2019년 12월 13일

## 핵심 메시지

> "업무 시간 밖에서 게임 아이디어를 생각하는 것은 낭비된 시간이다."
> 아이디어는 가치가 없고, 실행만이 가치를 만든다.

---

## 주요 내용

### 1. 아이디어 → 컨셉 → 디자인 3단계 전환
- **아이디어(Idea):** 머릿속의 흐릿한 생각 — 아직 가치 없음
- **컨셉(Concept):** 아이디어를 글로 적었을 때 — 핵심 구성요소가 드러남
- **디자인(Design):** 구체적 구현 세부사항이 있는 상태 — 실제 만들 수 있음
- 저자는 이 전환을 틱택토를 실시간으로 설계하면서 시연: 초기 문제(가독성, 무승부)를 수정하며 컨셉이 디자인으로 발전하는 과정을 보여줌

### 2. 시각화 도구: 마인드맵
- 두 가지 용도로 사용 가능:
  1. 테마적 연결을 브레인스토밍 (발산)
  2. 기존 디자인 요소 간 관계를 정리 (구조화)
- 서로 다른 기능이 실제로 의미 있게 상호작용하는지 파악
- 스코프가 과도한지 시각적으로 확인 가능

### 3. 실행 도구: 그리드
- 메커닉들을 교차 참조하여 모든 가능한 상호작용을 나열
- 기존 메커닉과 새 메커닉의 호환성을 매핑
- 기능 구현 여부를 객관적 데이터로 판단할 수 있게 해줌
- "이 기능이 정말 필요한가?"에 대한 증거 기반 답변 제공

### 4. 핵심 원칙
- 디자인은 근본적으로 능동적 작업이지, 수동적 영감 기다리기가 아님
- 문서화와 반복을 추상적 사고보다 우선할 것

## DDworld에 적용할 수 있는 것
- 마인드맵: "성장 시스템"을 중심에 두고 가지를 뻗어가며 연관 시스템 탐색 → 스코프 체크
- 그리드: 핵심 메커닉(성장/전투/탐험/언락) 간 교차표 작성 → 상호작용이 약한 조합 발견
- 아이디어 → 컨셉 전환: DDworld의 머릿속 이미지를 글로 옮기는 것 자체가 첫 단계
