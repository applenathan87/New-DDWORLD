## 주요 내용 (원본 페이지 기반)

### 피라미드 3개 레이어 구조

**Base Layer (기본 레이어)**
- 게임의 핵심인 "순간순간의 게임플레이(moment-to-moment gameplay)"
- 예: Team Fortress 2의 한 매치, Candy Crush Saga의 한 레벨, Uncharted의 내러티브 레벨

**Retention Layer (유지 레이어)**
- 플레이어가 수일·수주·수개월·수년간 플레이를 지속하게 만드는 요소
- 진행도, 언락, 기술 트리, 내러티브, 도전과제, 리더보드 포함

**Superfan Layer (열성팬 레이어)**
- 게임이 특정 플레이어에게 취미가 되는 단계
- 이들은 다른 어떤 게임보다 이 게임에 더 많은 시간과 금전을 투자함

### Core Loop
- Base Layer와 Retention Layer를 연결하는 "기어박스"

### 서비스 게임의 정의
- "Ongoing, compelling experiences to players" + "Ongoing source of revenue for game makers"를 동시에 제공하는 게임

### 윤리적 책임
- 루트박스와 가챠 메커니즘의 윤리성을 별도 장으로 다룸
- "규제는 피할 수 없지만 개인의 자유를 보호하면서 취약 계층을 지켜야 한다"

## DDworld에 적용할 수 있는 것
- 성장·언락 시스템 = Retention Layer 설계 문제
- Base → Retention → Superfan 흐름으로 DDworld의 플레이어 여정 설계하기
- Core Loop이 Base와 Retention을 얼마나 자연스럽게 연결하는지 점검
