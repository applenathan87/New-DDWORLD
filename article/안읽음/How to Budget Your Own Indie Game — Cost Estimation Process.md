# How to Budget Your Own Indie Game — Cost Estimation Process
**출처:** [Indie Games Marketer](https://www.indiegamesmarketer.com/how-to-budget-indie-game/)
**분류:** 1인 개발 / 재무 계획
**작성자:** Benoit Freslon (프랑스 인디 게임 개발자, 2006년부터 활동)

---

## 핵심 메시지
> 인디 게임 제작 비용은 $1,000~$10,000,000까지 다양하다. 아이디어 자체는 무료지만 제작은 반드시 비용이 든다. 자신의 시간도 비용으로 계산해야 하며, 손익분기점을 먼저 설정한 뒤 단계적·저위험으로 개발을 진행하라.

---

## 주요 내용

### 1. 게임 아이디어는 무료다
- 많은 개발자가 게임 아이디어만으로 부자가 될 수 있다고 착각한다
- 인터넷에서 찾은 무료 3D 모델과 몇 줄의 코드만으로는 부족하다
- "An original video game idea is 'free', but not its production." — 아이디어는 무료지만 실제 제작에는 비용이 든다

### 2. 직접 만들어도 무료가 아니다 — 시간은 돈이다
- 자신이 게임 개발에 투자하는 시간도 금전적 가치가 있다
- 생활에 필요한 월 소득을 고려해야 한다
- 구매한 자재와 개발 시간 모두 회수되어야 한다
- "paying 'nothing'" 같은 착각에서 벗어나야 한다

### 3. 개발 시간 추정을 위한 7가지 팁
1. 게임 컨셉 문서(GDD) 작성
2. 이전 프로젝트에서 소요된 시간과 비교
3. 다른 개발자들의 소요 시간 비교
4. 개발 팀에 물어보기
5. 인터넷에서 에셋 및 리소스 검색
6. 출시 날짜 및 마일스톤 설정
7. 전문가 상담

### 4. 자신의 비용 추정하기
- 월별 모든 지출을 목록화하고 각 항목의 비용을 추정한다
- 은행 웹사이트에서 지난해 지출을 확인한다
- **유럽 1인 개발자 월간 비용 예시** (자녀 없음, 세입자 기준):
  - 임대료 $315, 인터넷 $15, 휴대폰 $15, 보험 $15, 자동차 $200, 교통비 $10
  - 세금 $56, 수도 $15, 전기 $30, 하드웨어 $40, 소프트웨어 라이선스 $30
  - 의료보험 $20, 식비 $200, 엔터테인먼트 $100, 바/레스토랑 $30, 은행 수수료 $12
  - **월 합계: 약 $1,103** → 10개월 개발 시 **프로젝트 총 비용 약 $11,030**

### 5. 손익분기점의 중요성
- 손익분기점 = 손실 없음 (이득도 없음). 개발자가 반드시 도달해야 할 "#1 목표"
- 달성하면 다음 프로젝트 또는 DLC/업데이트로 진행 가능
- 미달성 시 계획 재검토 필요
- "Failure is not final, it's formative." — Alex Cars

### 6. 제작 비용에 영향을 미치는 요소들
- **플랫폼**: 모바일 < PC < 콘솔 순으로 복잡도·비용 증가
- **게임 유형**: 싱글플레이 < 멀티플레이
- **시각**: 추상적 < 사실적
- **사운드**: 단순 < 사실적
- 게임 모드, 기능, 메커닉의 수가 많을수록 비용 증가
- 저자의 선택 (EnigmBox): 1인 작업, 스토리텔링 제외, 2D, 미니멀리스트 접근으로 개발 시간과 비용을 줄임

## DDworld에 적용할 수 있는 것
- 월간 생활비를 실제로 계산해서 "DDworld 개발에 투자하는 시간의 비용"을 구체적 숫자로 파악해볼 것
- GDD 작성이 비용 추정의 첫 단계 — 현재 GDD 작성 단계와 맞닿아 있음
- 1인 개발 + 컨셉/경험 중심이라는 DDworld 방향은 저자가 권장하는 "저비용·저위험 먼저" 전략과 일치
- 스토리텔링·사실적 그래픽 제외, 미니멀리스트 접근 등 비용을 줄이는 선택지를 기획 단계에서 의식적으로 고려할 것
- 손익분기점을 먼저 설정하고, 그것을 기준으로 스코프를 역산하는 사고방식 적용
