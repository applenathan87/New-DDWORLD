## 5개에서 공통으로 나온 밤 파트 설계 원칙

다섯 게임을 관통하는 패턴 — 우리 밤 파트의 뼈대로 삼을 만한 것:

1. **낮의 판정이 밤에 돌아온다 (되먹임 루프).**
   Mind Scanners(전날 치료 방식 → 다음날 편지), Lil' Guardsman(낮 NPC를 마을에서 재회),
   Death and Taxes(선택이 음료 스피릿으로 콜백), Beholder(설치→수확 시간차) — 전부
   "낮의 행위 → 밤의 결과 확인"을 밤 파트의 **정서적 중심**으로 둔다.

2. **골드 소비처 = 코스메틱이 아니라 "낮을 강화하는 투자".**
   Lil' Guardsman(도구 업글), Death and Taxes(위젯 = 세계 영향 피드백 도구),
   Mind Scanners(기기 제작) — 골드를 쓰면 다음 낮이 유리해지는 구조라야 순환이 돈다.
   순수 장식은 후순위.

3. **유한한 자원이 선택 압박을 만든다.**
   Mind Scanners(하루 200초), Lil' Guardsman(부족한 크리스탈 배급),
   Papers Please(모자란 예산) — "다 못 한다"가 매일 밤을 딜레마로 만든다.
   무제한이면 밤은 심심한 정산이 된다.

4. **필수 지출이 골드를 "안 쓰면 위험한" 자원으로 만든다.**
   Papers Please(집세 미납 = 즉사), Mind Scanners(세금 미납 = 추방),
   Beholder(가족 급전) — 벌이만 있고 강제 소비가 없으면 골드는 숫자일 뿐.

5. **페널티는 유예형, 톤은 요약 유머로 누른다.**
   Papers Please(경고→누적→파국), Death and Taxes(4일 연속 위반해야 해고 = 관용 구간),
   Lil' Guardsman(엔드오브데이 유머 요약으로 다크한 결과를 가볍게) — 즉시 파국보다
   단계적 페널티가 코미디 톤에 맞고, 소신 판정의 여지를 남긴다.

## 「마왕성 인사팀」 밤 파트 적용 — 순환 고리

앞선 이데이션에서 그린 고리에 다섯 게임의 교훈을 얹으면:

```
[낮] 심문·간파·도장 판정
   │  └→ 성과 = 공적(승진) + 골드
   ▼
[밤] 유한한 밤 시간 안에서 선택:  ← Mind Scanners(200초 압박)
   ├ 여파 확인   : 어제 뽑은 놈의 사고 신문·감사 편지  ← Lil'Guardsman 콜백 / Beholder 수확
   ├ 도구 투자   : 골드로 촛불·돋보기 강화            ← Lil'Guardsman / Death&Taxes 위젯
   ├ 필수 지출   : 상납금·자릿세 (안 내면 누적 페널티) ← Papers Please 집세 / MindScanners 세금
   └ 부패 거래   : 캐낸 약점을 보고(공적) vs 협박(골드) ← Beholder 보고/협박
   ▼
[다음 낮] 강화된 도구 + 밤에 얻은 정보 → 판정이 유리해지거나 어려워짐
```

이 고리가 돌면 밤은 "미니게임 모음"이 아니라 **낮에 왜 정확히 판단해야 하는지에 이유를 주는 심장**이 된다 (= 우리가 세운 밤 파트 제1원칙).

## 온도차 / 우리가 주의할 점

- **톤 온도**: Papers Please·Beholder는 생계 압박이 무겁고 어둡다. 우리는 **다크판타지 코미디**가
  강하므로, 생계 압박은 희석하고 Lil' Guardsman·Death and Taxes의 **유머 균형**에 더 가깝게 가는 게 맞다.
  (같은 "밤 정산"이라도 "가족이 굶는다"가 아니라 "상납 못 하면 상사가 비아냥댄다"의 결.)
- **단계 비연결 원칙과의 긴장**: 우리 기획은 "각 단계 = 독립 지원자 세트"(콘텐츠 비용 이유)인데,
  Lil' Guardsman의 콜백 산책은 낮 인물의 재등장이 핵심이다. **밤 콜백을 어디까지 허용할지**
  (익명 신문 기사 수준 vs 특정 인물 재등장)가 설계 결정 포인트.
- **골드 도입 타이밍**: 기획 §15 #13 원칙 = "싱크 없는 화폐 선지급 금지". 위 고리의 필수 지출·도구
  투자(싱크)를 골드 획득(faucet)과 **동시에** 넣어야 한다.
