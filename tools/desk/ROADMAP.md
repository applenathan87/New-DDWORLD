# 출근부 로드맵 — ver02 계획

> **다음 세션은 이 파일을 읽고 "첫 묶음" 1번부터 시작한다.**
> 결정일: 2026-09-09 (ver01 완성 당일 대화). 목적 = **기록과 PM을 동시에.** 사람은 제목과 메모만 쓰고 나머지는 자동. 세션이라는 개념을 기록에서 빼고 **출근 · 커밋 · 퇴근**만 남긴다.

## ver01 현재 상태 (2026-09-09, 커밋 완료)

- 출근(할 일 고르기) → 부재/복귀 → 퇴근(제목 필수 + 한 일·배운 것·막힌 것·다음에 할 것) → 데브로그 md 완성 → `production/desk/`만 자동 커밋·푸시
- 뽀모도로 50/10: 시계·알림을 **서버**가 담당(윈도우 토스트 + 알람 소리, 맥은 osascript) → 크롬 꺼도 됨. 상태 `tools/desk/.pomo.json`
- 근태 통계 5타일 + 시작 달(heatStart)부터 1년 히트맵(5단계 잉크색, 툴팁, 클릭 시 일지), 도장 연출(출근·복귀 초록, 부재 노랑, 퇴근 초록+인사말+컨페티)
- 실행: `출근.bat`(git pull → 숨김 서버 → 브라우저) / `출근부-끄기.bat`. 바탕화면 바로가기 `출근부.lnk`. 로그 `tools/desk/desk.log`
- 데이터: `production/desk/todo.md`, `production/desk/devlog/YYYY-MM-DD.md`(하루 한 파일, frontmatter 영어 키)
- 설정: `desk.config.json` (seasonStart · heatStart · heatLevels · pomodoro · autoPush). **10월 1일 seasonStart → 2026-10-01** 로 바꿔 새 시즌 Day 1
- 사용 규칙: 창 여러 개 띄울 땐 창마다 담당 폴더, 커밋은 자기 파일만. 출근부 자동 커밋은 데이터 폴더만 집는다

## 결정 사항 (2026-09-09 확정 — 다시 논의하지 않는다)

1. **퇴근 보고는 3칸**: 제목(필수) · 메모(선택) · 다음에 할 것(선택). "배운 것·막힌 것" 칸 삭제. 막힌 건 할 일로 적는다("X 해결하기").
2. **한 일은 자동**: 오늘 완료로 체크한 할 일 + 오늘 git 커밋 요약(게임 리포, 폴더별 묶음). 볼트 리포(C:\ProjectDDWORLD) 포함 여부는 **10월 GDD·폴더 리뉴얼 때 결정** (커밋 요약 / 오늘 수정 노트 목록 / 퇴근 시 볼트 자동 커밋 중).
3. **다음에 할 것 → 할 일로 이어짐**: 퇴근 때 적은 줄은 그 자리에서 `todo.md`에 들어가고, 다음 출근 추천에서 미리 체크되어 뜬다.
4. **메모 줄이 `결정:`으로 시작하면** `production/desk/decisions.md`에도 "날짜 · 결정" 한 줄 복사 (결정 원장).
5. **세션 요약 명령은 만들지 않는다.** 기록 단위 = 커밋. 대화로 정한 것은 파일로 남기고 커밋한다. (여러 창 + 컨텍스트 클리어 문제를 "세션 끝 요약"으로는 풀 수 없다는 결론)
6. **세션시작·세션종료 스킬 삭제** (게임 리포 `.claude/commands/`와 볼트 `C:\ProjectDDWORLD\.claude\commands\` 두 벌 모두). `.claude/session_start.txt`도 제거. 하던 일은 출근.bat(pull)·출근부(시간·데브로그·커밋)·훅(브리핑)이 대신한다.
7. **출근 때 `production/desk/today.md` 생성** → SessionStart 훅이 읽어 준다. 훅은 새 창(startup)·재개(resume)·클리어(clear)·자동 압축(compact) 모두에서 돈다 → 비운 창도 새 창도 같은 브리핑으로 시작.
8. **할 일 추천은 규칙 기반**(앱 안에서 AI 호출 없음): 어제의 "다음에 할 것" → 이번 주 계획 미완료 → 현재 마일스톤 백로그 상위. 계획을 짜는 지능은 Claude 세션(주간)에 두고, 앱은 그 계획을 아침에 보여주기만 한다.
9. 마일스톤·주간 계획 파일 형식은 **10월 재정비에서 실제 마일스톤이 나올 때 확정** (두 번째 묶음).
10. 뽀모도로 휴식은 근무 시간에서 빼지 않는다. 휴식 뒤 다음 집중은 버튼으로 시작.

## 첫 묶음 — 다음 세션에 할 일 (순서대로)

1. **퇴근 보고 간소화** — `server.js` SECTIONS = ['한 일', '메모', '다음에 할 것']. 기존 파일의 "배운 것/막힌 것"은 "모르는 섹션 보존" 로직으로 그대로 남긴다. `app.js` 폼 3칸. README 예시 갱신.
2. **오늘 커밋 요약** — `server.js`에 `git log --since="YYYY-MM-DD 00:00" --format=...`(리포 루트) → 커밋 메시지 첫 줄 + 건드린 최상위 폴더로 묶어 줄 목록 생성. 퇴근 폼 "한 일"에 프리필(완료 할 일 + 커밋 요약). 같은 날 두 번째 퇴근은 중복 없이(이미 있는 줄은 건너뜀). `desk.config.json`에 `repos: ["."]`(나중에 볼트 추가 자리).
3. **다음에 할 것 → todo.md** — 퇴근 처리 시 각 줄을 열린 할 일로 추가(중복 제외). 출근 추천 목록(`renderPickPanel`)에서 "어제의 다음에 할 것"을 맨 위 + 미리 체크.
4. **결정 원장** — 메모 줄 `결정:` 접두 → `production/desk/decisions.md`에 `- YYYY-MM-DD · 내용` append. 파일 없으면 헤더와 함께 생성.
5. **today.md** — 출근·복귀·할 일 변경·퇴근 때 갱신. 내용: 날짜/Day/상태, 오늘 할 일(완료 표시), 어제의 다음에 할 것, 최근 결정 3개, (있으면) 현재 마일스톤. 위치 `production/desk/today.md` (자동 커밋 범위 안).
6. **SessionStart 훅** — `.claude/settings.json`의 `hooks.SessionStart`에 matcher `startup|resume|clear|compact`로 명령 추가: today.md 출력 + `git log --since=today --oneline` 출력. 기존 훅(active.md 안내)과 공존. Windows에서 돌아야 하므로 node 스크립트(`tools/desk/briefing.js`)로 작성해 훅이 `node tools/desk/briefing.js`를 호출.
7. **스킬 삭제** — `.claude/commands/세션시작.md`, `세션종료.md`(게임 리포) 삭제. 볼트의 같은 두 파일도 삭제하되, 볼트 세션시작에 있던 "읽을거리(안읽음 아티클) 확인"은 주간 회고(두 번째 묶음)로 이관한다는 메모를 이 파일에 남긴다. `.claude/session_start.txt` 삭제.
8. **문서 갱신** — `tools/desk/README.md`, 루트 `CLAUDE.md`의 협업 규칙(세션 상태 항목: today.md·데브로그가 기록, 세션 스킬 없음). `Origin/CLAUDE.md`의 작업일지(DAY 파일·000-log) 규칙은 10월 재정비 때 출근부로 일원화.
9. **테스트** — 임시 데이터 폴더(`DESK_DATA_DIR`)로 퇴근 프리필·decisions.md·today.md·다음 할 일 이어가기 확인. 훅은 새 창을 열어 브리핑이 뜨는지 확인. 실제 서버는 `출근.bat`로 재시작.
