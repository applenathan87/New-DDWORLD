아래 순서로 실행:

1. `.claude/session_start.txt`를 읽어 시작 시간 확인, 현재 시간과 차이로 세션 작업 시간 계산
   - **날짜 기준**: 현재 시각이 **01:30 이전**이면 전날 날짜로 작업일 처리
2. 계산된 작업 시간을 포함해서 오늘 한 일, 배운 것, 막힌 것, 다음 목표를 사용자에게 한번에 보여주고 맞는지 확인
3. `production/devlog/` 폴더에서 해당 날짜 파일이 있는지 확인:
   - **없으면** → 새 데브로그 파일 생성 (새로운 Day 번호 부여)
   - **있으면** → 기존 파일에 내용 추가, 작업 시간 합산
4. `git add .` → 변경사항 요약한 커밋 메시지로 `git commit` → `git push` 실행
5. 완료 후 "오늘도 수고했습니다! 데브로그가 업데이트됐어요." 라고 말하기

## 데브로그 파일 형식

```markdown
---
Day: (번호)
날짜: YYYY-MM-DD
작업시간: (숫자)
상태: 완료
---

# Day XX — 제목

## 한 일

## 배운 것

## 막힌 것

## 메모

## 다음 목표
```
