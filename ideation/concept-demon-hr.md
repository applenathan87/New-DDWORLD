# 컨셉 — 마왕성 인사팀 (가제)

> 상태: **신규 방향** (2026-07-03, Day 2). DDworld 헥사 오토배틀러를 **대체**. 기존 헥사 문서는 서랍에 보관(삭제 X, 미래의 다른 프로젝트일 수 있음).
> 성격: 진행 중 컨셉 스케치. 판정기준 통과 후 정식 GDD(`design/gdd/`)로 승격.

## 한 줄 (로그라인)

**"마왕성 인사팀에 들어간 신입사원이 되어, 사악한 직무에 지원한 몬스터들을 면접 보는 게임."**
(= Papers, Please의 판단·심문 손맛 + 다크판타지 코미디 HR)

## ⭐ 후크 — 판단축의 반전

- Papers, Please: 정직=통과 / 위조=적발 (단순 축).
- 우리: **악당을 뽑기에 축이 비틀린다.**
  - 거짓말을 잘함 → (사기·스파이 직무엔) **장점**
  - 진짜 잔인함 → 장점
  - 알고 보니 착함 / 갱생 가능 → **위험 신호** (악한 일을 못 할 놈)
  - 너무 유능함 → 내 상사 자리 위협? (사내정치 레이어)
- → **"정답"이 뻔하지 않고 직무·마왕성의 필요에 따라 달라진다.** 플레이어 실력 = 몬스터 간파 + "악한 일엔 뭐가 자질인가"를 읽는 것. **이 반전이 프리미스를 게임으로 만드는 핵심.**

## 코어 루프 — 대화형 심문 → 판단

1. 지원 몬스터 등장 (이력서/서류 + 겉모습·태도)
2. **보유 질문으로 심문** → 말·태도·서류 사이의 모순/거짓/과장을 포착
3. 판단: 승인 / 거절 / (나중)직무 배치
- 초반 = 질문 적음(표면만), 레벨업 = **심층 질문 해금**(교묘한 거짓말까지 간파)

## ⭐ 핵심 원칙 — 물성 (다이어제틱 데스크)

**"UI를 클릭하는 게 아니라, 책상 위 물건을 직접 잡고 만진다."** 이 물성이 이 게임의 정체성.
(Papers, Please가 좋게 느껴지는 핵심 = 이 물성. 책상 = 메뉴가 아니라 놀이터.)

책상 위 오브젝트 = 각각이 하나의 동작:
- **도장** = 판단(채용/불합격/직무배치). 드래그 → 쾅. 커밋의 손맛. **(데모 필수)**
- **이력서/서류** = 집어서 들여다보기, 촛불에 비춰 위조 인장 확인. (조사)
- **질문 카드** = 던지거나 놓아서 심문. 레벨업 = 질문 카드 해금(덱빌딩).
- **서랍** = 정보·도구 (주간 채용 규칙, 수배 전단, 전 직원 파일, 거짓 탐지 도구).
- **책상 밑 버튼** = 경비 호출 (위험 지원자·험악한 면접) → 리스크/드라마 층.

### 통합 루프 (카드 + 데스크가 한 흐름)
**묻고**(카드) → **관찰**(몬스터 반응·땀) → **조사**(이력서·서랍) → **판단**(도장) → [위험 시 **버튼/경비**]

### 데모 스코프
전부 물리화 X(3D 인터랙터블은 flat UI보다 무거움). 핵심 2~3개만:
**도장(필수) + 이력서 + (서랍 or 버튼 중 택1)**. 나머지는 확장.

## 진행의 척추 = 업무 스코프의 확장 (승진 = 새 업무 + 새 가젯) ⭐

**서류 심사 → 1차 면접 → 2차 → 최종 → HR 본연의 업무들(중재·면담·해고·승진 심사)** 로 업무 범위가 **늘어나거나 교체**된다. 이전 업무는 아랫사람에게 넘어간다. 승진 트리거 = 성과.

- 확장은 **가젯·기믹으로 체감**시킨다 (Papers, Please·Quarantine Zone 계보 — day가 갈수록 검증 도구와 판단 작업이 늘어남). 예: 촛불(위조 검사) → 질문 카드 → 돋보기(진술 거짓 판독) → 진실의 수정구 → ….
- **이 게임의 재미 = ① 가젯으로 업무가 늘어나는 것 + ② 세상을 한번 꼬아서 보는 것(판단축 반전).**
- 반전 룰은 전역이 아니라 **Day별 채용 지침의 변주** — 예: 사기 부서 채용의 날엔 "거짓말 잘하는 녀석들로 보내줘".
- **← 데모(MVP) = 서류 심사 + 1차 면접, 승진 1회.** 상세: [mvp-design.md](mvp-design.md)

## 커리어 아크 (비전 — 데모 아님)

신입(서류·1차 면접) → 2차·최종 면접 → HR 업무(중재·면담·연봉협상·해고·승진 심사) → 인사팀장 → **성주 엔딩**.
각 단계 = 다른 시스템 + 다른 가젯이라 **데모엔 넣지 않는다.** 데모 = 서류 심사 + 1차 면접. (스코프 방파제)

## 코미디 엔진

- **악당 뻥튀기** — "애기 사탕 뺏음"을 "대기근을 일으켰다"로 부풀리는 걸 간파
- **착한데 악한 척** — 사실 상냥한데 사악해 보이려다 어설프게 들통
- 거짓말이 양방향이라 자동으로 웃김

## 아트

- **캐릭터(몬스터·플레이어 손) = 복셀풍 로우폴리** — 네모네모한 블로키 룩 유지, 제작은 블렌더 박스 모델링 (2026-08-18 변경 — MagicaVoxel 복셀 단위 제작은 폐기). **환경(책상·사무실·소품) = 로우폴리 3D 모델링** (캐릭터와 단일 파이프라인).
- **톤 = 촛불 마왕성 사무실의 "귀여운데 사악한" 대비.** 옛 헥사 전투 게임의 코지 미니어처/틸트시프트 디오라마 톤은 **미승계.**
- 복셀풍 캐릭터의 "귀여운데 사악한" 대비가 면접 클로즈업에 잘 붙는다 — 이 대비 자체가 매력 (룩은 유지, 제작만 로우폴리로).

## 카운터 (리스크) — "Papers, Please 아류"

- Papers, Please는 이미 하위 장르(문서판단 심)를 낳음(Not Tonight, Death and Taxes 등).
- 차별화 = **판단축 반전 + 다크판타지 코미디 테마 + 대화형 심문**(문서 대조가 아니라 대화 간파).
- 데모가 "테마 + 한 판의 손맛"으로 서야 함.
