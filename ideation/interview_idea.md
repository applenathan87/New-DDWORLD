# 면접 덱빌딩 — 질문 카드를 전략 층으로

> 상태: **Draft v0.3** (2026-07-16) · 부모: [mvp-design.md](mvp-design.md) §7 · 형제: [interview-depth.md](interview-depth.md) (뎁스 아이디어 카탈로그 + 온도계 v1 스펙)
> 발단: §7 "카드 해금 = 덱빌딩 확장의 씨앗"을 실제 덱빌딩으로 키우는 논의 (2026-07-15).
> **방향 결정 (2026-07-15)**: 목적 = ① 준비 전략 + ② 면접 내 콤보. 수집·리플레이 변주는 부산물. 스코프 = **씨앗 프로토 선적용** (방파제: 물성 6종 상한 유지 · 질문 카드(대사 필요분) 5종 상한 유지 — 기술 카드는 대사가 없어 상한 대상 아님).
> **2차 결정 (2026-07-15)** ⭐: **아침 로드아웃 폐기 → 뽑기형 덱빌딩 채택** — 카드 매매(상점) + 덱세팅(정원제, 중복 = 확률 조형) + 면접 중 랜덤 뽑기. v0.1 §2b "뽑기 없음"은 이 결정으로 폐기 (§2b·§3d 개정).
> **3차 결정 (2026-07-16)**: **게이지 한계 초과 = 붕괴** — 면접 강제 종료 + 그 건 실패 판정 (붕괴는 단서가 아니라 그냥 실패). **카드 효과 = 범위 랜덤** (카드에 범위 표기, 예: +5~10 — 한계 근처에서 거는 도박). 용어 "덱 오염"은 유지 결정.
> ⚠️ **미결 (§6)**: 게이지의 의미·방향 + 아래쪽 극단 처리 — 확정되면 용어 일가(tell·hot/cold·온도계)를 일괄 개명. 시나리오 시연 발견 3건(§6-8~10)은 **보류**. S3b 롤백분(긴장 온도계)의 재기획을 이 문서가 흡수한다.

## 2. 구조 결정 4가지

### 2a. 카드 2계열 — 콘텐츠 비용이 강제하는 구조

질문 카드 1종 추가 = 지원자 전원의 답변 저작 (현재 면접 16건, 본편 수십 건). [mvp-design.md](mvp-design.md) §13 "카드 5종 상한"의 근거가 이것 — 이 구조 그대로는 덱이 못 자란다. → 2계열 분리:

| 계열 | 예 | 대사 비용 | 확장성 |
|---|---|---|---|
| **질문 카드** | 지원 동기 · 교차 검증 · 함정 질문 | 지원자별 답변 필요 | 소수 정예 (본편에도 8~10종) |
| **화법·기술 카드** | 차 대접(긴장↓) · 침묵(tell 강조) · 되묻기 · 미끼 서류 · 소지품 검사 | 시스템 효과 — 거의 불필요 (종족 공용 반응 1줄) | 사실상 무제한 |

- ⭐ **덱빌딩 = 면접 뎁스 기믹의 전달 수단**: [interview-depth.md](interview-depth.md) 아이디어 7종 중 ④소지품 검사·⑤미끼 서류 등이 기술 카드로 수집물화된다. 기믹을 한꺼번에 쏟으면 학습 붕괴 — 카드·도구로 하나씩 얻게 하면 성장 쾌감과 학습 커브 분산을 동시에 해결.
- **카드 업그레이드도 같은 논리로 저렴**: 시스템 속성(코스트·긴장 변화량·tell 선명도)만 바꾸면 대사 재저작 없음. 예: 함정 질문 → 정교한 함정 (실패 비용↓ — 열린 질문 #1과 연결).

### 2b. 랜덤 뽑기 **채택** (v0.2 개정 — v0.1 "뽑기 없음"을 뒤집음)

**결정 (2026-07-15 2차)**: 덱빌딩의 실체 = **수집·매매(상점) + 덱세팅(정원제 덱 구성) + 랜덤 뽑기 + 시너지(온도계 경유).**
개정 이유: 아침 로드아웃을 폐기한 시점에서 "판마다 조금씩 다름"을 만들 장치가 비었고, 뽑기가 그 자리를 채운다 (§5a 경고 1 — 변주를 지원자 콘텐츠가 전담하는 부담 — 을 뽑기가 분담). 덱빌딩의 정체성(뽑는 맛·확률 조형)도 뽑기 없이는 성립하지 않는다.

**v0.1이 기각했던 이유들에 대한 안전장치 (뽑기 채택의 전제 조건):**
1. **"필요한 질문을 못 뽑아서 케이스를 못 푸는" 상황 원천 차단** — ① **기본 질문 = 덱 밖 상시 비품** (책상 소품, 언제나 사용 가능) ② **결정타 2경로 저작 규칙**: 모든 케이스의 결정타는 카드 경로 + 서류·관찰 경로 병행 (S2b 저작 관행 "전원 서류에도 결정타 병행"의 규칙 승격). → 나쁜 손패 = 효율 하락일 뿐, 못 푸는 판은 없다 (§2d "효율이지 가능성이 아님" 원칙 그대로).
2. **포셔노믹스형 불공정 체감 방지** — 덱 오염 금지 (스트레스 카드류 없음 — 긴장 게이지는 지원자 쪽), **중복 투입 = 출현 확률을 플레이어가 직접 조형** (포셔노믹스 고수들이 뽑기 엔진으로 우회 달성하던 것을 정식 레버로 제공), 면접이 3액션으로 짧아 나쁜 손패의 비용이 한 판에 국한 (긴 카드 배틀이 아님).
3. **면접관 판타지 절충** — 픽션: 덱 = 책상 위 질문지 더미, 뽑기 = 더미에서 손에 잡히는 것. 기본 질문(비품) = "매뉴얼"이라 면접관의 주도권 픽션은 유지.

### 2c. 시너지의 기반 = 긴장 온도계 (S3b와 한 몸)

콤보가 성립하려면 카드들이 경유할 **공유 상태**가 필요 — 그게 온도계. 없으면 카드 10종을 모아도 일방향 조회 10개일 뿐 (순서·조합 무의미 — interview-depth의 문제의식 그대로). **온도계 기획 확정 = 덱빌딩 기획의 전제.** → §3에서 재기획.

### 2d. 가드레일 — 덱이 정답기가 되면 안 된다

- **돋보기 원칙([mvp-design.md](mvp-design.md) §6)의 일반화**: 카드는 정보 채널을 열 뿐, 합불을 출력하지 않는다. 해석과 방향(V/X)은 끝까지 플레이어 몫.
- **기본 카드만으로 모든 케이스 해결 가능** — 전문 카드 = 효율·확신 상승이지 가능성이 아님 (나쁜 손패로 못 푸는 판이 생기는 좌절을 방지).
- **질문 포인트 3 = 파워 인플레의 천연 방파제**: 수집이 늘어도 행동은 3회 — 옵션이 늘지 파워가 늘지 않는다. ⚠️ 역으로 **예산 자체를 파는 상품은 신중히** (까마귀 상점 드링크 +1 — 예산이 흔들리면 "이 지원자에겐 뭘 물을까" 조임이 풀림).
- 근본 경계: 후크 = 간파·판단축 반전이고 덱빌딩 = 보조 축. 빌드 고민이 지원자 읽기보다 커지면 주객전도. → 구조적 대응 = §3b (온도 전략 자체를 간파의 일부로 통합).

## 3. 씨앗 스펙 — "게이지 + 기술 카드 + 덱" (S3b 재기획 통합)

### 3a. 게이지 (가칭 "긴장" — 의미·방향·이름 = §6-1) — v1 승계 + 붕괴·범위 랜덤 (v0.3)

- **기본 골격 (v1 승계)**: 시작 25 / 던지기 세기 = 톤 판정 (드롭 속도 경계 1.5m/s — 압박/정중). v1 스펙·코드 = [interview-depth.md](interview-depth.md), 커밋 8c2c10e.
- **카드 효과 = 범위 랜덤 (3차 결정)** ⭐: 효과는 고정값이 아니라 **카드에 표기된 범위** (예: 압박 +5~10). 실제 변화량은 범위 안에서 랜덤 — 게이지 90에서 +5~10을 던지는 것 = 붕괴를 걸고 하는 도박. **공정 조건**: 범위와 현재 게이지를 전부 공개 (눈 뜨고 거는 도박이어야 함). 시드 로그 (재현용). v1의 고정값(+30/−10)은 범위로 전환 — 폭·스케일은 노브.
- **붕괴 (3차 결정)** ⭐: 게이지가 한계를 넘으면 **지원자가 무너져 퇴장 — 면접 즉시 종료, 그 건은 실패 판정** (남은 포인트 소멸, 도장 기회 없음. 오판과 동급 취급 — 세부는 튜닝). 붕괴는 단서가 아니라 **그냥 실패**. 한계선이 위쪽만인지 양쪽 다인지 = §6-2.
- **발끈 규칙(v1: 85에서 답변 거부)은 붕괴로 대체** — 한계 근처 구간은 경고 연출(입술 떨림·눈물 그렁 = 위험 신호)로 전환.
- (옵션 노브) 압박만 범위·정중은 고정값 — §6-6 "미달 답답함"이 관측되면 검토.

### 3b. tell = 온도 창 2계층 ⭐ (v1 수정 — 롤백 원인 해소)

v1 "긴장 ≥ 50에서만 tell 노출"의 문제: ① 기존 16건 밸런스 전면 영향 ② 매 면접 "일단 달구기"가 정답이 되는 단조로움. 수정안:

- **기본 tell**: 온도 무관 항상 노출 — **기존 케이스 전부 무수정 하위 호환**
- **심층 tell**: 진술에 온도 창 태그 — `hot`(긴장 높을 때만 새어 나옴) / `cold`(편안할 때만 새어 나옴)
- **거짓 유형(mvp-design §6, 4종)과 매핑**:

| 거짓 유형 | 온도 반응 | 공략 |
|---|---|---|
| 악행 뻥튀기 | **hot** — 압박에 무너짐 | 달군다 |
| 선함 은폐 | **cold** — 편안하면 본색이 샘 | 식힌다 (차 대접) |
| 위장 잠입 (스파이) | **무반응** — 프로라서 온도로 안 뚫림 | 함정 질문·교차 검증만 |
| 경력 위조 | 온도 부차 | 서류 대조·촛불 축 |

- ⭐ 노림수: **"달궈야 하나 식혀야 하나"가 지원자 읽기의 일부**가 된다 — 콤보가 곧 간파 (§2d 주객전도의 구조적 대응). 달구기만 정답인 게임이 아니게 됨.

### 3c. 기술 카드 씨앗 3종 (대사 불필요 · 질문 포인트 공유)

| 카드 | 코스트 | 효과 | 역할 |
|---|---|---|---|
| **차 대접** | ★1 | 긴장 −30 | 냉각 주 채널 (cold tell 수확) |
| **책상 내려치기** | ★1 | 긴장 +25, 답변 없음 | 질문 소모 없는 달구기 (던지기 톤 = 질문에 얹히는 무료 ±, 이건 순수 온도 조작) |
| **침묵** | ★1 | 다음 답변의 tell 지시문 선명화 | 질문 하나를 포기하고 관찰에 투자 |

- 포인트 3 공유 → **"기술에 1 쓰면 질문이 2개"** 조임이 운영 긴장의 원천.
- 획득처 = **까마귀 상점** (S3a 상점 진열 추가 — 골드 싱크 확장, #13 경제와 연결).
- 차 대접의 물성: 씨앗 = 카드 (기존 손패·던지기 파이프라인 재사용). 비전 = 주전자 소품으로 이전 검토 (§5 "덱 = 책상").

### 3d. 덱 시스템 ⭐ (v0.2 — 아침 로드아웃 폐기·대체)

- **덱 정원제**: 덱 = 정확히 N장 (씨앗 12~15로 시작, 본편 20 검토 — 노브). **중복 투입 허용** — 같은 카드를 여러 장 = 자주 잡히게 만드는 것. **종류·중복 비율의 조형이 곧 덱세팅** ("차 대접 3장 = 냉각 위주 덱").
- **뽑기**: 면접 시작 시 4장 + 카드를 쓸 때마다 1장 보충 (손패 상한 5 — 노브). 면접 종료 시 회수·재셔플. 픽션 = 책상 위 질문지 더미에서 손패로 넘어옴.
- **기본 질문 = 덱 밖 상시 비품** (★1, 책상 소품) — 어떤 손패에서도 최소 심문 가능 (§2b 안전장치 ①).
- **사용 규칙**: 질문 카드는 같은 종류 면접당 1회 (같은 질문 반복 = 픽션 붕괴. 중복 투입의 가치 = 매 판 안정적으로 잡히는 것). 기술 카드는 중복 사용 가능 (차 두 잔 대접 = 오히려 코미디 정합).
- **매매**: 까마귀 상점에서 구매 + **되팔기 반값** (덱을 다시 짤 수 있음 — "중고 화법은 값이 떨어지지"). 승진 지급 카드(교차 검증 등)는 별도 채널 유지.
- **덱 편집 = 밤, 내 방에서** (다이어제틱: 책상 서랍·카드 지갑). **아침 의식 없음** — 출근하면 바로 업무.
- **공문 힌트 1줄 유지** (예: "경리부 채용 — 착해 보이는 놈들을 조심하시오") — 덱세팅(밤)과 그날의 운용 방침(낮) 양쪽에 정보 제공.

## 5. 비전 메모 (씨앗 이후)

- **"덱 = 책상 위 실물"** (아침 의식 폐기에 맞춰 손질): 덱 더미·기본 질문·가젯이 전부 책상 위 물건으로 존재 — 말인 것(질문·화법) = 카드 더미, 물건인 것(주전자·미끼 서류) = 가젯. 본편에서 가젯이 늘면 책상 공간 배치 자체가 선택이 되는 비전. 메타 화면 없이 전부 다이어제틱 — 물성 원칙의 메타 확장.
- **#11 공문/JD 로테이션과의 상호 강화**: 로테이션이 채택되면 "오늘 뭘 넣어 가나"의 덱 가치가 날마다 재정의됨 — 덱빌딩과 #11은 서로의 가치를 배가.
- 즉석 질문 (§2b 절충) · 카드 업그레이드 (§2a) · 조건 매핑을 흔드는 예외 케이스 (§6-3).

### 5a. 포셔노믹스 교차 검증 (2026-07-15 조사 — 상세·출처 = [REF_GAME/potionomics.md](../REF_GAME/potionomics.md))

**우리 구조 결정이 검증됨:**
- **뽑기 운의 위험 실증** *(조사 당시 v0.1 "뽑기 없음"의 근거 — v0.2에서 뽑기를 채택하며 이 위험은 §2b 안전장치로 흡수)* — 포셔노믹스 최대 불만이 뽑기 오염(스트레스 카드가 손패에 섞임)이었고, 숙련 플레이 = "운을 지우는 덱"으로 수렴.
- **카드 2계열(§2a) 실증** — 카드 약 80종 전부 시스템 효과·고유 대사 0으로 협상극 성립 (네이밍·플레이버만으로). 깊이 = "게이지 하나 × 그걸 움직이는 수십 가지 방법".
- **정답기 금지(§2d)의 반면교사 실존** — 단일 최적 덱(Chorus 엔진)이 흥정을 자동승리 기계화. 포셔노믹스는 결과물이 가격(많고 적음의 문제)이라 살았지만 우리 결과물은 합불(맞고 틀림의 문제)이라 코어가 즉사.
- **긴장 게이지를 지원자 쪽에 둔 것** — 포셔노믹스의 플레이어측 스트레스는 "확률이 확률을 낳는" 나선으로 최대 불공정 체감 소스.

**스펙 반영 후보 (§6 확정과 함께 판단):**
1. **문턱은 확정, 움직임은 운 (v0.3에서 채택 형태 확정)** — 포셔노믹스 손맛의 원천("하트 만렙 = 무조건 성공")처럼 단서선·붕괴선 도달의 **결과**는 확정 (도달하면 반드시 샌다/무너진다). 대신 카드 효과가 범위 랜덤(§3a)이라 도달 **과정**이 도박 — 블랙잭 구조 (카드는 운, 21이라는 선은 확정).
2. **상·하한 3규칙** (§2d 보강) — ① 코스트 할인·환급은 0 아래로 못 내려감 (마이너스 비용으로 새는 버그 금지 — Jingle 교훈) ② 한 판 안에서 끝없이 강해지는 카드 금지 (상한 또는 판마다 초기화) ③ 지원자 저항 = 수치 깎기가 아니라 **접근 잠금** ("압박이 아예 안 통함, 정중만 열림") — 덱을 갈아끼울 이유가 매일 생김.
3. **첫 수·맺음 수 문법** — "언제 내는가"가 효과를 바꿈 (첫 질문으로 낼 때 보너스 / 마무리 전용 카드). 던지기 톤과 자연 결합, 대사 불필요.
4. **"멈출까, 더 갈까" 마감 선택** — 포인트를 아끼고 조기 판단 vs 끝까지 심문해 확신 (조기 종료 보상). v0.3의 범위 랜덤·붕괴와 자연 결합 — 매 면접에 미세 긴장.
5. **관계 → 카드 파이프라인** (비전) — 화법 카드를 "동료 악마에게 배운 기술"로 (Persona식, 밤 파트·상점과 연결). 보스급 지원자의 **덱 오염**(역심문 — 내 손패에 동요 카드 주입)도 비전 후보.

## 6. 미결 체크 질문 (확정 게이트)

1. **게이지의 의미·방향** (고민 중): 긴장이 차오르는 그림(위 = 붕괴, 달군다/식힌다·압력계 물성과 어울림) vs 멘탈이 깎이는 그림(0 = 멘붕, HP 직관 그대로). 기계적으로 동일 — 이름·연출·물성이 갈림. **⚠️ 확정되면 용어 일가(tell → ?, hot/cold → ?, 온도계 → ?)를 일괄 개명** (2026-07-16 용어 감사에서 확인된 13곳+).
2. **아래쪽 극단 처리** (고민 중): 편안한 쪽 끝은 안전 vs 양쪽 다 붕괴 (너무 풀어져도 면접 파탄 — "신발 벗고 눌러앉음"). 1번 결정에 따라 자연스러운 쪽이 달라짐.
3. **단서 조건 외우기 변질**: 유형↔조건 매핑이 고정이면 "뻥튀기형이네 → 달구자"가 자동화될 위험. 대응 = 예외 케이스로 흔들기 + **v0.3의 범위 랜덤·붕괴 리스크가 실행 난이도를 추가** (아는 것 ≠ 해내는 것) — 이걸로 충분한지 플레이 확인.
4. **정보 기아**: 기술 카드가 포인트를 먹으면 질문이 1~2개로 줄어 단서 부족 위험. 포인트 3 유지 후 플레이로 확인 vs 처음부터 4로 상향? (까마귀 상점 드링크 +1과의 상호작용 포함해서 볼 것)
5. **나쁜 손패 완충**: 씨앗은 다시 뽑기(면접 시작 시 손패 1회 교체) 없이 시작 — 플레이에서 "손패 때문에 억울한 판"이 관측되면 도입.
6. **(v0.3 신규) 범위 랜덤의 "미달" 답답함 관찰**: 단서선을 노렸는데 낮은 값이 굴러서 못 미침 = "아무 일 없음" 턴. 붕괴 도박(스릴)과 달리 미달은 맥이 빠짐 — 답답하면 범위 폭·단서선 위치·압박만 범위(§3a 옵션 노브) 조정.
7. **덱에 질문 카드 포함 (확인 대기)**: "질문+기술 모두 한 덱에서 뽑힌다"로 정리함 (안전장치 = 기본 질문 비품 + 결정타 2경로). "기술 카드만 뽑히고 질문 카드는 상시"를 의도했다면 §3d만 수정하면 됨.

**(2026-07-16 시나리오 시연에서 발견 — 전부 결정 보류, 스펙 미반영)**

8. **숨은 단서의 수확 방식**: 단서선 돌파 순간 자동 누설(A안) vs 창 안에 들어간 상태에서 질문해야 누설(B안 — 시연은 B안 + 창 진입 연출은 공짜 신호로 진행).
9. **기본 질문의 재사용 가능 여부**: B안이면 "창 안에서 찔러보는 범용 수확기" 역할이라 재사용 허용이 필요 — 현 문서엔 "상시 비품"까지만 명시.
10. **지원자별 게이지 개인차 스탯**: "잘 놀람 — 압박 효과 1.5배" 같은 반응성 개인차 도입 여부 (포셔노믹스 "고객 = 스탯 재조합" 계보, 저작 비용 낮음).
