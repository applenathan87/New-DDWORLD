# 밤 파트 — 퇴근 후의 내 방 (마왕성 기숙사)

> 상태: **Draft v0.2** (2026-07-05 — 사용자 결정 반영) · 부모 문서: [mvp-design.md](mvp-design.md)

> **v0.2 확정 결정**: ① 데모에 밤 파트 구현 ② 장소 = **내 방** ③ 행동 횟수 **제한 없음** ④ 상점·미니게임 = **직급별 언락** ⑤ 톤 = **경쾌·코믹** (디스토피아식 생계 압박 배제)

## 1. 톤 선언 — 우리 밤은 무겁지 않다 ⭐

레퍼런스 5종(Papers Please·Beholder 등)의 밤은 대부분 **디스토피아·우울·생계 압박**이다. 우리는 그 길로 더 파고들지 않는다:

- **밤 = 하루 중 가장 귀엽고 웃긴 시간.** 정산·업그레이드·미니게임을 통해 **마왕성 세계관의 코믹한 얼굴**을 보여주는 무대.
- 압박 장치(필수 지출·시간 제한·굶는 가족)는 **도입하지 않는다.** 긴장은 낮(심문·판정)의 몫, 밤은 이완과 보상의 몫.
- 다크함은 **신문 기사의 유머**로만 스친다 ("내가 뽑은 고블린이 금고를 털었다"는 아프지만 웃기게).

그래도 유지하는 원칙: **밤의 모든 요소는 낮과 순환한다** (여파 확인·다음 낮 준비). 순환하지 않는 활동은 넣지 않는다.

```
[낮] 심문·간파·도장 → 공적(승진) + 골드(수당)
[밤] 내 방: 신문(여파·웃음) → 정산(수입 확인) → 자유 행동(업그레이드·꾸미기·미니게임)
[다음 낮] 산 것들이 나를 돕는다 (+방이 점점 내 것이 되어간다)
```

## 2. 무대 — 마왕성 기숙사 내 방

- **새 그레이박스 공간**: 침대·작은 탁자·창문(달·박쥐)·선반·문. 고정 카메라 1컷 (데스크 뷰와 동일 문법).
- 퇴근 연출: 결산(공적 게이지) 종료 → 화면 전환 → 밤 방 (촛불 램프 플리커, 창밖 달빛).
- **방 = 성장의 거울**: 직급이 오르고 물건을 사면 방이 눈에 띄게 변한다 (선반에 장식이 쌓이고, 새 가구·설비가 언락). 커리어 진행의 물리적 체감 — 책상(업무 가젯)과 대구를 이루는 사적 공간의 빌드업.
- 방 안 소품 = 클릭 코미디: 애완 슬라임(밟으면 출렁), 「이달의 사원」 포스터, 창밖 박쥐 떼… 클릭하면 플레이버 한 줄. 세계관 엿보기의 최전선.

## 3. 밤 타임라인 — 자유 행동, 침대로 마감

행동 횟수 제한 없음. 하고 싶은 것을 하고, **침대 클릭 = 취침 → 다음날 출근.**

| 요소 | 물성 | 내용 |
|---|---|---|
| 석간 신문 | 탁자 위 신문 집어 읽기 | **여파**: 오판 기사·놓친 인재 기사·스케줄 위반 기사 + 세계관 플레이버 기사 |
| 월급봉투 | 봉투 클릭 → 명세서 | 수당 = 기본급 + 정확 보너스 + 근거 적중 보너스 − 사고 청구서 (명세 줄줄이 코미디) |
| 자유 행동 | 방 안 오브젝트들 | 아래 §5 — 직급별로 열리는 것이 늘어남 |
| 취침 | 침대 클릭 | 다음날 아침 출근 (아침 사고 보고서는 신문으로 흡수 → 아침은 바로 근무) |

## 4. 석간 신문 「마왕성 석간」

- **오채용**: "신입 {이름}, 첫 출근날 대형 사고" (명백 건 = 당일 석간 / 애매 건 = 1~2일 뒤 — 지연 사고 유지)
- **오거절**: "본성이 놓친 {이름}, 경쟁 던전 '옆동네 지하실' 입사… 그쪽 사장은 함박웃음"
- **스케줄 위반**: 기존 아침 보고서 문구를 기사체로 이관 (이미 코미디체라 재사용 가능)
- **플레이버 기사 풀**: 마왕 생신 행사·용사 동향·사내 공지 등 — 세계관 코미디 + 다음날 복선
- 신문 구석 = 개그 재사용처 (구인 광고·독자 투고).

## 5. 자유 행동 — 직급별 언락 ⭐

**"없다가 생긴다"가 핵심.** 첫 밤의 방은 단출하고(신문·월급·슬라임·침대), 승진할 때마다 방에 새 오브젝트가 **눈에 보이게 추가**된다. 성장·언락·빌드업을 밤 공간 자체로 구현.

| 직급 (레벨) | 언락 | 내용 |
|---|---|---|
| 1 (수습) | 기본 방 | 신문·월급봉투·애완 슬라임·포스터·침대 |
| 2 (승진 1회) | **까마귀 상점** | 창가 까마귀가 카탈로그를 물어옴 — 골드 소비 개시 (§6) |
| 3 (승진 2회) | **미니게임 테이블** | 뼈 주사위 등 골드 벌이 미니게임 (형태는 별도 프로토) |
| 4+ (본편) | 방 설비 확장 | 더 좋은 침대(컨디션↑)·수정구 TV·동료 방문 이벤트… |

- 언락 전 오브젝트는 **잠긴 채 보인다** (코믹 잠금 문구: "주사위 컵 — 3급 이상만 굴릴 수 있음 (인사 규정 §66)") → "다음 승진엔 뭘 주지?"를 밤에도 묻게 만든다 (가젯 검증 질문의 밤 버전).
- 미니게임 원칙: 순수 운보다 **간파의 변주** 우선 (속임수 읽기) — 낮의 눈을 밤에도 쓴다. 단, 톤은 가볍게.

## 6. 골드 — 가벼운 정산 + 기분 좋은 소비

- **수입**: 일당(기본급+정확+근거 적중−청구서). 청구서는 압박이 아니라 **명세서 위의 코미디 한 줄** ("문짝 수리비 −5G (돌주먹 님 건)").
- **소비 (까마귀 상점, 레벨 2+)**: 카테고리 3종 —
  1. **내일을 돕는 것**: 박쥐 에너지 드링크(내일 질문 포인트 +1), 내일 지원자 소문(정보) 등
  2. **방을 꾸미는 것**: 미니 마왕 조각상, 화분(맨드레이크), 벽걸이 트로피 — 사면 방에 실물로 진열
  3. **슬라임을 위한 것**: 간식·장난감 — 애완 슬라임 반응이 커짐 (순수 귀여움 담당)
- 필수 지출 없음. 안 사도 페널티 없음 — **사면 좋고, 모으면 큰 걸 산다**의 순한 경제. (§15 #13의 "싱크와 동시 도입" 충족: 상점 언락 = 싱크 개시와 골드 축적이 같은 흐름)
- 뇌물 승진(#13)은 본편 과제 유지.

## 7. 낮↔밤 되먹임 표

| 낮 → 밤 | 밤 → 낮 |
|---|---|
| 판정 정확도 → 수당·공적 | 드링크 → 내일 질문 포인트 +1 |
| 오판·위반 → 석간 기사 + 청구서 한 줄 | 소문 구매 → 내일 지원자 힌트 (구현 시 뽑기 선확정 필요) |
| 승진 → 방에 새 오브젝트 언락 | 방 꾸미기 → 직접 효과 없음 (애착·빌드업 담당) |

⚠️ 단계 비연결 원칙 정합: 신문 기사 = 케이스 결과 서술(재등장 아님) / 소문 = 내일 뽑기를 밤에 선확정하면 구현 가능.

## 8. 데모 스코프 (S3 구현분)

- **밤 방 그레이박스** + 신문 + 월급 정산 + 애완 슬라임·플레이버 클릭 + 침대 취침
- **까마귀 상점** (승진 후 언락 — Day 1 밤엔 잠김, 승진한 밤부터 열림): 드링크·장식 1~2종·슬라임 간식
- **미니게임 테이블 = 잠긴 티저만** (실제 미니게임은 본편/여유 시)
- 아침 사고 보고서 화면 삭제 → 신문으로 흡수
- 코드: `NightRoom`(방 그레이박스) + `NightFlow`(진행) — SchedulingFlow 선례 패턴, 새 씬 없이 같은 씬의 별도 좌표에 방 배치

## 9. 검증 계획

1. **밤이 기다려지는가** — "신문에 뭐가 났을까 + 뭘 살까"
2. **방이 애착 공간이 되는가** — 산 물건이 진열될 때 기분이 좋은가
3. **언락이 견인하는가** — 잠긴 주사위 컵을 보고 "다음 승진엔…"이 되는가
4. **낮과 순환하는가** — 드링크·소문이 다음날 실제로 도움됐는가

## 10. 열린 질문

1. 미니게임 형태 (뼈 주사위 홀짝 + 속임수 간파?) — 레벨 3 언락분, 별도 프로토
2. 소문(정보) 아이템의 데모 포함 여부 — 뽑기 선확정 구현 비용 대비
3. 신문 기사 저작 방식 — 템플릿+이름 삽입 vs 케이스별 전용 기사 (시트 열 추가)
4. 방 꾸미기 아이템 목록·가격 곡선 (본편: 골드 장기 싱크의 중심)
5. mvp-design 반영 — §2 방파제 표·§3 퇴근 장면 절 갱신 (이 문서 승인 시)
