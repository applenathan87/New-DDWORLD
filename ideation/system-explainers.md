# 1. 서류 심사 단계 (Day 1 오전)

## 게임 개요
1인 개발 중인 PC 인디게임(Unity). 장르는 **다크판타지 코미디 HR 시뮬레이션** — Papers, Please 계열의 판단·심문 게임이다. 플레이어는 마왕성 인사팀의 신입 직원이 되어 몬스터 구직자들을 심사한다. 핵심 후크는 **판단축 반전**: 악당을 뽑는 회사이므로 거짓말·잔인함이 (직무에 따라) 장점이고, "알고 보니 착함"이 탈락 사유다. UI 버튼 대신 책상 위 실물(서류·도장·깃펜)을 직접 잡고 조작하는 **다이어제틱 데스크**가 조작 원칙이다.

## 서류 단계의 위치
게임 첫날(Day 1)의 업무다. 하루 구조: **서류 심사(7건) → 오후 업무(면접 일정 잡기 퍼즐) → 퇴근 결산 → 성과에 따라 승진(Day 2 면접관) 또는 재도전**. 서류 단계는 면접 없이 **서류만 보고** 통과/탈락을 판정한다.

## 화면과 조작 (물성)
- 3D 책상 클로즈업 고정 카메라. 촛불 조명의 어두운 사무실.
- 책상 위에 **이력서**(지원자 서류)와 **공문**(오늘의 채용 지침 + 직무 요건서)이 놓여 있다. 아무 종이나 클릭하면 **두 장이 함께 눈앞으로 들려 올라와** 나란히 읽을 수 있다 (교차 대조가 핵심 플레이라서). 빈 곳을 클릭하면 내려놓는다.
- **단서 마킹**: 이력서의 각 줄과 "특이사항"은 클릭 가능한 단서다. 깃펜으로 **좌클릭 = V(합격 신호), 우클릭 = X(탈락 신호)**를 표시한다. 즉 "이 줄이 근거다"가 아니라 **"이 줄은 어느 방향의 근거다"까지 커밋**해야 한다 — 같은 사실이 직무에 따라 장점도 결점도 되는 게임이라, 방향이야말로 플레이어가 반전 축을 이해했는지의 증거다.
- **판정 = 도장**: 통과/탈락 도장 2개를 손으로 잡아 서류 위에 내리찍는다. **근거를 최소 1개 마킹하지 않으면 도장이 찍히지 않는다** (감으로 찍기 방지). 도장은 커서가 가리킨 지점에 낙하해 잉크 자국을 남긴다.

## 판정 구조 (퍼즐의 뼈대)
- **직무(JD)** 3종: 일반 행정(요구: 꼼꼼함·야근 내성 / 결격: 서류 위조·방화 충동), 던전 경비(요구: 우직함·겁 없음·위협적 인상 / 결격: 상냥함·용사 측 인사), 회계(요구: 숫자 집착·의심 많음·인색함 / 결격: 횡령 전과·씀씀이 헤픔).
- 지원자마다 **지원 직무가 정해져 있고**, 정답은 "이 지원자의 실제 자질이 그 직무의 요구/결격과 맞는가"로 결정된다. **같은 특성도 직무가 다르면 정답이 뒤집힌다** (예: 방화 충동은 행정에선 결격이지만, 방화부서라면 합격감이라고 해설이 짚어줌).
- 데이터 구조: 지원자 1건 = 이력서 줄 1~3개 + 특이사항 1개. 각 줄에는 숨은 태그가 있다 — 빈 값(단서 아님) 또는 **정답 방향과 같은 값(결정적 근거)**. 모든 케이스는 결정적 근거를 최소 1개 갖도록 검증기가 강제한다.

## 콘텐츠 구조 (리플레이 설계)
- 케이스 풀 **34건** 중 매판 **7건을 뽑는다**. 이미 나온 케이스는 뒤 순위로 밀리는 **셔플백** 방식이라, 실패 후 재도전하면 새 얼굴들이 나온다 (간파 게임은 답을 외우면 죽기 때문).
- 첫 판의 첫 케이스만 고정: "물컹이"(착한 슬라임이 경비에 지원 — 훈훈한 추천서가 탈락 사유가 되는 튜토리얼 반전 케이스).
- 케이스 유형 분포 목표: 명백 합격 20% / 명백 탈락 20% / 간파 필요 50% / 함정 10%. 함정 예시: 훈훈한 할머니 마녀가 알고 보니 "올해의 함정" 수상자라 합격("착해 보임 ≠ 착함"의 역반전), 무급 지원이 인간에겐 스파이 신호지만 드래곤에겐 금고 애착의 증거인 케이스 등.

## 채점과 보상
- 하루가 끝나면 **퇴근 결산**: 건별로 정답 공개 + 3단 채점 — ① 근거·방향 적중 ② "단서는 짚었지만 방향을 반대로 읽었다"(반전 오독 — 최고의 학습 모먼트로 취급) ③ "결정적 단서는 따로 있었다".
- 최종 화면에서 **공적 게이지**가 0→100으로 차오른다. 공적 = 정확 판정 ×2 + 근거 적중 ×1을 기준치 대비 100점 환산. **100 도달 = 승진**(다음날부터 면접관 업무 해금), 미달 = 다음날 서류 재도전(새 뽑기).

## 기술 메모
콘텐츠는 전부 외부 JSON(지원자·직무·공문·정답·해설)이라 코드 수정 없이 늘릴 수 있고, 로드 시 검증기가 데이터 규칙(정답 방향 근거 존재, 줄 수 한계 등)을 강제한다.

## 예시 케이스: 물컹이 (첫 판 고정 튜토리얼 반전)

**① 이력서 (플레이어가 보는 것)**
```
지원자 서류 · MHR-01-001
물컹이 / 슬라임 ♂ / 지원 직무: 던전 경비 / 희망 연봉: 연 1,800 G
"저… 무섭게 생겼다는 말 많이 들어요!"
이력
 · 동네 아이들 사이에서 '말랑이 형'으로 통함
 · 다친 참새를 3개월 간호해 하늘로 날려보냄
 · 추천서: '이렇게 착한 슬라임은 처음입니다' — 인간 마을 촌장
특이사항: 추천서에서 은은한 꽃향기가 남. 이력서 모서리에 참새 스티커.
```

**② 함께 대조하는 공문/직무 요건**
```
공문: "마왕성 인재상: '악행에 진심인 자'. 훈훈한 인재는 정중히 거절할 것."
던전 경비 — 요구: 우직함·겁 없음·위협적 인상 / 결격: 침입자와 친해지는 성격·지나친 상냥함·용사 측 인사
```

**③ 숨겨진 데이터**: 이력 3줄과 특이사항 전부 evidence=FAIL(탈락 방향 결정타), 정답 = FAIL.

**④ 정답 플레이**: 두 장 대조 → "경비의 결격 = 상냥함" 발견 → 추천서 줄에 **우클릭 X** (일반 상식으론 추천서가 합격 신호라 여기서 반전 학습이 일어남) → 탈락 도장. 결산 해설: *"인간 촌장의 훈훈한 추천서는 마왕성에선 위험 신호다. — 여기선 '착함'이 결격이다. 판단축이 뒤집혔다!"*

**⑤ 설계 의도**: 일반 게임이라면 명백히 합격인 서류를 첫 케이스로 줘서, 설명 없이 스스로 "아, 여긴 착하면 떨어지는구나"를 발견하게 만든다.

# 2. 면접 일정 잡기 — 전화 스케줄링 퍼즐 (Day 1 오후)

## 게임 내 위치
Day 1의 오후 업무다. 하루 흐름: 서류 심사(오전) → **면접 일정 잡기(오후)** → 퇴근 결산 → 다음날 아침 사건 보고서. 서류 심사가 "읽고 간파하는" 업무라면, 이 파트는 **제약을 듣고 배치하는 퍼즐**로 하루의 리듬을 바꾸는 역할이다.

## 픽션 설정 (단계 비연결 원칙)
스켈레톤 인턴이 업무를 인계한다: *"오늘 인사팀 **전체**에서 서류 통과된 지원자 명단입니다. 수정구로 연락해서 가능한 시간을 들은 다음, 일정표에 사진을 붙여 주세요."* — 중요한 설계 결정: **내가 오전에 통과시킨 인물들이 아니라 독립된 지원자 세트**다 (픽션: "심사한 서류는 다른 팀 면접으로 배정 — 정이 든다는 규정 때문"). 인물을 단계 간 연결하면 콘텐츠 저작 비용이 폭증하고 랜덤 풀 구조와 충돌하기 때문에, 각 단계를 자기완결 퍼즐로 유지한다.

## 화면과 조작 (물성)
- 책상 위에 **사진 카드 5장**(통과자 명단) 트레이, **수정구**(마왕성의 전화 — 실제 책상 위 3D 소품), **캘린더 종이**(6슬롯: 내일/모레 × 오전/오후/밤).
- **통화**: 사진을 수정구로 끌어다 대면(또는 클릭) 사진이 수정구에 붙고, 말풍선으로 통화 대사가 나온다. 통화 내용은 "통화 기록" 패드와 사진 카드 라벨에 요약 축적된다.
- **배치**: 사진을 캘린더 슬롯에 드래그. 차 있는 슬롯에 넣으면 기존 사진이 트레이로 밀려난다.
- **확정**: 5명 전원 배치 시 "일정 확정" 버튼 활성화 → 초록 확정 도장이 캘린더에 쾅.

## 퍼즐 구조 — 제약 매칭
정보가 3층으로 전달된다: ① **사진 힌트**(일부만 누설: "낮에는 전화를 안 받는다고 함") ② **통화 대사**(제약의 진짜 출처 + 코미디 채널: *"햇빛 알레르기가… 심각하게 치명적입니다"*) ③ **슬롯 경고**("[!] 비 예보", "[!] 보름달").

| 후보 | 제약 | 통화 대사 요지 |
|------|------|------------|
| 불라디 (뱀파이어 남작) | 밤만 가능 | 햇빛 알레르기 |
| 물렁공 (슬라임) | 비 금지 | 빗물과 섞여 자신의 경계를 잃음 |
| 돌주먹 (오크) | 보름달 금지 | "그날은 다른 제가 됩니다" |
| 가마솥 (마녀) | 오후만 가능 | 오전엔 솥이 끓고, 밤엔 "다른 일"이 |
| 달그락 (스켈레톤) | 제약 없음 | "뼈는 스케줄이 없습니다" — 퍼즐의 여유 조각 |

슬롯 6개에 5명 배치라 자유도가 1칸 있고, 무제약 후보가 배치 실수를 구제하는 완충재다.

## 핵심 디자인: 위반해도 막지 않는다
잘못된 배치(뱀파이어를 낮에)도 **경고 없이 그대로 확정할 수 있다.** 대가는 즉시가 아니라 **다음날 아침 "사건 보고서"**로 온다:

> *"낮 면접에 오신 불라디 님은 입장 3초 만에 재가 되셨습니다. 유족(박쥐 12마리)에게 위로금을 지급했습니다."*
> *"우천 면접일, 물렁공 님이 배수구로 유실되었습니다. 현재 하수도에서 수색 중입니다."*

무사고면 인사팀장이 "신입치고는 수상할 정도로 완벽하군"이라며 칭찬한다. 이 구조는 게임 전체의 **"지연 사고" 시스템**(오판의 대가가 하루 뒤 보고서·신문으로 돌아오는 것)의 튜토리얼이다 — 통화를 안 듣고 대충 꽂는 플레이어에게 게임이 잔소리 대신 코미디 사고로 가르친다.

## 채점과 데이터
- 현재 프로토에서 스케줄링 위반은 승진 게이지(공적)에 반영되지 않고 아침 보고서 연출로만 돌아온다 (본편에서는 평가 하락 예정).
- 콘텐츠는 전부 외부 JSON: 슬롯(라벨·경고·태그)과 후보(힌트·통화 대사·필수/금지 태그·사고 문구) — 코드 수정 없이 확장 가능.

## 설계 의도 요약
① 하루 안에서 업무 종류를 바꿔 리듬을 만든다 (간파 → 배치 퍼즐) ② 통화 말풍선 = 세계관 코미디의 전달 채널 ③ "막지 않고 나중에 청구"로 판단 책임의 무게를 학습 ④ 3일 구조의 지연 사고 시스템 예습.

# 3. 1차 면접 단계 (Day 2)

## 게임 내 위치와 해금 조건
Day 1에서 성과를 내면 — 퇴근 결산의 공적 게이지가 100에 도달하면 — **승진해서 Day 2부터 1차 면접관**이 된다. 미달이면 Day 1을 새 서류들로 재도전한다(케이스 풀에서 새로 뽑힘). 승진 공문: *"금일부로 귀하를 1차 면접관에 임명함. 서류 요약은 스켈레톤 인턴이 작성함. 진술과 서류의 어긋남을 잡아낼 것."*

## 화면 구성
- **지원 몬스터가 책상 너머에 실제로 등장한다** (마법 버스트와 함께 나타나 인사말을 건넴 — 서류 단계와의 가장 큰 차이: 상대가 눈앞에 있다). 현재는 종족색 그레이박스, 복셀풍 로우폴리 모델로 교체 예정.
- 책상에는 인턴이 쓴 **서류 요약**(양피지 템플릿, 이력 2줄 — 서류 단계보다 정보가 적다)과 공문.
- 화면 하단에 **질문 카드 4장이 손패**로 서 있다: 기본 질문 ★ / 근무 조건 ★ / 지원 동기 ★ / 함정 질문 ★★ (함정 질문: "용사님께서 오시면 어떻게 모실 건가요?" — '용사님'이라는 존칭에 어떻게 반응하는지 보는 것).

## 코어 루프 (한 명당)
1. **질문 = 카드 던지기**: 손패의 카드를 잡아 몬스터에게 끌어 던지면 카드가 날아가 마법으로 흡수되며 질문 발동. **면접당 질문 포인트 3** — ★ 비용만큼 소모, 최대 3번. "이 지원자에겐 뭘 물을까"가 자원 퍼즐.
2. **답변 = 새 단서**: 답변이 화면 자막으로 나오고 — 반응 지시문(*"(손바닥에 적은 대본을 훔쳐본다)"*)이 붙으면 몬스터가 움찔한다 — 동시에 **서류의 '진술 기록' 칸에 답변이 줄로 쌓인다. 이 줄도 좌/우클릭 V/X 마킹 대상.** 서류(문서) ↔ 진술(답변) ↔ 반응(지시문)의 **단서 삼각형**을 대조해 거짓을 간파한다.
3. **판정**: 근거 최소 1개 마킹 후 합격/불합격 도장. 몬스터가 판정에 반응하고(합격 = 신나서 들썩 / 탈락 = 움찔) 마법으로 퇴장.
4. 4명을 마치면 퇴근 결산 — 서류 단계와 같은 건별 정답 공개 + 공적 게이지.

## 콘텐츠 설계
- 면접 풀 **16명 중 매판 4명** (재도전 시 새 얼굴, 첫 판 첫 슬롯은 함정 질문의 교과서적 통과 사례인 오크 '끄르렁' 고정 — 함정 카드 튜토리얼).
- **결정타가 카드 4종에 분산** — 어떤 지원자는 근무 조건에서, 어떤 지원자는 지원 동기에서 결정적 단서가 나온다. 카드 선택이 실제로 유의미하도록. 단 **전원 서류에도 결정타 병행** — 카드를 엉뚱하게 써도 서류를 꼼꼼히 읽으면 풀 수 있다. 카드는 지름길이지 유일한 열쇠가 아니다.
- 예시 (임프 '밀크티' — 선함 은폐형): 서류엔 "마을 우물에 저주를 걸었다"는 악행 경력, 확인 메모엔 "저주 이후 물맛이 좋아져 마을 명물이 됨". 지원 동기를 물으면 — *"악당이 되면 다들 나를 무서워하겠지. 그럼… 친구는 언제 생기지?" (꼬리가 축 처진다)* — 악당인 척하는 착한 임프. 탈락이 정답.

## 물성 디테일
카드 던지기는 도장 찍기와 같은 "잡고-던지기" 문법이고, 책상 위 소품(해골·머그)을 집어 몬스터에게 던지면 **맞고 튕기며 움찔한다** — 판정과 무관한 순수 코미디 물성.

## 설계 의도 요약
① 서류 단계의 "읽기 간파"에 **심문이라는 능동적 정보 획득**을 얹는다 — 정보를 사서 모으는 구조 ② 질문 포인트 제한 = 무엇을 모를지 선택하는 긴장 ③ 반응 지시문 = 비언어 단서의 저비용 구현 ④ 답변도 마킹 대상 — 서류 단계에서 배운 문법(V/X)이 그대로 확장된다.
