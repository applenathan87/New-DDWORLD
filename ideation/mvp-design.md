# 마왕성 인사팀 — MVP 기획 v0.2

> 상태: **Draft** (2026-07-03, Day 2) · 부모 문서: [concept-demon-hr.md](concept-demon-hr.md)
> 성격: ideation 단계 MVP 전체 기획. 검증 통과 후 `design/gdd/`로 승격.
> 확정 반영: 가제 "마왕성 인사팀" / 판단 = JD 적합 합·불 (직무 배치 아님) / 오판 대가 = 하루 결산 + 지연 사고 / 압박 = 질문 횟수 제한 / **승진 트리거 = 성과** / **진행 = 가젯(검증 도구) 해금** / 반전 룰 = **Day별 지침 변주**.

---

## 1. MVP 정의와 목표

- **MVP = 15~20분 수직 슬라이스.** 공모전 데모(2027-04)의 뼈대.
- **이 게임의 재미 정의 (컨셉 확정): ① 가젯·기믹으로 업무 스코프가 늘어나는 것 + ② 세상을 한번 꼬아서 보는 것(판단축 반전).**
- 검증할 것 세 가지:
  1. **후크가 서는가** — "악당을 뽑는다 → 판단축이 비틀린다"가 플레이 3건 안에 체감되는가
  2. **물성이 손맛인가** — 도장 쾅이 계속 찍고 싶은 감각인가
  3. **가젯 진행이 견인하는가** — 새 도구를 받았을 때 "다음 승진엔 뭘 주지?"가 궁금한가
- 성공 판정 = 후크 3판정(본인이 사랑함 / 솔로 스코프 / 남이 "오?") 재통과 + §12 플레이테스트 기준.

## 3. 진행 구조 — 3일 + 승진 1회 ⭐

**핵심 설계 1: 승진 = 업무 범위의 확장·교체 + 새 가젯 지급.** (Papers, Please·Quarantine Zone 계보 — day가 갈수록 검증 도구와 판단 작업이 늘어남)
**핵심 설계 2: "매일 새 도구 하나" 리듬** — Day 1 촛불 → Day 2 질문 카드 → Day 3 돋보기.

### Day 1 — 수습: 서류 심사 (도구: 촛불)
- **이력서만 보고** 서류통과/탈락 도장. 면접 없음. 통과 도장 = "면접 안내 부엉이 발송" 연출.
- **촛불 가젯**: 이력서를 촛불에 비춰 위조 인장·지워진 글씨 검사 (Day 1부터 가젯 재미 시작).
- 역할: 물건 다루기 튜토리얼 + **판단축 반전 학습** (예: "추천서가 너무 훈훈함 → 탈락 사유").
- 물량: 6~8건 (건당 60~90초). ~~공문 지침: "내일 면접 인원 최소 N명 확보"~~ → **쿼터 폐지 (2026-07-04, 프로토 플레이 후 결정)** — 클리어 기준은 정확도(승진 판정)만. 압박·가드레일 역할은 결산 채점과 지연 사고가 수행.

### Day 1 후반 — 면접 일정 잡기 (전화 스케줄링 퍼즐, 2026-07-04 추가)

- **사진 카드를 수정구(마왕성의 전화)로 통화 → 제약을 듣고 → 캘린더 슬롯에 드래그 부착 → 도장으로 확정.**
- 제약 3층: 지원자 제약(뱀파이어=밤만, 슬라임=비 불가…) / 슬롯 제약(비 예보·보름달) / (심화) 상호 제약. 정보의 진짜 출처 = **통화**(코미디 전달 채널), 이력서 힌트는 일부만.
- **위반 배치도 확정 가능** — 대가 = 다음날 아침 사고 보고서 ("낮 면접의 뱀파이어 님은 재가 되셨습니다"). 지연 사고 시스템과 정합.
- ⭐ **단계 비연결 원칙 (2026-07-04 확정)**: 서류에서 내가 통과시킨 특정 인물이 스케줄링·면접에 그대로 나오지 않는다. **각 단계 = 독립 지원자 세트의 자기완결 퍼즐** (픽션: "심사한 서류는 다른 팀 면접으로 배정"). 이유: 인물 연결 시 단서 네트워크 저작 비용 폭증 + 향후 **몇십 명 풀에서 랜덤 추첨**하는 리플레이 구조와 충돌.

### Day 1 퇴근 → 승진 심사 (성과 트리거)
- **성과 조건**: Day 1 판정 정확도 기준 통과 (예: 8건 중 6건) → 승진. 미달 시 "수습 연장" — Day 1 재도전 (데모에선 기준 낮게).
- 승진 연출: "서류 심사는 이제 스켈레톤 인턴이 합니다" — **이전 업무가 아랫사람에게 넘어가는 것**을 명시. 커리어 판타지의 씨앗.

### Day 2 — 1차 면접관 (도구: 질문 카드)
- 질문 카드 심문 개방 (기본 4종). 4~5명.
- JD 지침 예시: "던전 경비 채용 — 겁 없는 자" (평범한 축의 날 — 기준선 학습).

### Day 3 — 1차 면접 심화 (도구: 돋보기) — **데모 클라이맥스**
- **돋보기 가젯 해금**: 직전 답변에 대면 거짓 신호 판독 (면접당 1회).
- **특별 지침 = "사기 부서(보이스피싱단) 대량 채용 — 거짓말에 능한 자를 보내라."** ← 반전 룰의 Day별 변주. **돋보기를 댔는데 거짓말이 안 나오면 탈락** — 거짓말 탐지기가 채용 도구로 뒤집히는 순간이 데모 최대의 "오?".
- **용사 측 스파이 1명** 잠입 — "거짓말 잘함 = 합격인 날"에 진짜 위험한 거짓말쟁이를 걸러야 하는 **이중 반전**.
- 카드 1종 해금(교차 검증). 4~5명. Day 3 퇴근 = 데모 엔딩: 최종 등급(S~D) + "2차 면접관 승진" 예고 컷 (비전 티저).

### 퇴근 장면 (매일, 초경량)
- 결산을 "퇴근" 프레임으로: 촛불 끄기(물성 한 번) → **신문 1면**(지연 사고·놓친 인재 기사 = 세계관 엿보기) + 인턴/동료 대사 1~2줄 → 다음날 출근.
- 미니게임·탐사 없음 — 본격 나이트 페이즈는 본편 과제 (§15). 데모는 지루함 방지 + 세계관 엿보기의 씨앗만.

## 4. 코어 루프 상세

### 4a. 서류 심사 루프 (Day 1, 건당 60~90초)
1. 인턴이 서류를 책상에 놓음
2. 이력서 집어 검토 ↔ 서랍의 JD 공문과 대조 (+의심되면 촛불 검사)
3. 도장: **서류통과 / 탈락**

### 4b. 면접 루프 (Day 2~3, 건당 2~4분)
1. 지원자 입장 — 외형·태도 첫인상 (비언어 단서 시작)
2. 서류 재검토 — 진술과 대조할 기준선
3. **심문**: 질문 카드 선택 → 답변 + 반응 연출 (질문 포인트 제한, §7) (+Day 3: 돋보기 1회)
4. 도장: **합격 / 불합격**

### 4c. 하루 루프 (5~7분)
출근 → 서랍에서 오늘의 공문 확인 (JD·수배 전단·특별 지침) → 심사/면접 N건 → **퇴근** (결산 + 신문 + 동료 한 컷)

## 5. 판단 시스템 — "JD 적합" 판정 + Day별 축 변주

잡오프닝 = JD(요구 자질 명세)가 이미 있고, 지원자는 거기에 지원한다. 플레이어는 배치하지 않는다 — **"이 JD에 진짜 맞는 놈인가"만 판단한다.**

- **JD** = 요구 자질 + 결격 자질. 예: `고문 기술자 — 요구: 잔인함·꼼꼼함 / 결격: 공감능력`
- **지원자** = 실제 자질(숨김) + 주장 자질(서류·진술로 표현)
- **플레이어의 실력** = 주장↔실제의 간극을 간파해 실제 자질을 JD와 대조하는 것
- **정답 룰**: 실제 자질이 JD를 충족하면 합격이 정답.
- **⭐ 반전은 전역 룰이 아니라 Day별 지침의 변주다.** 그날의 채용 지침(JD)이 "무엇이 자질인가"를 매번 다르게 비튼다:
  - 사기 부서의 날 → **거짓말 능숙 = 핵심 요구 자질** ("거짓말 잘하는 녀석들로 보내줘")
  - 경리부의 날 → 거짓말 = 결격 (횡령 위험)
  - 훈훈한 추천서 → 대부분의 마왕성 JD에선 위험 신호
- → **매일 상식 축이 다르게 꼬인다 = 변주 엔진이자 리플레이 엔진.** "세상을 꼬아서 본다"의 기계적 구현.

## 6. 거짓말·단서 시스템

**단서 삼각형: 서류 ↔ 진술 ↔ 반응(비언어).** 두 꼭짓점이 어긋나면 거짓 신호.

### ⭐ 단서 마킹 = 깃펜 방향 마킹 (근거 시스템 — 2026-07-04 추가, 07-04 방향(V/X)으로 격상)

**"읽기"를 "해석 커밋"으로 바꾸는 핵심 인터랙션.** 이력서 줄·특이사항·(면접) 답변 = 전부 깃펜으로 마킹 가능한 단서.
- **좌클릭 = V (합격 신호) / 우클릭 = X (탈락 신호).** 중립 마킹("이 줄이 근거다")에서 **방향 커밋("이 줄은 합격/탈락 근거다")**으로 격상 — 판단축 반전 게임에서 같은 사실이 직무 따라 V도 X도 되므로, **방향이야말로 반전 축을 읽었는지의 증거.**
- 근거 메모 패드에 V/X와 함께 수집. **근거 최소 1개 없이는 도장을 못 찍는다.**
- 결산 3단 채점: "근거·방향 적중" / **"단서는 짚었지만 방향을 반대로 읽었다 — 여긴 마왕성이다"** (반전 오독, 최고의 학습 모먼트) / "결정적 단서는 따로 있었다".
- **깃펜 = 마킹의 물성 도구**: 종이를 들면 손 위치로 날아와 대기, 마킹마다 사각 긋는 연출. 잡기 강제는 안 함(마찰 방지).
- **평가 체크리스트 = 면접 단계 도구 (결정, 2026-07-04)**: 항목(조직/태도·직무/기술·적합성·충성도)은 심문 후 종합 판단용 → 면접 답변이 쌓일 때 진가. **면접관 승진 보상 가젯으로 지급** ("승진 = 새 도구" 축 정합). 좌/우클릭 V/X 문법 동일.
- 가젯과 연결: 촛불 = 숨은 단서 줄을 드러냄 / 돋보기 = 답변의 거짓 판독(방향 힌트).
- 열린 노브: ① 최소 1개 강제 유지 여부 ② 근거·방향 적중의 평가(승진/등급) 반영 비중 — 프로토 플레이 후 결정.

거짓 유형 4종 (코미디 엔진과 1:1 매핑):
1. **악행 뻥튀기** — "애기 사탕 뺏음"을 "대기근 주도"로 부풀림 (간파 시 웃김)
2. **선함 은폐** — 착한데 악한 척, 어설프게 들통 (간파 시 웃김 + 탈락의 죄책감)
3. **경력 위조** — 스펙 거짓 (서류 대조·촛불 검사로 적발)
4. **위장 잠입** — 용사 측 스파이 (함정 질문·돋보기로만 간파, Day 3 한정)

반응 연출은 저비용 우선: 땀 이펙트, 시선 회피, 텍스트 지시문("…목소리가 떨린다"), 말줄임표. 복셀 애니메이션은 **긴장/안도 2종만**.

### 검증 가젯 — 승진 진행의 물리적 축 ⭐

승진할 때마다 책상에 도구가 하나씩 늘어난다. **판단 작업의 종류가 눈에 보이게 확장**되는 것이 커리어 진행의 체감.

| 가젯 | 기능 | 해금 | 제한 |
|---|---|---|---|
| **촛불** | 이력서를 비춰 위조 인장·지워진 글씨 검사 | Day 1 (기본) | 없음 (시간만 소모) |
| **돋보기** | 직전 답변의 거짓 신호 판독 (참/거짓만) | Day 3 (승진 보상) | **면접당 1회** |

- **돋보기가 추리를 대체하지 않는 이유**: 거짓 여부만 알려주고 "그래서 합격인가"는 안 알려준다. 판단축 반전 덕에 **거짓말 = 탈락이 아니므로**, 탐지기가 정답기가 되지 않는다. (이 시너지가 Quarantine Zone식 기기를 우리 게임에 안전하게 이식하는 근거)
- 비전: 승진마다 가젯 추가 — 진실의 수정구, 계약 낙인, 급여 대장, 해고 통지서… (post-MVP)

## 7. 질문 카드

- **기본 4종** (Day 2 개방, 목업 승계): 기본 질문 ★ / 근무 조건 ★ / 지원 동기 ★ / 함정 질문 ★★
- **해금 1종** (Day 3): 교차 검증 ★★ (서류 특이사항 하나를 캐물음) — *압박 질문은 post-MVP로 이동 (Day 3 학습량 조절: 돋보기가 들어오므로)*
- **면접당 질문 포인트 3** (★=1, ★★=2) → "이 지원자에겐 뭘 물을까"가 자원 퍼즐.
- 카드 해금 = 성장·언락 쾌감의 최소 구현 (덱빌딩 확장의 씨앗).

## 8. 오판의 대가 — 퇴근 결산 + 지연 사고

- **퇴근 결산**: 판정 일부만 즉시 공개 (명백 건은 확인, 애매 건은 "두고 봐야…" → 긴장 유지)
- **지연 사고**: 오채용 → 1~2일 뒤 아침 **"사건 보고서"** (예: "채용하신 회계 고블린이 금고를 돌려깠습니다") → 평가 하락
- **오거절도 대가**: 놓친 인재가 경쟁 던전에 취업한 **신문 기사** (코미디 + 양쪽 오판 모두 아픔 + 세계관 엿보기)
- 누적 평가 → 승진 심사(§3) + 데모 최종 등급 S~D. 리플레이 동기.

### 10a. 콘텐츠 구조 — 날짜별 풀 + 셔플백 (확정 2026-07-04)

**요구사항의 핵심: 게임오버(승진 미달) 재도전 시 똑같은 문제를 다시 풀게 하지 않는다.** 이 게임의 재미는 간파인데, 간파는 답을 아는 순간 죽는다 — Papers, Please의 '서류 대조 작업'과 달리 재작업 가치가 없으므로 재도전 변주는 필수.

**확정 구조:**
- **날짜별 케이스 풀**: 각 케이스에 소속 풀 태그(day1/day2/day3). 날짜별 풀 = 난이도 커브 그 자체 (day1 풀 = 쉬움·튜토리얼성, day3 풀 = 이중반전급).
- **회차 시작 시 풀에서 N건 뽑기 + 순서 셔플.** 재도전 시 **미출현 케이스 우선**(셔플백) — 풀 소진 시에만 본 케이스 재등장.
- **고정 슬롯 공존**: 스토리성 인물·핵심 반전 케이스는 날짜/위치를 저작 (풀과 별개 층). Day 1 지원자가 Day 3에 반드시 등장할 필요는 없음 — 다만 겹쳐도 되는 케이스는 **인접 날짜 풀에 중복 태그 허용** (콘텐츠 비용 완화).
- **뽑기 제약**: 정답 PASS 최소 수 보장(쿼터 성립성 — 랜덤이 퍼즐을 못 깨게), 그날 활성 JD와 매칭, 시드 저장(버그 재현·리플레이 검증).
- **풀 크기 가늠**: 등장 N건당 풀 ≥ N×1.5 (재도전 1회에 절반 이상 새 얼굴).
- ~~적용 시점 = S3부터~~ → **프로토 선적용 완료 (2026-07-04, S2c 빌드)**: 17건 풀 → 매 판 7건 뽑기, 물컹이 첫 슬롯 고정(미출현일 때만). 단독 테스터 단계라 회차 변주를 우선함 — 외부 테스터에게 동일 경험이 필요해지면 시드 고정으로 해결.

## 15. 열린 질문 (다음 결정)

1. **함정 질문의 실패 비용** — 스파이가 아닌 지원자에게 쓰면? (기분 상해 퇴장 = 판단 기회 상실?)
2. ~~지원자 구성~~ → **구조 확정 (2026-07-04): 날짜별 풀 + 셔플백 (§10a).** 프로토 S2까지는 고정 세트, S3부터 풀 적용.
3. **돋보기 제한 튜닝** — 면접당 1회 vs 하루 N회 충전식?
4. **승진 미달 처리** — Day 1 재도전 vs 기준 완화 vs 연출만 다르게? (데모 플레이테스트에서 결정)
5. **퇴근 장면 확정** — 초경량(신문+대사)으로 채택했는데, 본격 나이트 페이즈(미니게임·성 내부 탐사)는 본편 과제로 미룸. 이 선긋기 확인 필요.
6. **[목업 2차 발, 2026-07-04] 보류 도장** — 판정을 2택(통과/탈락)에서 3택(채용/보류/탈락)으로? 보류의 비용·해소 규칙이 필요 (없으면 전부 보류하는 도피처가 됨).
7. **[목업 2차 발] 예상 평가 스탯 패널** (총성도/업무능력/비용/사고위험) — 간파를 숫자로 보여줄 것인가? 숫자가 정답을 누설하면 간파 재미가 죽을 위험 vs 판단 재료가 풍부해지는 이득.
8. ~~[목업 2차 발] 평가 체크리스트~~ → **결정 (2026-07-04): 면접 단계 도구로 채택, 면접관 승진 보상 가젯으로 지급** (§6). 사무실 사기 보너스는 비전 유지.
9. **드래그 재배치 유지 여부** — 플레이테스트에서 실제로 쓰는지 관찰 후 결정 (안 쓰면 제거가 답).
10. **근거 마킹 노브** (§6) — 최소 1개 강제 유지? → 프로토 플레이 후. ~~근거 적중을 승진 평가에 반영?~~ → **부분 결정 (2026-07-04): 반영함** — 공적 공식(정확 ×2 + 근거 적중 ×1)으로 승진 게이지에 포함 (#13 선반영).
11. **[보류 — 고민 후 결정, 2026-07-04] 공문/JD 로테이션**: 정답을 케이스 단독이 아니라 **(케이스 × 그날 공문)**으로 정의하는 안. 같은 지원자가 공문에 따라 합/불이 뒤집혀 재도전 변주·콘텐츠 재사용이 배가됨 (§5 "Day별 지침 변주"의 기계적 확장). 비용 = `correct`/`reveal`을 JD별 다중 정의로 스키마 전면 변경 + 케이스당 해설 다중 저작. ⚠️ **S3 스키마 설계 착수 전까지 결정** — 나중에 붙이면 콘텐츠 전면 재작성.
12. ~~케이스 저작 도구~~ → **방향 확정 (2026-07-04): 시트로 간다.** 도구는 구글 시트 유력(엑셀 없음 — Numbers/Notion DB 대안), 시점 = 케이스 20건+ 도달 시 변환 파이프라인 구축. 그 전까지는 Claude 자연어 서술 → JSON 반영 유지.
13. **보상 경제 — 방향 확정 (2026-07-04), 상세·구현 = S3.** 3축 구조:
    - **공적(인사평가 점수)** = 경험치 역할의 **누적 승진 게이지**. 매일 결산에서 획득(정확도·근거 적중·무사고) → 차면 승진 심사. 표기는 다이어제틱("인사기록 카드에 공적 +N") — EXP 표기 금지. 인사팀 직원인 플레이어 본인도 평가받는 아이러니가 세계관.
    - **직급** = 레벨 (유한 사다리: 수습→서류심사관→1차 면접관→…). 승진 = 업무·가젯 확장 (기존 §3 그대로).
    - **골드** = 소비 자원. 싱크 후보 4종: **뇌물 승진**(공적 부족분을 골드로 메꿈 — 실력 구제책 + 마왕성다움) / 가젯·책상 업그레이드 / 퇴근 유흥(나이트 페이즈 씨앗) / 사고 청구서·벌금(픽션 이미 존재 — "수리비 300G"). 수당 공식 스케치: 기본급 + 정확도 보너스 − 사고 청구서.
    - **원칙**: ① 싱크 없는 화폐 선지급 금지 — 싱크 최소 1개와 동시 도입 ② XP 별도 축 없음(공적이 곧 게이지) ③ 반복 견인의 1차 동력 = 케이스 신선도, 게이지는 빌드업 보조 (골드 때문에 반복하면 코어 경고 신호) ④ 결산의 게이지 차오르는 연출에 투자.
    - **페이싱**: 본편 승진 = 여러 날 누적. 현 데모의 "Day 1 성과 즉시 승진"은 압축 페이싱 한정임을 명시.
    - **프로토 선반영 (2026-07-04)**: 결산에 **공적 게이지** 구현 — 0→100 차오르는 바 + 중앙 카운터("N / 100") 동기 연출, 만땅 순간 번쩍+샤라랑(승진), 미달이면 멈춤. **승진 판정을 공적 100 도달로 전환** (원점수 = 정확 ×2 + 근거 적중 ×1, 기준 = `days[].meritGoal` — 정답 수 기준 promoteMin 대체). 저장·누적은 없음 — 골드·누적·뇌물은 S3까지 구현 금지.
