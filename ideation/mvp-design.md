# 마왕성 인사팀 — MVP 기획 v0.2

> 상태: **Draft** (2026-07-03, Day 2) · 부모 문서: [concept-demon-hr.md](concept-demon-hr.md)
> 성격: ideation 단계 MVP 전체 기획. 검증 통과 후 `design/gdd/`로 승격.
> 확정 반영: 가제 "마왕성 인사팀" / 판단 = JD 적합 합·불 (직무 배치 아님) / 오판 대가 = 하루 결산 + 지연 사고 / 압박 = 질문 횟수 제한 / **승진 트리거 = 성과** / **진행 = 가젯(검증 도구) 해금** / 반전 룰 = **Day별 지침 변주**.

---

## 1. MVP 정의와 목표

- **MVP = 15~20분 수직 슬라이스.** 공모전 데모(2027-04)의 뼈대.
- **이 게임의 재미 정의 (컨셉 확정): ① 가젯·기믹으로 업무 스코프가 늘어나는 것 + ② 세상을 한번 꼬아서 보는 것(판단축 반전).**
- 검증할 것 세 가지:
  1. **후크가 서는가** — "악당을 뽑는다 → 판단축이 비틀린다"가 플레이 3건 안에 체감되는가
  2. **물성이 손맛인가** — 도장 쾅이 계속 찍고 싶은 감각인가
  3. **가젯 진행이 견인하는가** — 새 도구를 받았을 때 "다음 승진엔 뭘 주지?"가 궁금한가
- 성공 판정 = 후크 3판정(본인이 사랑함 / 솔로 스코프 / 남이 "오?") 재통과 + §12 플레이테스트 기준.

## 2. 스코프 (방파제)

| IN (MVP) | OUT (비전 — 넣지 않음) |
|---|---|
| 서류 심사 업무 (Day 1) | 2차·최종 면접 |
| 1차 면접 업무 (Day 2~3) | HR 확장 업무 (중재·면담·연봉협상·해고·승진 심사) |
| 질문 카드 심문 + 질문 포인트 제한 | 직무 배치 (판단은 JD 적합 합·불만) |
| **승진 1회 (성과 트리거)** = 업무 교체 + 가젯 지급 | 예산·사무실 사기 시스템 (HUD 표시도 생략) |
| **가젯 2종: 촛불(Day 1) · 돋보기(Day 3 해금)** | 경비 버튼 / 험악 면접 리스크 층 |
| 도장 판단 + 퇴근 결산 + 지연 사고 | **본격 나이트 페이즈** (퇴근 미니게임·탐사) |
| **초경량 퇴근 장면** (신문 1면 + 동료 대사 1~2줄) | Day 간 지원자 인과 연결 · 스토리 NPC (본편 과제) |
| 물성 6종: 도장·이력서·카드·서랍·촛불·돋보기 | 사내정치 축 ("너무 유능함 → 상사 위협") |

## 3. 진행 구조 — 3일 + 승진 1회 ⭐

**핵심 설계 1: 승진 = 업무 범위의 확장·교체 + 새 가젯 지급.** (Papers, Please·Quarantine Zone 계보 — day가 갈수록 검증 도구와 판단 작업이 늘어남)
**핵심 설계 2: "매일 새 도구 하나" 리듬** — Day 1 촛불 → Day 2 질문 카드 → Day 3 돋보기.

### Day 1 — 수습: 서류 심사 (도구: 촛불)
- **이력서만 보고** 서류통과/탈락 도장. 면접 없음. 통과 도장 = "면접 안내 부엉이 발송" 연출.
- **촛불 가젯**: 이력서를 촛불에 비춰 위조 인장·지워진 글씨 검사 (Day 1부터 가젯 재미 시작).
- 역할: 물건 다루기 튜토리얼 + **판단축 반전 학습** (예: "추천서가 너무 훈훈함 → 탈락 사유").
- 물량: 6~8건 (건당 60~90초). 공문 지침: "내일 면접 인원 최소 N명 확보" (전원 탈락 방지 가드레일 겸 압박).

### Day 1 퇴근 → 승진 심사 (성과 트리거)
- **성과 조건**: Day 1 판정 정확도 기준 통과 (예: 8건 중 6건) → 승진. 미달 시 "수습 연장" — Day 1 재도전 (데모에선 기준 낮게).
- 승진 연출: "서류 심사는 이제 스켈레톤 인턴이 합니다" — **이전 업무가 아랫사람에게 넘어가는 것**을 명시. 커리어 판타지의 씨앗.

### Day 2 — 1차 면접관 (도구: 질문 카드)
- 질문 카드 심문 개방 (기본 4종). 4~5명.
- JD 지침 예시: "던전 경비 채용 — 겁 없는 자" (평범한 축의 날 — 기준선 학습).

### Day 3 — 1차 면접 심화 (도구: 돋보기) — **데모 클라이맥스**
- **돋보기 가젯 해금**: 직전 답변에 대면 거짓 신호 판독 (면접당 1회).
- **특별 지침 = "사기 부서(보이스피싱단) 대량 채용 — 거짓말에 능한 자를 보내라."** ← 반전 룰의 Day별 변주. **돋보기를 댔는데 거짓말이 안 나오면 탈락** — 거짓말 탐지기가 채용 도구로 뒤집히는 순간이 데모 최대의 "오?".
- **용사 측 스파이 1명** 잠입 — "거짓말 잘함 = 합격인 날"에 진짜 위험한 거짓말쟁이를 걸러야 하는 **이중 반전**.
- 카드 1종 해금(교차 검증). 4~5명. Day 3 퇴근 = 데모 엔딩: 최종 등급(S~D) + "2차 면접관 승진" 예고 컷 (비전 티저).

### 퇴근 장면 (매일, 초경량)
- 결산을 "퇴근" 프레임으로: 촛불 끄기(물성 한 번) → **신문 1면**(지연 사고·놓친 인재 기사 = 세계관 엿보기) + 인턴/동료 대사 1~2줄 → 다음날 출근.
- 미니게임·탐사 없음 — 본격 나이트 페이즈는 본편 과제 (§15). 데모는 지루함 방지 + 세계관 엿보기의 씨앗만.

## 4. 코어 루프 상세

### 4a. 서류 심사 루프 (Day 1, 건당 60~90초)
1. 인턴이 서류를 책상에 놓음
2. 이력서 집어 검토 ↔ 서랍의 JD 공문과 대조 (+의심되면 촛불 검사)
3. 도장: **서류통과 / 탈락**

### 4b. 면접 루프 (Day 2~3, 건당 2~4분)
1. 지원자 입장 — 외형·태도 첫인상 (비언어 단서 시작)
2. 서류 재검토 — 진술과 대조할 기준선
3. **심문**: 질문 카드 선택 → 답변 + 반응 연출 (질문 포인트 제한, §7) (+Day 3: 돋보기 1회)
4. 도장: **합격 / 불합격**

### 4c. 하루 루프 (5~7분)
출근 → 서랍에서 오늘의 공문 확인 (JD·수배 전단·특별 지침) → 심사/면접 N건 → **퇴근** (결산 + 신문 + 동료 한 컷)

## 5. 판단 시스템 — "JD 적합" 판정 + Day별 축 변주

잡오프닝 = JD(요구 자질 명세)가 이미 있고, 지원자는 거기에 지원한다. 플레이어는 배치하지 않는다 — **"이 JD에 진짜 맞는 놈인가"만 판단한다.**

- **JD** = 요구 자질 + 결격 자질. 예: `고문 기술자 — 요구: 잔인함·꼼꼼함 / 결격: 공감능력`
- **지원자** = 실제 자질(숨김) + 주장 자질(서류·진술로 표현)
- **플레이어의 실력** = 주장↔실제의 간극을 간파해 실제 자질을 JD와 대조하는 것
- **정답 룰**: 실제 자질이 JD를 충족하면 합격이 정답.
- **⭐ 반전은 전역 룰이 아니라 Day별 지침의 변주다.** 그날의 채용 지침(JD)이 "무엇이 자질인가"를 매번 다르게 비튼다:
  - 사기 부서의 날 → **거짓말 능숙 = 핵심 요구 자질** ("거짓말 잘하는 녀석들로 보내줘")
  - 경리부의 날 → 거짓말 = 결격 (횡령 위험)
  - 훈훈한 추천서 → 대부분의 마왕성 JD에선 위험 신호
- → **매일 상식 축이 다르게 꼬인다 = 변주 엔진이자 리플레이 엔진.** "세상을 꼬아서 본다"의 기계적 구현.

## 6. 거짓말·단서 시스템

**단서 삼각형: 서류 ↔ 진술 ↔ 반응(비언어).** 두 꼭짓점이 어긋나면 거짓 신호.

거짓 유형 4종 (코미디 엔진과 1:1 매핑):
1. **악행 뻥튀기** — "애기 사탕 뺏음"을 "대기근 주도"로 부풀림 (간파 시 웃김)
2. **선함 은폐** — 착한데 악한 척, 어설프게 들통 (간파 시 웃김 + 탈락의 죄책감)
3. **경력 위조** — 스펙 거짓 (서류 대조·촛불 검사로 적발)
4. **위장 잠입** — 용사 측 스파이 (함정 질문·돋보기로만 간파, Day 3 한정)

반응 연출은 저비용 우선: 땀 이펙트, 시선 회피, 텍스트 지시문("…목소리가 떨린다"), 말줄임표. 복셀 애니메이션은 **긴장/안도 2종만**.

### 검증 가젯 — 승진 진행의 물리적 축 ⭐

승진할 때마다 책상에 도구가 하나씩 늘어난다. **판단 작업의 종류가 눈에 보이게 확장**되는 것이 커리어 진행의 체감.

| 가젯 | 기능 | 해금 | 제한 |
|---|---|---|---|
| **촛불** | 이력서를 비춰 위조 인장·지워진 글씨 검사 | Day 1 (기본) | 없음 (시간만 소모) |
| **돋보기** | 직전 답변의 거짓 신호 판독 (참/거짓만) | Day 3 (승진 보상) | **면접당 1회** |

- **돋보기가 추리를 대체하지 않는 이유**: 거짓 여부만 알려주고 "그래서 합격인가"는 안 알려준다. 판단축 반전 덕에 **거짓말 = 탈락이 아니므로**, 탐지기가 정답기가 되지 않는다. (이 시너지가 Quarantine Zone식 기기를 우리 게임에 안전하게 이식하는 근거)
- 비전: 승진마다 가젯 추가 — 진실의 수정구, 계약 낙인, 급여 대장, 해고 통지서… (post-MVP)

## 7. 질문 카드

- **기본 4종** (Day 2 개방, 목업 승계): 기본 질문 ★ / 근무 조건 ★ / 지원 동기 ★ / 함정 질문 ★★
- **해금 1종** (Day 3): 교차 검증 ★★ (서류 특이사항 하나를 캐물음) — *압박 질문은 post-MVP로 이동 (Day 3 학습량 조절: 돋보기가 들어오므로)*
- **면접당 질문 포인트 3** (★=1, ★★=2) → "이 지원자에겐 뭘 물을까"가 자원 퍼즐.
- 카드 해금 = 성장·언락 쾌감의 최소 구현 (덱빌딩 확장의 씨앗).

## 8. 오판의 대가 — 퇴근 결산 + 지연 사고

- **퇴근 결산**: 판정 일부만 즉시 공개 (명백 건은 확인, 애매 건은 "두고 봐야…" → 긴장 유지)
- **지연 사고**: 오채용 → 1~2일 뒤 아침 **"사건 보고서"** (예: "채용하신 회계 고블린이 금고를 돌려깠습니다") → 평가 하락
- **오거절도 대가**: 놓친 인재가 경쟁 던전에 취업한 **신문 기사** (코미디 + 양쪽 오판 모두 아픔 + 세계관 엿보기)
- 누적 평가 → 승진 심사(§3) + 데모 최종 등급 S~D. 리플레이 동기.

## 9. 물성 (다이어제틱 데스크) — MVP 확정 6종

| 오브젝트 | 동작 | 우선순위 |
|---|---|---|
| **도장** | 드래그 → 쾅. 잉크 자국 + 진동 + 소리 | **1 (필수, 폴리시 최우선)** |
| **이력서** | 집어 들여다보기 | 2 |
| **질문 카드** | 부채꼴에서 잡아 앞으로 던지면 발동 | 3 |
| **촛불** (가젯) | 이력서를 갖다 대면 숨은 표식 드러남 | 4 |
| **서랍 1칸** | JD 공문·수배 전단 (교차 대조의 물리적 거점) | 5 |
| **돋보기** (가젯) | 집어서 지원자/답변에 대면 판독 연출 | 6 |

- 서랍 vs 경비 버튼 중 **서랍 선택** — 교차 대조(진술↔서류↔지침)가 코어 플레이라서. 버튼은 드라마 층이라 post-MVP.
- 구현 순서: flat UI 그레이박스 먼저 → 물성은 도장부터 순차 적용 (Strange Horticulture 교훈: 물성의 절반은 시청각 피드백 — 소리·애니에 투자).
- **6종이 상한.** 더 늘리고 싶으면 하나를 빼고 넣는다.

## 10. 콘텐츠 분량 (솔로 스코프 검산)

- **지원자 총 14~18건**: 서류 전용 6~8 + 면접 8~10. 종족 5~6종 재사용 (고블린·슬라임·뱀파이어·오크·스켈레톤·미믹).
- **대사 매트릭스**: 면접 지원자 10 × 카드 5종 ≈ 50 답변. 지원자당 유효 단서 답변은 3~4개, 나머지는 종족 공용 템플릿으로 비용 절감.
- **정답 분포**: 명백 합격 20% / 명백 불합격 20% / 간파 필요 50% / 함정 10%.
- **JD·일일 지침 3~4종**: 일반 행정(하급) / 던전 경비 / 회계 / **사기 부서 특채 (Day 3, 반전 변주의 쇼케이스)**.
- 데이터는 전부 외부화 (ScriptableObject 또는 JSON — 하드코딩 금지 원칙 준수).

## 11. UI·컨트롤 (목업 승계)

- 고정 카메라 데스크 뷰 + 마우스 중심. `Tab` 메뉴 / `I` 지원자 정보 / `L` 업무 일지 / `ESC` 면접 종료.
- HUD는 **날짜 + 인사팀 랭크만.** 예산·사무실 사기는 비전이므로 표시도 생략 (목업의 해당 요소는 비전 프리뷰로 간주).

## 12. 검증 계획

플레이테스트 질문 4:
1. 거짓말을 간파해 뒤집었을 때 "오?" 순간이 있었나 (후크)
2. 도장이 계속 찍고 싶은가 (물성)
3. 돋보기를 받았을 때 "다음 승진엔 뭘 주지?"가 궁금했나 (가젯 견인력)
4. 다음 지원자가 궁금한가 (콘텐츠 견인력)

정량 기준:
- 15분 완주율 ≥ 80%
- 간파 필요 건의 오판율 30~50% 구간 (너무 쉽지도 어렵지도 않게)
- Day 1 종료 시점까지 판단축 반전을 설명 없이 이해 (튜토리얼 텍스트 최소)

## 15. 열린 질문 (다음 결정)

1. **함정 질문의 실패 비용** — 스파이가 아닌 지원자에게 쓰면? (기분 상해 퇴장 = 판단 기회 상실?)
2. **지원자 구성** — 고정 시나리오(서사 통제) vs 풀 추첨(리플레이성)? 데모는 고정 추천, 추첨은 본편 과제.
3. **돋보기 제한 튜닝** — 면접당 1회 vs 하루 N회 충전식?
4. **승진 미달 처리** — Day 1 재도전 vs 기준 완화 vs 연출만 다르게? (데모 플레이테스트에서 결정)
5. **퇴근 장면 확정** — 초경량(신문+대사)으로 채택했는데, 본격 나이트 페이즈(미니게임·성 내부 탐사)는 본편 과제로 미룸. 이 선긋기 확인 필요.
