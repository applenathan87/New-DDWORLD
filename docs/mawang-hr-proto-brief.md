> **역할 분담**: 코드·콘텐츠 초안 = Claude 전담 / 사용자 = 플레이 판정(손맛·"오?"·코미디 톤)·디렉션·Play+콘솔 에러 전달. 사용자의 유니티 학습(Origin)은 독립 병행 — 이 프로토에 의존하지 않음.

## 가설 (mvp-design §12)

1. **판단축 반전**이 플레이 3건 안에 "오?"를 만든다 (물컹이 = 반전 학습 설계)
2. **도장 판정**이 계속 찍고 싶은 손맛이다 (S2에서 드래그 물성으로 본검증)
3. 가젯 해금이 "다음 승진엔 뭘 주지?" 견인력을 만든다 (S3)

## 기술 규칙 (이 프로토의 5계명)

1. **부트스트랩 패턴**: 씬 = `mawanghr.unity` (Bootstrap GO 하나). UI·오브젝트 전부 코드 생성 → 인스펙터 수작업 0, 사용자는 Play만.
2. **Input System 전용 프로젝트** (`activeInputHandler: 1`) — legacy `Input.*` API 금지. UI 입력은 EventSystem(InputSystemUIInputModule) 경유만.
3. **콘텐츠 전부 JSON**: `Assets/StreamingAssets/MawangHR/gamedata.json`. 지원자·JD·일일지침 추가는 코드 수정 없이.
4. **격리**: `Assets/Scripts/MawangHR/`(네임스페이스 `MawangHR`)만 사용. 옛 프로토(`Hex/`·`CombatTest/`·`Systems/`) 참조·수정 금지.
5. **한글 폰트**: 씬이 `MonaS12 SDF`(guid c612899a…)를 Bootstrap에 주입. 깨지면 OS 폰트 폴백이 자동 작동.
