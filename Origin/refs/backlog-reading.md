# 백로그 읽기 목록 — "언젠가, 해당 단계 오면"

> 흥미롭지만 **지금 단계(1단계 보이는 공간)엔 이르거나 무관**한 자료들. 버리지 않고 모아둠.
> 각 항목에 **언제 필요한지(단계)** 를 표시. 그 단계 도달하면 꺼내볼 것.
> ⚠️ 검증: 웹 검색 기준(완독 X).

## 🔜 2단계 · 복셀/로우폴리 캐릭터 아트

- [ ] [Low Poly Game Art: An Ultimate Guide (RetroStyleGames)](https://retrostylegames.com/blog/low-poly-game-art-an-ultimate-guide/) — 실루엣·제한 팔레트·플랫 컬러.
- [ ] [The Low-Poly Revolution (Wayline)](https://www.wayline.io/blog/low-poly-revolution) — 로우폴리 감각 개관.
- [ ] [MagicaVoxel 공식 (ephtracy)](https://ephtracy.github.io/) — 우리 캐릭터 도구, 양자화/디더링 기능.

## ⏸ 4단계 · 절차적 애니메이션 (코드로 움직임)

> ⚠️ "절차적 애니메이션"(움직임) ≠ "절차적 생성"(콘텐츠 자동생성, 맨 아래).
> 참고: 우리는 애니메이션을 B방식(Blender 키프레임)으로 기울었음. 절차적은 '런' 곁가지 정도의 대안.

- [ ] [Giving Personality to Procedural Animations using Math — t3ssel8r](https://www.youtube.com/watch?v=KPoeNZZ6H4s) — 스프링/댐퍼로 움직임에 성격. 어제 'V자 흔들림' 연장선.
- [ ] [Freya Holmér — Math for Game Devs (part 10)](https://www.youtube.com/watch?v=Pku6WAs1fF8) — 흔들림·보간의 수학.

## ⏸ 5단계~ · 게임 손맛 (juice)

- [ ] [The Art of Screenshake — Vlambeer (정리)](https://www.gamedesign.gg/knowledge-base/game-design/game-feel-feedback/the-art-of-screenshake-jan-willem-nijman-vlambeer/) — 타격감·피드백. 전투 연출 붙일 때.
- [ ] [Juice it or Lose it (정리)](https://gamejuice.co.uk/resources/juice-it-or-lose-it) — 밋밋함에 juice 얹기.

## 📚 상시 · 셰이더/렌더링 심화 (필요할 때)
