# 블렌더 로우폴리 가구 제작 가이드 — 마왕성 책상 편

> 레퍼런스: 복셀풍 책상 턴어라운드 시트 (정면/좌우/후면/상단 + 보라 배너 엠블럼)
> 이 룩의 정체 = **로우폴리 박스 지오메트리 + 픽셀아트 텍스처 + Point 필터**. 트루 복셀 아님.
> 아트 방향과의 관계: 캐릭터 = MagicaVoxel / **환경·가구 = 블렌더 로우폴리** (ADR-002 갱신 기준) — 이 가이드가 그 환경 파이프라인이다.
> 작성: 2026-07-05 · Origin 학습 트랙 (4단계·M5 아트 패스 선행 학습)

---

## 0. 왜 MagicaVoxel이 아니라 블렌더인가

- 복셀 툴로 가구를 만들면 폴리곤이 낭비되고(작은 정육면체 수천 개), 픽셀 나뭇결 같은 **면 단위 텍스처 제어가 안 된다**.
- 레퍼런스의 느낌은 "큰 박스 몇 개 + 픽셀 텍스처"라서 블렌더가 정확한 도구다. 비유하면: 복셀 툴은 레고, 지금 필요한 건 **합판에 시트지 붙이기**.
- 폴리 예산 감각: 이 책상 = **500~1,500 삼각형**이면 충분 (기둥·패널 다 넣어도).

## 1. 준비 (최초 1회)

1. Blender 4.x 설치 (무료, blender.org)
2. **단위 확인**: Scene Properties(오른쪽 프린터 아이콘) → Units → Metric, 1.0 — 블렌더 1유닛 = 1m = 유니티 1유닛. 여기가 어긋나면 임포트 때마다 고생한다.
3. **게임 실측 치수** (그레이박스 DeskRig.cs 기준 — 이대로 만들면 씬에 꽂았을 때 크기가 맞는다):
   - 책상 전체: **가로 2.3m × 높이 0.75m × 깊이 1.25m**
   - 상판 두께 0.08m / 다리(기둥) 0.08×0.08m
4. **레퍼런스 깔기**: 턴어라운드 시트를 뷰별로 잘라(정면/측면/상단) → 블렌더에서 `Add > Image > Reference`로 각 직교 뷰에 배치. 숫자패드 1(정면)/3(측면)/7(상단)에서 반투명하게 깔고 덧그리듯 모델링.

## 2. 블로킹 — 큰 덩어리 먼저 (30분 목표)

> 원칙: **디테일 금지.** 실루엣이 레퍼런스와 겹칠 때까지 박스만.

1. `Shift+A > Mesh > Cube` → `S`로 스케일 → N패널(치수 직접 입력)로 **상판**(2.3 × 1.25 × 0.08) 배치, 윗면 y=0.75
2. 같은 방식으로 **몸통 패널**(앞판·뒤판·옆판), **모서리 기둥 4개**, **하단 받침**
3. **Mirror Modifier**: 왼쪽 절반만 만들고 오른쪽은 미러 — 기둥·패널이 자동 대칭. (Modifier Properties > Add Modifier > Mirror, X축)
4. **스냅 켜기**: 자석 아이콘 → Increment. 모든 치수를 **0.01m 배수**로 — 복셀풍은 치수가 깔끔한 배수일 때 산다.
5. 이 단계 완성 기준: 회색 상태로 게임 그레이박스와 나란히 놓아도 어색하지 않은 실루엣.

## 3. 디테일 — 패널 음각과 몰딩 (이 스타일의 90%)

레퍼런스의 "가구 느낌"은 몰딩(테두리 단차)에서 나온다:

1. 앞판 선택 → `Tab`(에딧 모드) → 면 선택 → `I`(Inset Faces)로 테두리 안쪽에 면 생성 → `E`(Extrude) 후 살짝 **안으로 밀어넣기**(-0.02m) = 음각 패널
2. `Ctrl+R`(Loop Cut)로 앞판을 3분할 → 패널 3개 (레퍼런스 후면처럼)
3. 기둥 위아래에 약간 넓은 캡(주추) — 작은 박스 얹기
4. **하지 말 것**: Bevel 남발(둥근 모서리는 이 스타일이 아님), Subdivision Surface(로우폴리에 금지)

## 4. 배너 (보라 깃발)

- 별도 오브젝트로: 평면(Plane) → `Ctrl+R`로 가로 2~3분할 → 정면 뷰에서 아래쪽 정점을 살짝 앞뒤로 → 천이 걸린 느낌. 하단 삼각 컷은 정점 병합(`M`)으로
- 봉(가로대)은 얇은 실린더(8각이면 충분) + 양끝 캡
- **엠블럼(해골 문장)은 모델링하지 않는다** — 텍스처로 그린다 (§5)

## 5. UV와 텍스처 — 룩의 나머지 절반

### 5a. UV 언랩
1. 오브젝트 전체 선택 → `Tab` → `A`(전체 선택) → `U > Smart UV Project` (초심자용; 익숙해지면 Seam 수동)
2. **텍셀 밀도를 일부러 낮게**: 이 룩은 "1m당 16~32픽셀"이 정석. 책상 전체가 **256×256 텍스처 한 장**에 들어가면 성공
3. 체커 텍스처를 입혀 픽셀 크기가 면마다 비슷한지 확인 (한 면만 픽셀이 잘거나 뭉개지면 UV 크기 조정)

### 5b. 텍스처링 — 두 갈래 (쉬운 길부터)
- **1차: 팔레트 방식 (첫 모델 권장)** — 나무 3~4톤 + 보라 2톤 + 금색이 칸칸이 칠해진 아주 작은 텍스처(예: 64×64)를 만들고, 면별 UV를 해당 색 칸 위로 옮겨 놓기. 나뭇결은 없지만 톤은 즉시 잡히고, 실패 비용이 거의 없다.
- **2차: 픽셀아트 텍스처 (레퍼런스 룩)** — UV 레이아웃을 PNG로 내보내(`UV > Export UV Layout`) Aseprite/포토샵에서 픽셀 단위로 나뭇결·엠블럼을 그린다. 블렌더 안에서 하려면 Texture Paint 모드 + 브러시 Falloff를 Constant로. 레퍼런스 시트의 정면 뷰를 밑그림 레이어로 깔고 따라 그리면 빠르다.
- 공통: **안티앨리어싱 금지, 부드러운 브러시 금지** — 픽셀이 픽셀로 보여야 한다.

## 6. 내보내기 (블렌더 → 유니티)

1. 정리: `Ctrl+A > All Transforms` (스케일·회전 적용 — 이거 안 하면 유니티에서 크기가 튄다), 오브젝트 **원점을 바닥 중앙**으로 (배치 기준점)
2. 불필요 데이터 삭제: 레퍼런스 이미지 오브젝트, 미러 Modifier는 Apply
3. `File > Export > FBX`: Selected Objects 체크, Apply Scalings = **FBX All**, Forward = -Z, Up = Y
4. 텍스처 PNG는 FBX와 같이 복사

## 7. 유니티 임포트 체크리스트

- [ ] FBX 임포트 후 Scale Factor 1로 크기 확인 — **1m 기본 큐브와 나란히 놓고 비교**
- [ ] 텍스처 **Filter Mode = Point (no filter)** ← 이 한 칸이 룩의 절반. 잊으면 뿌옇게 뭉개진다
- [ ] 머티리얼 = URP/Lit, 텍스처를 Base Map에
- [ ] **촛불 조명 아래에서 확인** — 우리 무드는 조명 의존이 커서, 흰 배경에서 예쁜 톤과 게임 안 톤이 다르다. mawanghr 씬에 임시로 끌어놓고 볼 것
- [ ] 프로토 반영은 아트 패스(M5) 때 DeskRig의 그레이박스 교체로 — 지금은 학습·톤 검증용

## 8. 학습 순서 제안 (책상으로 바로 시작하지 말 것)

| 순서 | 대상 | 배우는 것 | 예상 |
|-----|------|----------|------|
| 1 | **머그컵** | 박스 블로킹·팔레트 텍스처·FBX 왕복 | 1~2시간 |
| 2 | **책 더미** | 멀티 오브젝트·살짝 어긋난 배치 감각 | 1시간 |
| 3 | **책상 (본편)** | 미러·패널 음각·UV 계획·픽셀 텍스처 | 반나절 |
| 4 | 배너·수정구 받침 등 소품 | 곡면 최소화 요령 | 각 1시간 |

머그부터 하는 이유: **블렌더→유니티 왕복 파이프라인 전체를 가장 작은 물건으로 먼저 뚫는 것**이 핵심이라서다. 파이프라인이 뚫리면 책상은 시간 문제고, 안 뚫린 채 책상부터 잡으면 모델링·UV·익스포트 문제가 한꺼번에 터진다.

## 9. 이 레퍼런스 시트의 활용법

- 턴어라운드(정면/측면/후면/상단)가 이미 있으니 **§1-4의 레퍼런스 깔기 재료로 그대로 사용** — AI 생성 시트의 가장 좋은 용도다
- 단, AI 시트는 뷰 간 디테일이 서로 안 맞는 경우가 있으니(기둥 개수·패널 분할 등) **정면을 기준 뷰로 정하고 나머지는 참고만**
- 엠블럼은 정면 뷰에서 크롭해 픽셀 텍스처의 밑그림으로
