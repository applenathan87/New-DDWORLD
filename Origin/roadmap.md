# Origin — 전체 지도 (DDworld 전투 MVP)

목표: **재밌고 보기 좋은 전투**를, 유니티를 처음부터 이해하며 만든다.
각 단계마다 눈에 보이는 결과물이 하나씩 나오도록 순서를 짰다.

> 표기: 단계별 상세 워크북은 진행할 때 `docs/phase-N-*.md`로 따로 작성한다.
> 이 파일은 "지도"만.

## 진행 원칙

- 한 번에 한 걸음. 개념을 이해하고 넘어간다. **이해 기준 = 디렉터 수준** (뭘 하는지·왜 이 방식인지 설명 가능하면 통과. 밑바닥까지 파지 않는다).
- 재미는 기존 배틀테스트로 어느 정도 검증 완료. **이번 트랙의 핵심 검증 = 비주얼("보기 좋은가")**. 밸런스 본검증은 추후 별도 영역.
- 중간 점검 2곳:
  - **1단계 끝 → "보기 좋은가?"** ← 이번 트랙의 심장
  - **5단계 끝 → 전투가 돌아가는가 + 재미 재확인**

## 단계

### 0단계 · 유니티랑 친해지기
새 프로젝트(**Unity 6000.5.1f1** + URP — 기존 프로토타입과 동일 버전) 생성, 화면 둘러보기, 저장.
- 배울 개념: Scene(무대), GameObject, Inspector, Play 모드, Scene 뷰 이동/회전.

### 1단계 · 보이는 공간
잔디 바닥 → 카메라(쿼터뷰) → 조명 → 소품(돌담/울타리) → 색 → 후처리(Bloom/DOF).
- 배울 개념: Transform, Camera, Light, Material, URP Post-processing.
- 목표 레퍼런스: `refs/`의 성벽·잔디 이미지 (따뜻한 미니어처 룩).
- ✅ **점검: 보기 좋은가?**

**아트 방향 — 잔디/환경 디테일 (확정):**
- **입체 잔디(지오메트리) + 바람 살랑임 + 흩뿌린 작은 디테일들 — 인터랙티브는 없음, 전부 복셀 톤.**
- 밋밋함을 죽이는 **3층 구조**로 공간을 채운다:
  1. **바닥층** — 잔디 머티리얼 (칠한 바닥, 저비용)
  2. **디테일층** — 서 있는 풀 뭉치·작은 꽃·돌멩이·버섯·잔가지 등을 흩뿌림 ← 밋밋함을 잡는 핵심
  3. **소품층** — 나무·바위·성벽·울타리 등 큰 것
- 구분: **바람 살랑임 = 배경 애니(거의 공짜, 유지)** vs **인터랙티브(캐릭터 반응) = 채택 안 함**.
- 성능: 지오메트리 잔디는 밀도·오버드로우가 부담. 작은 아레나 + 강한 DOF + GPU 인스턴싱으로 관리. 실제 도입 시 프로파일러 실측.

### 2단계 · 첫 캐릭터 모델 만들기
MagicaVoxel로 캐릭터 1체 제작. **부위 분리**(머리/몸/팔/다리/무기) — Blender 리깅 대비.
- 배울 것: MagicaVoxel 기초, 부위 분리 모델링, 내보내기.
- Claude와 함께 진행.

### 3단계 · 캐릭터 등장
2단계 모델을 유니티로 임포트 → 필드에 세우기 → 정점색/머티리얼 정리.
- 배울 개념: 모델 임포트, FBX/OBJ, 머티리얼 적용.

### 4단계 · 애니메이션 (B방식)
Blender에서 본 심기 + 리깅 + 키프레임(대기·이동·공격·피격·사망) → FBX → 유니티 재생.
- 배울 것: Blender 리깅 기초, 리지드 부위 애니메이션, 유니티 Animator/Animation.
- ⚠️ 유니티에서 잠시 벗어나 Blender 학습이 끼는 구간. 제대로 익히면 모든 캐릭터에 재활용.

### 5단계 · 전투
양쪽 군대 고정 배치 → 자동 전투(이동·공격·HP·사망 = 최소 전투 규칙).
- 배울 개념: 스크립트 기초, 유닛 상태, 간단한 전투 루프.
- ✅ **점검: 재밌는가? (MVP 심장)**

### 6단계 · 배치
플레이어가 전투 전 유닛을 직접 배치.

### 7단계 · 게임 규칙
승패 판정, 상성/카운터, 웨이브 등 상위 규칙.

### 8단계 · UI
체력바, 시작 버튼, 결과 화면, 배치 UI.

### 9단계 · 통합 & 플레이테스트
처음부터 끝까지 한 판이 돌아가게. 재미 튜닝. → 검증되면 본 프로토타입으로 이식.
