# Designing Games for Game Designers
**저자:** Stone Librande (EA/Maxis)
**출처:** [GDC Vault](https://gdcvault.com/play/1015307/Designing-Games-for-Game)
**분류:** 게임 디자인 교육 / 시스템 사고
**발표:** GDC 2012

---

## 핵심 메시지

GDC Vault 공식 설명 기반:

> "Stone describes the evolution of these games and talks about the underlying lessons contained in each one."

게임 디자인을 가르치기 위해 직접 카드/보드게임을 만든 10년간의 과정. 디자이너이자 플레이어로 동시에 참여하는 방식이 전통 강의보다 개념을 더 효과적으로 내재화하게 한다.

---

## 주요 내용 (GDC Vault 공식 설명 기반)

### 1. 강연의 핵심
- Librande가 10년간 게임 디자인 수업을 위해 직접 만든 카드/보드게임들의 발전 과정 소개
- 각 게임은 특정 디자인 주제를 다룸: 룰 시스템 작성, 목표 선택, 적 조율, 비대칭 밸런싱

### 2. 학습 방식
- 학생들이 디자이너이자 플레이어로 동시에 참여
- 이 방식이 전통 강의보다 개념을 더 효과적으로 내재화하게 함

### 3. 대상 청중 (공식 설명 원문)
- 어린이 게임 교육 관련 디자이너, 게임 연구자, 게임 디자인 기초 지식을 원하는 모든 사람
- 사전 디자인 경험 불필요
