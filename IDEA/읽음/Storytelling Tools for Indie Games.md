# Storytelling Tools to Boost Your Indie Game's Narrative and Gameplay
**발표자:** Blake Rebouché
**출처:** [GDC YouTube](https://www.youtube.com/watch?v=8fXE-E1hjKk)
**분류:** 내러티브 / 인디게임 기획

---

## 핵심 메시지

> 인디게임은 스토리와 메커닉을 따로 만들면 안 된다.
> 게임플레이 자체가 이야기를 전달해야 한다.

---

## 주요 내용

### 1. 인디의 현실
- 방대한 컷씬이나 보이스 액팅 없이 이야기를 전달해야 함
- 대신 인디는 메커닉으로 감정을 전달하는 데 유리

### 2. 메커닉이 곧 내러티브
- Papers Please: 서류 도장 찍기라는 단순한 메커닉이 관료주의의 공포를 전달
- Celeste: 등반이라는 메커닉이 자기 극복의 서사를 전달
- 규칙 자체가 세계관과 주제를 담을 수 있음

### 3. 세계관을 UI에 녹이기
- UI 텍스트 하나가 세계관을 드러낼 수 있음
- 인터페이스 디자인이 곧 세계관 설계
- 예: 냉혹한 세계 → 딱딱한 폰트와 색상 / 따뜻한 세계 → 손글씨와 따뜻한 색

### 4. 플레이어를 공저자로 만들기
- 완전히 설명하지 말고 여백을 남겨라
- 플레이어가 해석하고 채워넣는 공간 = 몰입의 원천
- 암시 > 설명

### 5. 작은 팀의 장점 활용
- 일관된 비전 유지가 쉬움
- 게임플레이-내러티브 통합이 빠름
- 실험을 빠르게 시도할 수 있음

---

## DDworld에 적용할 수 있는 것
- 전투 메커닉 자체가 DDworld의 주제를 전달하게 설계
- UI 디자인에 세계관 반영 → 설명 없이 분위기 전달
- 성장 시스템에 서사를 얹기: 단순한 레벨업이 아닌 "각성" 서사
- 플레이어가 완전히 이해 못해도 몰입할 수 있는 여백 설계
