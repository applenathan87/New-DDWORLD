# TFT (Teamfight Tactics) vs DDworld

> **Status**: Research / Comparative Analysis
> **Author**: nathan
> **Last Updated**: 2026-05-25

> **Purpose**: TFT가 어떻게 매치 내 성장으로 리플레이성을 확보하는지 분석하여, DDworld의 방향성 결정 근거로 삼는다.

## 2. 핵심 게임플레이 루프

```
매치 시작 (8인 로비, 모두 동일 시작)
  ↓
라운드 1~3: PvE (몬스터와 전투, 골드/아이템 획득)
  ↓
라운드 4+: PvP (다른 플레이어와 1v1)
  ↓ 매 라운드:
  ┌─────────────────────────────────────┐
  │ 1. 상점 갱신 (5장 유닛 카드 노출)      │
  │ 2. 골드로 유닛 구매 (1~5 코스트)       │
  │ 3. 유닛 배치 (보드에 드래그, 시너지 발동) │
  │ 4. 아이템 장착 (구성요소 합성)          │
  │ 5. 자동 전투 (관전)                   │
  │ 6. 승/패 → HP 변동, 다음 라운드        │
  └─────────────────────────────────────┘
  ↓
HP 0 = 탈락. 최후 1인까지 진행.
매치 길이: 30~40분
```

### 성장 메카닉 (핵심)

| 메카닉 | 효과 |
|--------|------|
| **골드 경제** | 라운드 보상 + 이자(10/20/30/40/50 골드 임계) + 연승/연패 보너스 |
| **유닛 별 업그레이드** | 같은 유닛 3장 → 2성 (스탯 ×1.5), 9장 → 3성 (스탯 ×2.5) |
| **시너지(Trait)** | 같은 특성 유닛 2/3/4/6장 → 진영 보너스 |
| **레벨업** | 골드로 플레이어 레벨 ↑ → 보드 슬롯 ↑ + 고코스트 유닛 등장 확률 ↑ |
| **공유 풀** | 모든 플레이어가 같은 유닛 풀에서 뽑음 (희귀 유닛 경쟁) |
| **아이템 합성** | 구성요소 2개 → 완성 아이템 |
| **카루셀** | 라운드마다 회전 선택대에서 유닛/아이템 픽 |

## 3. DDworld 비교 매트릭스

| 항목 | TFT | DDworld 현재 | 비고 |
|------|-----|------------|------|
| **장르 정체성** | 8인 오토배틀러 | 1v1 심리전 오토배틀러 | DDworld는 의도적으로 좁힘 |
| **플레이어 수** | 8인 동시 | 2인 1v1 | |
| **매치 길이** | 30~40분 | **10분** | ❗ 큰 차이 |
| **시작 자원** | 골드 0 + 빈 보드 | 45장 덱 (양쪽 동일) + 손패 8장 | DDworld는 처음부터 풍부 |
| **변화의 원천** | **카드 RNG (상점 갱신)** | 손패 드로우 + **상대 가변성** | 다른 종류의 변화 |
| **매치 내 성장** | ⭐⭐⭐ 매우 강함 (별 업그레이드 + 시너지 + 레벨) | ❌ 없음 (덱 고정) | **DDworld의 약점으로 인식** |
| **매치 간 진행** | 랭크/배틀패스/코스메틱 | (계획 단계) | 둘 다 메타 진행 보유 |
| **숨겨진 정보** | 약함 (모두 같은 보드 공개) | **강함 (배치 비공개)** | **DDworld 차별점** |
| **심리전** | 약함 (간접적 — 상대 빌드 예측) | **핵심 가치** | DDworld 정체성 |
| **운 요소** | 큼 (카드 풀, 아이템 RNG) | 작음 (대칭 덱) | DDworld 의도된 디자인 |
| **결정 빈도** | 매우 높음 (라운드마다 5~10개 결정) | 중간 (라운드마다 5장 배치) | TFT가 더 잦은 결정 |
| **결정 깊이** | 중간 (메타 빌드 따라가는 경향) | **높음 (배치 패턴 해석)** | DDworld 강점 |
| **콘텐츠 갱신** | ⭐⭐⭐ 시즌별 전체 리셋 | (Post-MVP 콤보 시스템) | TFT는 운영 부담 큼 |
| **인디 적합성** | ❌ AAA 스튜디오 게임 | ✅ 1인 인디 가능 | 다른 시장 |
| **e스포츠** | 글로벌 토너먼트 | (Post-1.0 가능성) | 다른 스코프 |

## 4. DDworld가 배울 점 (Take-aways)

### 🎯 TFT가 잘하는 것 중 차용 가능

#### A. **명확한 진행감 시각화** ⭐⭐⭐
TFT는 라운드마다:
- 골드가 올라간다 (숫자 가시화)
- 별이 채워진다 (1성 → 2성 → 3성)
- 시너지가 발동된다 (왼쪽 패널 강조)
- HP가 줄어든다 (다음 게임 압박감)

**DDworld 적용 안**:
- 판돈 누적을 시각적 폭발로 (코인 쌓이는 연출)
- 라운드 승수 카운터 강조 (별 채우기 등)
- 이월 카드 효과 시각 강화
- → **"내가 뭔가 모으고 있다"** 감각을 비-성장 방식으로 강화

#### B. **시너지 발견의 즐거움** ⭐⭐⭐
TFT 신규 플레이어가 가장 좋아하는 순간 = "이 두 유닛 조합 미쳤다!"

**DDworld 적용 안**:
- `replayability-and-synergy.md`의 콤보 시스템 (위치 기반)
- 매치 중 콤보 발동 시 명시적 연출 (이름 표시, 화면 변화)

#### C. **레벨업으로 게임 진행 페이싱**
TFT는 라운드 5/9/14 등에서 레벨이 자동으로 올라감 → 새 가능성 열림.

**DDworld 적용 안**:
- 라운드별 "잠금 해제" — 라운드 3부터 함정 사용 가능, 라운드 4부터 추가 카드 1장 손패 등
- → **매치 내 페이싱** 강화

### ⚠️ 부분적 차용

#### D. **카루셀 같은 공유 선택 이벤트**
TFT의 카루셀 = 모든 플레이어가 회전대에서 동시에 픽

DDworld는 1v1이라 카루셀 자체는 안 맞지만, "매치 사이 보상 선택"으로 변환 가능 (Bazaar 스타일).

## 5. DDworld가 피할 점 (Anti-patterns)

### 🚫 TFT를 따라가면 망하는 것들

#### A. **30~40분 매치 길이**
- TFT가 그 길이여도 되는 이유: 8인 경쟁, 매 라운드 새 자극
- 1v1 + 1인 인디는 그 페이스 못 유지함
- DDworld의 **10분이 차별점**. 절대 늘리지 말 것

#### B. **무거운 RNG (운 요소)**
- TFT는 운 요소 큼 (어떤 카드 뽑냐 + 아이템 RNG)
- "라인업 운으로 졌다" 불만 다수
- DDworld의 Anti-Pillar "랜덤 운 게임 아님"과 정면 충돌
- → **대칭 덱 + 손패 공개** 유지

#### C. **메타 빌드 정답화**
- TFT는 매 패치마다 "정답 빌드" 1~3개로 수렴
- 결정의 폭은 넓어 보이지만 실제로는 좁아짐 ("S 티어 빌드만 픽")
- DDworld는 **상대 가변성**으로 정답을 자연 분산시켜야

#### D. **세트 로테이션 (콘텐츠 운영 부담)**
- TFT는 3~6개월마다 전체 유닛/시너지 교체
- AAA 스튜디오니까 가능
- 1인 인디는 절대 불가
- → DDworld는 **소수 콘텐츠를 깊게** 운영 (5병종 + 점진 확장)

#### E. **8인 멀티플레이어 (서버 부담)**
- TFT는 매칭 큐 + 동기화 + 서버 비용
- 1인 인디는 1v1도 부담
- → **비동기 PvP** (Bazaar, Despot's Game 패턴) 고려 가치

## 6. 결정적 통찰 (Key Insight)

> **TFT는 "라운드마다 새로움"으로 리플레이성을 확보한다. DDworld는 "상대마다 새로움"으로 같은 목표를 달성해야 한다.**

| 측면 | TFT의 답 | DDworld의 답 |
|------|---------|------------|
| 매 라운드 다르게 만드는 법 | 새 카드 + 새 아이템 + 새 시너지 | 새 손패 + **새로운 상대 행동** |
| 매 매치 다르게 만드는 법 | 다른 라인업 빌드 | 다른 상대 = 다른 심리전 |
| 장기 동기 부여 | 시즌 + 랭크 + 새 세트 | (메타 진행 — 별도 설계 필요) |

**핵심**: TFT의 "성장 감각"을 그대로 베끼면 DDworld는 TFT의 열화판이 됨. DDworld는 **다른 축(심리전)**에서 같은 가치(흥미로운 결정)를 제공해야 함.

단, TFT의 **"시각적 진행감 / 시너지 발견 / 페이싱"**은 차용 가치 있음. 핵심 메카닉(성장)이 아닌 **연출/UX**에서 배울 점.

## 7. DDworld 적용 우선순위

| 우선순위 | 차용 요소 | 작업량 | 효과 |
|---------|---------|-------|------|
| ⭐⭐⭐ | 시너지 발견 연출 (콤보 시스템과 결합) | 중 | 매치 내 자극 ↑ |
| ⭐⭐⭐ | 판돈 누적 시각 강화 | 소 | "모으는" 감각 ↑ |
| ⭐⭐ | 라운드별 잠금 해제 (페이싱) | 중 | 매치 페이싱 ↑ |
| ⭐⭐ | 매치 사이 보상 선택 (Bazaar 영감) | 대 | 빌드 서사 ↑ |
| ⭐ | 시즌/배틀패스 (메타 진행) | 대 | 장기 동기 ↑ (Post-1.0) |
