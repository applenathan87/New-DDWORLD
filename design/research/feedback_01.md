# DDworld 설계 진단 #01 — 현행 작업본 전체 리뷰

설계 자체는 피벗 이유·긴장 설계·문서화 수준 모두 탄탄. 다만 **구조적으로 위험한 지점 3개**와 시스템 리스크 몇 개가 보인다. 심각도 순으로 정리.

## 🔴 구조적 문제 — 코어 루프를 위협

### P1. MVP에 패배 조건이 없다 → 긴장 장치 3종이 전부 무력화

Core Tension의 세 장치(HP 이월 / permadeath / 멀티덱 강제)는 전부 **"손실을 아프게"** 만드는 장치인데, 지금 MVP 스코프에는 그 손실의 바닥이 없다:

- 게임오버 = 나중 도입 (Q8/Q20)
- 카드 0장 데드엔드 없음 (Q11 생산 슬롯이 보장)
- 역습 없음 (Q15, MVP 일방 확장)
- 시간 압박 없음 (Day는 무한, 페널티 없음)

→ 유닛을 다 잃어도 **"며칠 기다리면 복구"**. 손실이 긴장이 아니라 그라인드(시간 낭비)가 된다. 다키스트 던전의 긴장은 "잃으면 진짜 진다"에서 나온다.

더 위험한 건 **MVP 플레이테스트의 검증 대상이 바로 이 긴장**이라는 점. 바닥 없이 테스트하면 "소모전이 재밌는가"라는 질문 자체가 검증이 안 됨 — 거짓 결론이 나올 수 있다.

**해결안**: 게임오버 풀 기획(Q20)은 나중이어도, MVP에 **placeholder 압박 1개는 필수**.
- 추천: A11 후보에 이미 있는 "주간 공습"의 최소 버전 — N일마다 성 방어전, 실패 시 성 HP 감소, 0이면 캠페인 리셋. (어차피 후보 1순위라 버려질 작업이 아님)
- 더 싼 대안: **방치 비용** — 적 타일이 Day 경과에 따라 서서히 강해짐. "기다리면 복구"가 "기다리면 더 어려워짐"으로 바뀜.

### P2. permadeath가 Pillar 2와 정면충돌 — "아끼다 게임 끝나는" 문제

실버 Lv3 = 카드 3장 머지(장당 생산 4일) + 건물 투자 = **잃으면 12일+ 증발**. 그러면 합리적 플레이는:

> 소모품 브론즈만 내보내고, 아끼는 실버는 벤치에 모셔둔다.

RPG의 엘릭서 문제 그대로. "티어 = 소모품↔투자 축"이라는 설계가 그대로 **"브론즈만 소모하고 실버는 장롱"이라는 최적해**를 만든다. 게다가 "배치만으로 이길 수 있어야"(baseline) 원칙 때문에 브론즈 물량으로도 이기니, 투자 유닛을 낼 이유가 더 없어진다. **"키운 군대가 빛을 보는" 순간(코어 판타지)이 구조적으로 안 온다.**

**해결안** (조합 가능):
1. **손실을 "전멸"이 아닌 "감소"로 명확화** — 분대 카드는 병사 1명이라도 살면 카드 생존(축소된 채 유지). 이미 개별 HP 구조(Bad North식)라 자연스럽고, "잘 쓰면 지킬 수 있다"가 되어 후방 배치·운용 판단이 생긴다. ※ 지금 문서가 애매함: Q3 "카드 HP 0 시 소멸" vs combat.md Edge Case "병사 HP 0 → 카드 소멸" vs game-concept "죽으면 분대가 줄어듦" — **분대 전멸 = 소멸**인지 명문화 필요.
2. **난이도가 투자 유닛을 강제** — 적 디자인(Q19)에 "브론즈 물량이 물리적으로 안 통하는" 패턴을 심기(예: AoE 몬스터 = 물량 카운터). 실버를 낼 수밖에 없는 타일을 만드는 것.
3. **복구를 시간이 아닌 골드로** — 재훈련/부활 비용을 경제 결정으로 치환하면, 손실 = "그라인드"가 아니라 "지갑 아픔"이 됨. 골드 sink도 확보.

### P3. 콘텐츠의 등뼈(적 디자인 Q19)가 Tier 4에 있는데, 실제로는 Tier 0이다

상성표를 지운 순간, 전투의 모든 다양성은 **적 진형·특성**에서 나온다("유불리 = 내 패턴 × 몬스터 특성"). 그런데:

- 아군 로스터(Q25)는 8종까지 확정했는데 상대는 미정 — **순서가 뒤집혔다.** PvE 오토배틀러에서 적 = 콘텐츠 그 자체.
- 100% 공개 + 단판 + 자동전투 = **같은 적 구성엔 같은 배치가 영원히 정답**. 소모전 장치는 "어떤 카드를 낼지"는 흔들지만 "어디에 놓을지"는 못 흔든다. 적이 단조로우면 배치는 몇 시간 만에 루틴화된다("고블린 떼 = 늘 방패병+마법사").

**해결안**: Q19를 사실상 Tier 0으로 승격. 전부 정할 필요는 없고 두 가지만:
1. **적 변주의 문법** — 어떤 축으로 다양해지나 (물량/장갑/원거리/돌진/소환/오라/지형점유…). 아군 8종의 패턴 각각에 "이게 꽂히는 적"과 "이게 막히는 적"이 최소 1개씩 있게 역설계.
2. **MVP 적 6~8종 초안**. 전투 프로토타입 검증("배치가 달라지는가")만이라면 3종으로도 시작 가능.

## 🟠 시스템 리스크

### P4. 경제 스노우볼 + "끝" 부재 = 후반 붕괴
영토 영구 + 타일당 패시브 골드 + 브론즈팩 무제한 → 전형적 4X 스노우볼. 문서도 인지하고 "후반 부유 = 클리어 특권"이라 했지만, **클리어(Q20)가 미정이라 그 특권이 "긴장 제로 구간의 무한 연장"**이 된다. → 캠페인의 끝(최종 보스 타일 / 전역 정복 / N주 생존)을 Q19 다음 우선순위로. 끝이 있어야 후반 부유가 "클리어 스퍼트"로 기능한다.

### P5. "전투는 얇아도 됨" × "매일 전투" = 반복 피로
깊이를 메타에 몰빵한 결정은 좋은데, **플레이 시간의 대부분은 여전히 전투(배치+관전)**다. 가장 얇은 행위를 가장 자주 반복하는 구조. 관전도 매일 보면 스킵 대상 — 배속을 주면 Pillar 3이 죽고, 안 주면 피로. → ①전투 목표 길이를 짧게(30초~1분) 명시 ②배속 기본 제공 + **명장면 자동 슬로모**(대량 처치·메테오) 같은 연출 훅으로 "보는 맛"을 압축 ③이벤트 타일(전투 없는 날)의 밀도를 페이싱 knob으로 관리.

### P6. 죽음의 소용돌이가 구조적으로 강함 (이미 인지된 리스크)
매일 진격 강제 + 치유소 = N일 벤치 + "약한 타일 남기기"는 유한하고 초보는 모름. 군대가 약해지면 회복 수단이 "더 약한 전투"뿐인데 그것도 바닥난다. → **"시간은 압박, 골드는 완충"** 교환 구조 추천: 진격 스킵(수비의 날)을 골드로 구매 / 치유소 벤치 기간 골드 단축. 빈 땅 정착이 이미 "전투 없는 하루" 역할을 하니 이것도 완충으로 인정.

## 🟡 마이너 / 정합성

- **P7**: 위협 없는 MVP에선 "빈 땅 먼저 싹 정착 → 스노우볼 → 전투"가 지배 전략. P1의 시간 압박이 생기면 자동 해결(하루의 기회비용 발생).
- **P8 문서 정합**: pve-pivot Q25 제목이 "MVP **7종**"인데 본문은 8종 / game-concept Open Items도 "7종" + 방패병 "(나중)" 잔재 (game-concept.md:109, 154). 정본 제목이 틀린 건 곤란하니 한 줄 수정 대상.
- **P9 코드 잔재**: BattleSimulator.cs:20-21에 `typeAdvantage/typeDisadvantage`(RPS 상성) — "상성표 제거" 결정과 불일치. 옛 PvP 프로토타입이라 당장 무해하지만, 전투 프로토타입 재작업 시 계승 주의. + unity-prototype에 README 없음.
