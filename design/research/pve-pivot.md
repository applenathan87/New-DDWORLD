## A. 확정된 결정 (LOCKED — 2026-06-29)

1. **PvE로 전환, 비동기 PvP 폐기.** 이유: "칸막이 걷고 서로 배치 까는" 심리전은 동기/대면에서만 성립. 비동기/PvE에선 "정답 찾기"로 떨어짐. 솔로 인디엔 PvP 인프라(BaaS/고스트/매칭)도 과한 리스크.
2. **코어 재미 = 전술 퍼즐.** 적 배치를 보고, 내가 키운 빌드로 "어떻게 풀지" 고민 → 카운터 배치 → 자동 전투.
3. **메타 구조 = 문명식 헥사 영토 확장.** 성(castle) 중심에서 주변 헥사를 차지하며 **영토 영구 누적**(로그라이크 런 리셋 아님).
4. **확장 2방식**: 적 있는 땅 = **전투로 정복** / 빈 땅 = **구매**.
5. **하이브리드 구조 + 단계화**:
   - 영구 베이스 레이어(영토·건물·해금) + 출정(위험지역 런) 레이어.
   - **MVP/프로토타입 = 영구 베이스 + 전투 먼저** (출정·리셋 없이 코어 검증). **출정 레이어 = Phase 2.**
   - ⚠️ 설계 제약: **덱·전투를 "영구 상태"에 하드커플 금지** → 나중에 출정 런 래퍼를 씌울 수 있게.
6. **건물 = 병종 언락 게이트.** 예: 기마병 훈련소 → 기마병 언락. (영구) 레벨업·기타 역할(자원/버프)은 나중에 확장.
7. **덱 흐름 = A+B**:
   - (A) 출정 *전* 영구 풀(건물로 키운 병종)에서 **시작 덱 편성**.
   - (B) 출정 *중* 클리어 보상으로 **드래프트 성장**(StS식).
   - 실패 시 **런 덱/획득물만 리셋, 베이스(영토·건물·해금)는 보존.**
8. **기둥(안)**: ① 전술 퍼즐 "풀었다!" (구 심리전 대체) ② 내 빌드의 서사 (중심축 격상) ③ 보는 맛 (유지).
9. **유지(전환 영향 없음)**: 아트/렌더 — [ADR-003](../../docs/architecture/ADR-003-rigid-instancing-crowd-rendering.md) 리지드 인스턴싱·정점색 1머티리얼·400명, [ADR-002](../../docs/architecture/ADR-002-visual-style-low-poly-3d.md) Low-poly Voxel. PvE 오토배틀러도 다수 병사 렌더 그대로 필요.

**레퍼런스**: 문명(헥사·확장) + Bad North/Thronefall(성·오토배틀) + StS/Despot's Game/Hades(덱빌딩·하이브리드).

## B. 풀어야 할 Q 리스트 (우선순위 순)

> 방식: 위 Tier부터 하나씩 결정 → 해당 문서 반영 → 커밋. Tier 0~1이 game-concept 개정의 뼈대.

### Tier 0 — 코어 전투 & 덱
- [x] **Q1. 결정(C)** — **적 본대 항상 100% 공개 = 코어 퍼즐**: 공개된 적 배치에 맞춰 내 유닛을 "퍼즐 풀듯" 카운터 배치하는 것이 핵심 코어요소. 일반 인카운터엔 숨김 없음. **변주(숨김/함정)는 보스 전용 — 패턴/페이즈로 구현.** 숨김 적용 시 공정 원칙 준수(텔레그래프 / 정찰 가능 / 학습된 속성), 첫판 gotcha RNG 금지.
- [x] **Q2. 결정 — 단판 기본 + 플레이어 개입 레이어 (순수 관전 X).**
  - **형태**: 단판 1회 (배치→풀공개→자동전투→결과). 진행/레벨에 따라 스테이지·난이도 증가(성에서 멀수록↑). 보스 = 페이즈(Q1).
  - **유닛 상태**: 카드→유닛 변환(개별 HP). 연속 전투 시 **소모 HP 그대로 다음 판 이월** → 다친 부대 후방 배치 vs 그대로 운용이 전략. 회복 = 유물("전투 후 N% 회복")/힐러 유닛.
  - **개입**: ① 액티브 스킬 유닛(예: HP 낮은 1기, 쿨 차면 마우스 타겟팅 메테오) ② 사용 아이템(포션/렐릭). 단 대다수 유닛은 자동 = **배치가 메인 스킬**(오토배틀러 정체성 유지).
  - → HP 이월·소모 구조 = Q10, 액티브/아이템/렐릭 성장 = Q16 연결.
- [x] **Q3. 결정 — 하이브리드 분대/영웅 + 병사 개별 HP + 병사 수는 카드 레벨로 증감.**
  - 분대 카드(대다수, 병사마다 개별 HP — Bad North식, 죽으면 분대 축소) + 단일/영웅 카드(소수·강력·액티브).
  - 유형별: 민병 = HP/공/방 낮은 다수 / 액티브·영웅 = 소수·1기.
  - ~400 병사 = 배치 분대들의 병사 수 합산(ADR-003 인스턴싱).
  - 병사 수 = **카드 레벨**. 레벨업 = **C 하이브리드**: 건물 업글이 해당 병종 공격력/방어력/규모를 **패시브로** 올림(1/2/3레벨) + 같은 카드 **머지** 시 추가로 더 크게 상승.
  - **⭐ 유닛 영구소멸(permadeath)**: 레벨과 무관하게 카드 HP는 한정 → **HP 0 시 카드 소멸**. 다키스트 던전식 "유닛을 아끼는 긴장" + 성장맛. 회복 = 유물("전투 후 N% 회복")/힐러로 소멸 방지. *(소멸 시 손실 vs 보존 범위 = Q8/Q18)*
- [x] **Q4. 결정 — 원래 5x5 그리드 + 7장 덱/5부대 배치 + 자유 위치.**
  - 전장 = **원래 5x5 그리드**(combat.md). 핵심 = **열(column) 기반 일직선 전진** — 배치한 열이 전투 매칭 결정 = 배치 읽기 퍼즐의 핵심. PvE: 적은 인카운터가 미리 배치(Q1 풀공개), 플레이어는 자기 구역에 배치.
  - **덱 ≤ 7장 지참 → ≤ 5부대 배치** = 7중 5 선택·배치 레이어(이 적에 맞는 5장 고르기).
  - **자유 위치** — 어느 칸이든(마법사 맨 앞 가능).
  - combat.md 튜닝범위(3x3~7x7 / 3~8장) 내 신규 기본값. *(PvP "비밀배치·동시공개" → PvE "적 풀공개 후 카운터"로 reframe = 문서정리 C)*
- [x] **Q5. 결정 — 자유 편성 + 단계별 시점.** 보유 컬렉션에서 아무 ≤7장 자유 편성(중복은 보유 수만큼). 과해지면 나중에 소프트 제약. 편성 시점: **MVP(단발 전투) = 전투 사이 자유 재편성 / 출정 레이어(Phase 2) = 출정 단위 고정**(들고 간 로스터로 끝까지 — permadeath·HP이월 긴장).
- [x] **Q6. 결정 — 획득 = 가챠라이트 3중1 드래프트.** 기본 = 스테이지 클리어 보상(3장 중 1장 선택). 시장(market) 건물 건설 후 = 일정 시간마다 금화로 카드팩 오픈(3중 1 선택). → 루프 덜 하면서 덱 확장·강화. (출정-중 드래프트 = 스테이지 보상, 시장팩 = 베이스 레이어 획득)

### Tier 1 — 출정(런) 구조 ★ 가장 큰 미결
- [ ] **Q7.** 출정 형태 — 별도 던전 맵(Loop Hero식, 깔끔) vs 헥사 국경 밀기(통합, 리셋 경계 모호)?
