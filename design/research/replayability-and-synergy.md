## 0. 요약

반복 피로도 걱정에서 출발하여, **카드 강화는 설계 훼손으로 배제**, 대안으로 **위치 기반 시너지 × 포커 핸드 구조 × 이월 시스템 결합**을 선택했습니다. MVP에서는 **방향 B (병종당 1개 = 4개 콤보로 시작 → Alpha에서 병종당 2개 + 복합 = 8~9개로 확장)**을 채택합니다. 드로우 운이 Anti-Pillar와 충돌하는지에 대한 검토는 §10에 정리되어 있습니다.

덱 빌딩은 **Option B (매치 전 덱 공개) + Option C (병종당 5~15장 제약)** 조합으로 도입 결정 (§11). Anti-Pillar "복잡한 경영 게임이 아니다"는 "무거운 경영이 아니다"로 해석을 완화 (§12). 카드 획득은 **상자 뽑기 (인게임 재화 한정, 플레이어 우선순위 선택으로 가중치 부여)** 방식으로 확정 (§13). 외부 결제 없음. 세부 스펙(가격, 확률, 중복 처리 등)은 후속 논의.

## 1. 배경: 반복 피로도 걱정

### 1.1 문제 제기

- 같은 5병종을 반복해 배치하는 구조가 매치 수가 늘어날수록 지루해지지 않을까?
- 프로토타입에서 "처음 몇 번은 재미있지만 그 이후로 루틴화"되는 위험

### 1.2 전제 재검토

"같은 병종을 반복 배치 = 지루하다"는 전제는 심리전 게임에서는 성립하지 않을 가능성이 큽니다. 근거:

| 게임 | 반복 요소 | 지루한가? |
|------|---------|----------|
| 체스 | 똑같은 16개 말 | 500년째 재미있음 |
| 포커 | 똑같은 52장 카드 | 수백 년째 재미있음 |
| 바둑 | 똑같은 흑/백 돌 | 3천 년째 재미있음 |

**이유**: 말은 같지만 **조합, 상황, 상대가 매번 다르기** 때문.

DDworld도 같은 원리가 작동할 잠재력:
- 상대 손패 매 라운드 다름 (8장 중 어떤 카드?)
- 상대 배치 매 라운드 다름 (25칸 중 어디?)
- 5x5 그리드에 5장 배치 조합의 경우의 수 ≈ **6,375만 가지**

### 1.3 결론

반복 피로도는 **진짜 문제일 수 있지만**, 먼저 코어 루프의 심리전이 "반복을 흡수하는지"를 프로토타입에서 검증해야 합니다. 피로도가 **실제로 발생한다고 확인된 후에** 대응책을 결정하는 게 순서입니다.

단, 대응책의 **방향성**은 미리 설계해두는 것이 유리합니다 — 이 문서가 그 방향성입니다.

## 2. 검토 배제: 카드 강화

### 2.1 원제안

같은 병종이라도 강화 버전(창병+1, 창병+2 등)이 있으면 "원하는 강화 카드가 나왔을 때의 쾌감"이 생김.

### 2.2 배제 이유

#### 이유 1: 심리전 설계 붕괴

"읽었다!"의 쾌감은 **"파워가 동등한데 배치로 승부가 갈린다"** 에서 나옵니다.
- 상대가 "창병+2"를 가지고 있고 나는 "창병"만 있다면 → 배치를 아무리 잘 읽어도 파워 차이로 짐
- 심리전이 "누가 더 좋은 카드 뽑았냐"로 환원됨
- Pillar "심리전" 붕괴

#### 이유 2: Anti-Pillar 2개 위반

- "**랜덤 운 게임이 아니다**" — 강화 카드가 손패에 나오는지가 운이 됨
- "**복잡한 경영 게임이 아니다**" — 강화 재료 수집, 어떤 카드를 강화할지 등 메타 시스템 증가

#### 이유 3: 인디 밸런스 부담

- 현재 밸런스 대상: 병종 5개
- 강화 도입 시: 병종 5개 × 강화 5단계 = **25가지 조합**
- 병종 간 상호작용까지 고려하면 테스트 케이스 기하급수적 증가
- 솔로 인디 1인에게 비현실적

### 2.3 참고: BM과의 연결

같은 구조가 [design/research/monetization.md](monetization.md)의 카드 판매 배제 이유와 일치합니다. **돈으로 사든 게임 내에서 얻든**, 결과적으로 설계에 미치는 영향은 동일합니다.

## 3. 선택된 방향: 위치 시너지 × 포커 핸드 × 이월

### 3.1 핵심 아이디어 구조

```
위치 시너지 (배치 단계의 선택)
        ×
포커 핸드 랭크 (콤보 계층)
        ×
이월 3장 (라운드 간 연속성)
        =
"콤보 준비 → 다음 라운드 발현" 이라는 새로운 전략 레이어
```

### 3.2 왜 이 조합이 강력한가

#### 이월 시스템의 의미 격상

| 이전 | 이후 |
|------|------|
| "5장 쓰고 남은 3장" (수동적 잔여물) | "다음 콤보를 위한 **의도적 시드**" (능동적 도구) |

이월이 **찌꺼기**에서 **도구**가 되는 변화. 같은 3장인데 플레이어 뇌에서의 취급이 완전히 달라집니다.

#### 심리전 한 층 확장

이월 카드는 상대에게 공개됨 → 읽기의 대상이 확장됨:

> "상대가 창병 2장 + 궁병 1장 이월했네. 다음 라운드에 **팔랑크스 + 엄호사격** 콤보 준비 중이군. 내 기병으로 측면 파고들어서 궁병부터 끊어야겠다."

이는 deck.md의 Player Fantasy "읽기의 재료"와 정확히 일치. 읽기의 **대상**이 "카드 종류"에서 "카드 종류 + 조합 의도"로 확장됩니다.

#### 포커 프레임의 학습 비용 절감

포커 핸드는 **인류가 이미 학습한 공용 언어**입니다. 원페어, 트리플, 스트레이트, 풀하우스, 포카드 — 모르는 성인이 거의 없습니다.

> "새로운 8개 규칙을 외우세요" ❌ (학습 부담 큼)
> "포커 아시죠? 그거랑 비슷해요" ✅ (기존 지식의 응용)

8개 콤보도 학습 비용이 3~4개처럼 느껴질 수 있습니다.

## 4. 포커 랭크 매핑 매트릭스

포커의 계층 구조를 DDworld 5장 배치에 매핑:

| 포커 랭크 | DDworld 매핑 | 병종 예시 | 효과 방향 |
|-----------|------------|----------|---------|
| 원페어 | 같은 병종 2장 인접 | 창병 2 인접 | 기본 시너지 |
| 투페어 | 다른 병종 각 2장 | 창병 2 + 궁병 2 | 혼성 부대 |
| 트리플 | 같은 병종 3장 | 기병 3 쐐기 | 병종 특화 버프 |
| 스트레이트 | 같은 줄/대각선 5장 | 한 열 전체 | 일직선 돌파 |
| 플러시 | 같은 병종 5장 ("올인") | 민병대 5 | 극단 전략 |
| 풀하우스 | 트리플 + 페어 | 창병 3 + 궁병 2 | 복합 전술 |
| 포카드 | 같은 병종 4장 + 함정 1 | 기병 4 + 함정 | 최상위 콤보 |

**5장 배치 제약이 오히려 포커 구조와 완벽히 맞습니다.** 5장 드로우 포커가 정확히 이 구조입니다.

## 5. 병종별 콤보 초안 (8~9개)

> **주의**: 수치/위치 조건은 모두 **초안**이며 프로토타입에서 조정됩니다.

### 5.1 기병 (돌격 테마)

| 콤보 | 조건 | 효과 (초안) |
|------|------|-----------|
| **쐐기 진형** | 트리플, 삼각 배치 | 돌격 첫 타격 +50% |
| **일렬 돌격** | 스트레이트, 한 열 (세로) | 돌격 발동 거리 단축 |

### 5.2 창병 (방어 테마)

| 콤보 | 조건 | 효과 (초안) |
|------|------|-----------|
| **팔랑크스** | 원페어, 세로 인접 | 전방 방어력 +30% |
| **방진(Box)** | 포카드, 사각 배치 | 전방위 방어 + 기병 돌격 완전 무효화 |

### 5.3 궁병 (원거리 테마)

| 콤보 | 조건 | 효과 (초안) |
|------|------|-----------|
| **집중 사격** | 트리플, 뒷줄 | 명중률 75%→95%, 데미지 +20% |
| **일제 사격** | 스트레이트, 뒷줄 한 열 | 매 틱 동시 발사 |

### 5.4 민병대 (물량 테마)

| 콤보 | 조건 | 효과 (초안) |
|------|------|-----------|
| **군중 사기** | 원페어, 인접 | 패닉 임계값 50%→30% |
| **인해전술** | 플러시, 5장 올인 | 사망 시 1회 부활 (1명씩) |

### 5.5 복합 (무병종 특화)

| 콤보 | 조건 | 효과 (초안) |
|------|------|-----------|
| **풀하우스** | 트리플 + 페어 | 약한 쪽 병종이 강한 쪽의 버프 일부를 공유 |

**총 9개** (병종별 2개 × 4병종 + 복합 1개)

### 5.6 함정은 왜 제외?

- 함정은 이미 "비공개 배치" 특수 메카닉 보유
- 다른 병종과 구조가 다름 (HP 1, 1회용)
- 콤보 시스템에 편입 시 복잡도 폭증
- 단, **포카드 콤보의 "+ 함정 1개" 포지션**으로는 활용 (기병 4 + 함정 1)

## 6. 리스크 4가지와 완충 방법

### 6.1 리스크 1: 시너지 강도의 딜레마

- **너무 강하면** → "콤보 안 나온 라운드는 그냥 진다" → 드로우 운 의존 증가 (Anti-Pillar 위반 경계선)
- **너무 약하면** → 아무도 안 쓰고 묻힘 → 디자인 낭비

**완충 방법**: 시너지는 **효율 향상**이지 **필수 승리 조건**이 아니도록. 창병 혼자 놔도 약하지 않아야 함. 콤보 보너스 상한선 정해두기 (예: 스탯 +30% 넘지 않기).

### 6.2 리스크 2: 상위 콤보의 "승리 확정"

포커에서 로열 스트레이트 플러시는 사실상 승리 확정. DDworld의 포카드/플러시도 비슷한 강도면 "콤보 나온 사람이 이긴다" 게임이 됩니다.

**완충 방법**: 상위 콤보는 **강력하지만 카운터 가능**하게. **"콤보 vs 콤보"의 상호 카운터 구조** 설계.

예시:
- 기병 포카드(쐐기 강화) ↔ 창병 방진(Box) — 완전 무효화
- 민병대 플러시(인해전술) ↔ 궁병 일제 사격 — 대량 광역
- 궁병 일제 사격 ↔ 기병 돌격 — 빠른 접근

가위바위보 구조를 상위 콤보에서도 유지.

### 6.3 리스크 3: 이월 전략의 강제화

"이월을 잘 활용하는 플레이어가 지배"하는 구조가 되면, 모든 플레이어가 매 라운드 이월 계산에 매달림 → cognitive load 폭증.

**완충 방법**: "1라운드에도 즉각 배치 가능한 5장"을 꾸준히 유효하게 유지. 즉발 전략과 콤보 전략이 공존해야 함.

구체적으로:
- 원페어/투페어 같은 **하위 콤보는 즉시 발현 가능** (이월 불필요)
- 풀하우스/포카드/플러시 같은 **상위 콤보만 이월 필요**
- 즉발 전략 승률을 콤보 전략과 비슷하게 유지 (프로토타입에서 수치 조정)

### 6.4 리스크 4: Cognitive Load

Phase 3 리뷰에서 이미 배치 단계 6항목 한계선 경고. 여기에 "시너지 규칙"이 추가되면 7~8개.

**완충 방법**: 시너지를 **시각적으로** 드러내기.

- 팔랑크스 준비된 창병 2개가 배치될 때 둘 사이에 **방패 이펙트 미리 표시**
- 플레이어가 "규칙"을 읽는 대신 "그림"을 읽게 됨 (클래시 오브 클랜의 "공격 범위 표시" 같은 UX)
- 배치 중 실시간으로 "현재 손패로 가능한 콤보" 힌트 표시 (옵션, 숙련자는 끔)

## 7. MVP 전개 전략: 방향 B (선택됨)

### 7.1 두 방향 비교

| | 방향 A: 처음부터 8개 전부 | 방향 B: 단계적 도입 (선택) |
|---|---|---|
| **MVP 콤보 수** | 8~9개 | 4개 (병종당 1개씩) |
| **장점** | 게임이 처음부터 깊이 있음 | 밸런싱 점진적, 비교 검증 가능 |
| **단점** | 프로토타입 검증 기간 길어짐, 밸런싱 리스크 큼 | 출시 콘텐츠가 단계적으로 느는 구조 |

### 7.2 방향 B 선택 이유

1. Anti-Pillar "랜덤 운 게임이 아니다"가 실제로 지켜지는지 **콤보 없는 버전에서 먼저 검증** 필요
2. 콤보가 오히려 운 요소를 키우는지 아닌지는 **비교 데이터가 있어야** 판단 가능
3. 1인 인디의 반복 테스트 여력 고려
4. MVP 4개 → Alpha 8~9개 확장의 자연스러운 콘텐츠 로드맵

### 7.3 단계별 콘텐츠 로드맵

#### Phase 0: 프로토타입 초기 (콤보 없음)
- 반복 피로도 가설 검증
- 코어 루프만으로 심리전이 충분히 재미있는지 확인
- "콤보 없어도 된다"는 판단이 나오면 §8 시너지 시스템은 **도입 안 할 수도 있음**

#### Phase 1: MVP (병종당 1개씩 = 4개 콤보)
- 가장 상징적인 콤보 하나씩만 선택
- 추천: 팔랑크스(창병), 쐐기 진형(기병), 집중 사격(궁병), 군중 사기(민병대)
- 모두 **하위 콤보(원페어/트리플)**로 시작 — 즉발 가능, 이월 불필요

#### Phase 2: Alpha (콤보 확장, 이월 전략 도입)
- 병종별 2개씩 + 복합 = 9개로 확장
- 풀하우스/포카드/플러시 같은 **상위 콤보** 추가 → 이월 전략 활성화
- 콤보 간 카운터 구조 밸런싱

## 10. 부록: 운의 두 종류 — Anti-Pillar 재해석 기준

### 10.1 왜 이 섹션이 필요한가

"드로우도 운인데 Anti-Pillar 위반 아닌가?"라는 질문은 앞으로 반복될 가능성이 큽니다 (피드백, 리뷰, 외부 자문 등). 이 섹션은 **그 질문의 표준 답변**입니다.

### 10.2 게임 디자인에서 "랜덤"은 두 종류

| 구분 | 정의 | 플레이어 경험 |
|------|------|-------------|
| **Input Randomness** (입력 랜덤) | 플레이어가 **결정 내리기 전**에 랜덤이 결정됨 | "이 재료로 어떻게 최선을 만들까?" (판단 요구) |
| **Output Randomness** (출력 랜덤) | 플레이어가 **결정한 후**에 랜덤이 적용됨 | "결정했는데 운으로 빗나갔다" (판단 무력화) |

### 10.3 각 종류의 역할

**Input Randomness는 "흥미로운 판단의 재료"** — 없으면 게임이 솔브됨 (체스/틱택토)
**Output Randomness는 "판단의 무효화"** — 많으면 실력이 무의미해짐 (주사위 게임)

**전략 게임의 보편적 원칙**:
> Input Randomness는 적극 활용. Output Randomness는 최소화.

### 10.4 Sid Meier의 원칙

> "**불확실성 없이는 흥미로운 결정이 없다.**"
> — Sid Meier (Civilization 디자이너)

포커가 재미있는 이유는 **매번 새 손패가 와서 새 문제가 되기 때문**입니다. 모든 플레이어가 매 판 같은 손패를 받으면 포커는 죽습니다.

### 10.5 DDworld의 운 분석

#### Input Randomness (활용됨) ✅
- **드로우 8장**: 랜덤, 단 양쪽 **동일한 확률 분포**. 받은 패로 최선의 배치 판단
- **상대 손패 공개**: 상대도 같은 불확실성 하에 있음
- **포커 핸드 콤보** (도입 시): 어떤 콤보가 가능한지가 드로우에 따라 다름 → 매 라운드 새 문제

#### Output Randomness (최소화됨) ✅
- **궁병 명중률 75%**: 있긴 함. 단, 배치의 큰 그림을 바꿀 정도는 아님
- **크리티컬 시스템**: 아직 미도입 (도입 시 Output Randomness 증가 주의)
- **판돈 정산**: 잔존 병사 계산은 결정론 (운 없음)

### 10.6 대칭성이 결정적

DDworld가 "운 게임이 아닌" 결정적 이유는 **대칭성**:

1. 양쪽 동일한 덱 (45장 동일 구성)
2. 양쪽 손패 공개 (8장 전체)
3. 양쪽 동일한 규칙 (배치 5장, 5판 3선승)

**클래시 로얄**이 운/P2W 비판을 받는 이유는 이 대칭이 깨져있기 때문:
- 상대 덱 비공개
- 카드 레벨 비대칭 (과금 차이)
- 엘릭서 타이밍 비대칭

DDworld에는 비대칭이 없습니다. 운이 불공평하게 작용할 구조가 아닙니다.

### 10.7 Anti-Pillar의 정확한 해석

game-concept.md의 Anti-Pillar 원문:

> **랜덤 운 게임이 아니다** — 드로우 운이 아닌 **배치 판단**이 승패를 결정

이 문구는 이미 **"드로우는 있지만 승패 결정 요인이 아니다"** 를 명시하고 있습니다. 정확한 해석:

```
❌ 랜덤이 0이다
✅ 랜덤은 판단의 재료일 뿐, 승패를 지배하지 않는다
```

### 10.8 경계선: 언제 "운 게임"으로 넘어가는가

운이 "있다"에서 "지배한다"로 넘어가는 경계선 3가지. 콤보 시스템 도입 시 특히 주의:

#### 경계선 1: 상위 콤보가 너무 강하면
포카드나 플러시가 거의 자동 승리를 준다면 "누가 포카드 뜨느냐"게임이 됨 → Anti-Pillar 위반
**완충**: §6.2 카운터 구조로 완화

#### 경계선 2: Output Randomness 확대
크리티컬 확률을 너무 높이면 "운 좋아서 크리티컬 5연속" 결과 발생
**완충**: 크리티컬은 "보너스" 수준으로만. 베이스 승률을 뒤집지 않을 정도

#### 경계선 3: 드로우 편차의 극단
극단적으로 불리한 손패(예: 민병대 8장) 가능성
**완충**: 이월 시스템 3장이 완충 장치. 5판 3선승이 한 라운드 운을 평균화

### 10.9 참고: Sid Meier 인용 출처

- Sid Meier's Memoir! (2020, W.W. Norton)
- GDC 강연 "Interesting Decisions" (2012)

### 10.10 결론

**Anti-Pillar "랜덤 운 게임이 아니다"는 유지하되 해석을 명확히 합니다**:

```
해석: 랜덤이 0이 아니라, 랜덤이 승패를 지배하지 않는다는 뜻.
      드로우는 Input Randomness로 "판단의 재료"이며,
      Output Randomness는 최소한으로 유지되어야 한다.
```

이 해석은 GDD 본문 수정 없이도 일관됩니다. Anti-Pillar 본문("드로우 운이 아닌 배치 판단이 승패를 결정")이 이미 이 구분을 담고 있기 때문입니다.

## 11. 덱 빌딩 도입 (Option B + C 조합)

### 11.1 도입 배경

§3~§7의 콤보 시스템에 더해, 플레이어가 "나는 기병 특화 덱으로 러시를 쳐보고 싶다" 같은 **특화 덱 구성**의 재미를 추구할 수 있도록 덱 빌딩 요소를 도입합니다. 단, 대칭성 훼손을 최소화하는 방식으로 설계합니다.

### 11.2 대칭성의 3개 층위

| 층위 | 내용 | 심리전 기여도 | 덱 빌딩 시 훼손? |
|------|------|-------------|---------------|
| 구조적 대칭 | 규칙, 그리드 크기, 배치 수 | 필수 | ❌ 훼손 없음 |
| 자원 대칭 | 덱 구성, 카드 풀 | 중간 | ✅ **이게 훼손됨** |
| 정보 대칭 | 상대 손패 공개 | 필수 | ❌ 훼손 없음 (유지) |

덱 빌딩은 **자원 대칭만 훼손**하고 나머지 두 층위는 유지. 따라서 "운 게임"이 되지는 않지만, 전략 공간의 성격이 달라집니다.

### 11.3 선택된 방향: Option B + C

#### Option B: 매치 전 덱 공개

- 매치 시작 전 양쪽 덱 구성 45장이 서로 공개됨
- 양쪽이 상대 덱을 **알고** 배치 전략 수립
- 현재 DDworld의 "손패 공개" 철학과 완벽히 일관됨
- **심리전이 덱 메타 레이어까지 확장**

#### Option C: 병종당 5~15장 제약

- 총 45장 유지
- 각 병종 최소 5장, 최대 15장
- 극단적 비대칭 자동 방지

#### 참고한 디자인 모델

| 모델 | 예시 | DDworld 적합성 |
|------|------|--------------|
| 완전 비대칭 | 하스스톤, MTG | ❌ 심리전 붕괴 |
| **매치 전 덱 공개** | — (희귀) | ⭐ 최적 |
| 제약 프레임 | 매직 리미티드 | ✅ 적합 |
| 매치 내 드래프트 | 오토체스류 | ✅ 적합 |

**바둑의 접바둑 원리**: 비대칭 조건이어도 **양쪽이 알고 시작하면 공정**합니다.

### 11.4 제약의 수학적 특성

5병종 × min 5장 = 25장 베이스. 남은 20장을 어떻게 분배하느냐가 특화의 핵심.

| 특화 수준 | 가능성 | 조합 예시 |
|---------|-------|----------|
| 1병종 집중 (1개만 15장) | ✅ 가능 | 15 + 10 + 10 + 5 + 5 |
| 2병종 집중 (2개 15장) | ✅ 가능 | 15 + 15 + 5 + 5 + 5 |
| 3병종 집중 (3개 15장) | ❌ 불가능 | 15×3 = 45 → 나머지 2병종 min 위반 |
| 완전 올인 (1병종 45장) | ❌ 불가능 | max 15 위반 |

**설계적 우수성**: 특화는 **최대 2병종까지만** 가능. "3병종 동시 올인"이 수학적으로 차단되어 극단적 지배 전략 방지.

### 11.5 주요 덱 시나리오 7가지

#### 시나리오 A: 균형 덱 (기본/디폴트)

```
기병 10 / 창병 10 / 궁병 10 / 민병대 10 / 함정 5
```
- **성격**: 범용 대응
- **콤보 발현률**: 각 병종 트리플 ~30%
- **포지셔닝**: 덱 빌딩 부담 싫은 플레이어의 기본 선택지

#### 시나리오 B: 기병 러시 덱

```
기병 15 / 창병 5 / 궁병 10 / 민병대 5 / 함정 10
```
- **성격**: 공격적 속공
- **강점**: 궁병덱에 압승, 느린 덱 상대 유리
- **약점**: 창병 방진에 카운터당함

#### 시나리오 C: 창병 요새 덱

```
기병 5 / 창병 15 / 궁병 10 / 민병대 5 / 함정 10
```
- **성격**: 방어 + 반격
- **강점**: 기병 러시 완벽 차단
- **약점**: 원거리 딜링 부족, 궁병 포격에 녹음

#### 시나리오 D: 궁병 포격 덱

```
기병 5 / 창병 10 / 궁병 15 / 민병대 10 / 함정 5
```
- **성격**: 원거리 누킹
- **강점**: 창병덱, 민병대덱에 우위
- **약점**: 기병 러시에 매우 취약

#### 시나리오 E: 민병대 인해 덱

```
기병 5 / 창병 10 / 궁병 5 / 민병대 15 / 함정 10
```
- **성격**: 물량 + 지속 압박
- **강점**: 기병덱, 함정덱 상대 강함
- **약점**: 궁병덱에 광역 잡힘

#### 시나리오 F: 함정 지뢰밭 덱 ⚠️ 특이 케이스

```
기병 5 / 창병 10 / 궁병 5 / 민병대 10 / 함정 15
```
- **성격**: 정적 방어, 상대 진군 통제
- **강점**: 상대 진군 예측 시 파괴적
- **⚠️ 치명적 약점**: 함정은 판돈 계산 제외 → 이겨도 판돈 적립 매우 낮음
- **자연적 제한**: 경제 불이익으로 메타에서 약함 → 자기 밸런싱 효과

#### 시나리오 G: 2병종 올인 (극단)

```
기병 15 / 창병 15 / 궁병 5 / 민병대 5 / 함정 5
```
- **성격**: 근접 전투 완전 특화
- **강점**: 창병 방어벽 뒤 기병 쐐기 조합
- **약점**: 궁병 포격 덱에 압도적 불리

### 11.6 매치업 매트릭스 (초안)

| | 균형 | 기병 | 창병 | 궁병 | 민병 | 함정 | 기·창 |
|---|---|---|---|---|---|---|---|
| **균형** | - | 중립 | 중립 | 중립 | 중립 | 중립 | 중립 |
| **기병** | 중립 | - | 불리 | 유리 | 중립 | 유리 | 중립 |
| **창병** | 중립 | 유리 | - | 불리 | 유리 | 유리 | 중립 |
| **궁병** | 중립 | 불리 | 유리 | - | 유리 | 유리 | 매우 유리 |
| **민병** | 중립 | 중립 | 불리 | 불리 | - | 유리 | 불리 |
| **함정** | 중립 | 불리 | 불리 | 불리 | 불리 | - | 불리 |
| **기·창** | 중립 | 중립 | 중립 | 매우 불리 | 유리 | 유리 | - |

#### 관찰 사항

1. **완벽한 가위바위보 구조 없음** — 궁병 상대적 강세, 함정 상대적 약세 (프로토타입에서 밸런스 조정 필요)
2. **함정덱은 경제 페널티로 자연 제한** (판돈 제외)
3. **균형 덱은 중립 포지션** — 초보자/범용 선택지
4. **2병종 올인은 고위험 고보상** — 카운터 당하면 완전 불리
5. **지배 전략 부재** ✅ — 어떤 덱도 모든 매치업에서 유리하지 않음

### 11.7 덱 공개의 심리전 4레이어

기존 DDworld의 심리전 구조가 **4레이어로 확장**:

```
1단계: 매치 시작 전 — 덱 메타 읽기 (신규)
  "상대 기병 15장 특화. 나는 균형 덱이지만 창병 위주 배치로 대응해야겠다"

2단계: 매 라운드 — 손패 읽기 (기존)
  "기병 3장 손패. 쐐기 진형 준비 중이군"

3단계: 매 라운드 — 이월 읽기 (콤보 시스템 연계, §3 참조)
  "기병 2장 이월. 다음 라운드 쐐기 콤보 확정"

4단계: 배치 — 그리드 읽기 (기존)
  "오른쪽 열에 쐐기 오는군, 중앙에 방진 배치"
```

심리전이 매치 시작 전부터 시작됨. DDworld의 핵심 강점이 증폭되는 구조.

### 11.8 밸런싱 숙제 3가지

#### 숙제 1: 궁병덱 과강 가능성

매치업 매트릭스에서 궁병덱이 3개 덱 상대로 유리. 프로토타입에서 검증 필요.
**완충**: 기병덱이 궁병덱 카운터 → 메타에서 기병 비중 높아지면 자연 조정

#### 숙제 2: 덱 메타 고정화

시간이 지나면 "최강 덱"이 발견되고 모두가 복사 → 다양성 붕괴 리스크.
**완충**:
- 덱 공개 메커닉이 **카운터 픽**을 유도 → 고정 덱 불가능 (상대 덱에 따라 내 배치 전략 달라짐)
- 매치업 다양성이 균형 덱을 보상

#### 숙제 3: 신규 플레이어 진입 장벽

덱 빌딩 자유도가 높으면 초보자가 "뭘 어떻게 해야 할지" 모름.
**완충**:
- **균형 덱(시나리오 A)을 기본 프리셋**으로 제공
- 튜토리얼/초보자는 균형 덱으로 시작
- 경험 쌓이면 커스터마이징 언락

### 11.9 이월 시스템과의 연계

덱 빌딩이 도입되면 이월 시스템의 전략적 의미가 **또 한 번 격상**됩니다:

- 기병 15장 특화 덱 → 손패에 기병 3장 이상 나올 확률 ~55%
- "이번 라운드 즉발 쐐기 진형 가능 여부" 빈도 증가
- 이월 전략: 다음 라운드까지 콤보 재료 보존 선택지 증가

**결과**: 덱 빌딩 × 콤보 시스템 × 이월 시스템 삼중 상호작용으로 리플레이성 극대화.

## 12. Anti-Pillar "복잡한 경영 게임이 아니다" 재해석

### 12.1 필요성

덱 빌딩 도입은 Anti-Pillar 3번째 항목 "복잡한 경영 게임이 아니다"와 표면적 충돌. 이 해석을 명확히 할 필요.

### 12.2 해석 방향

```
기존: 복잡한 경영 게임이 아니다
      — 핵심은 매치 내 심리전, 메타 시스템은 보조

수정: 무거운 경영 게임이 아니다
      — 매치 내 심리전이 핵심. 덱 구성은 "가벼운 메타"로 허용
      (병종 비율 조정만). 카드 수집/강화/레벨링 시스템은 도입하지 않는다.
```

### 12.3 "가벼운 메타" vs "무거운 메타" 선긋기

| 허용 (가벼운 메타) | 배제 (무거운 메타) |
|-----------------|-----------------|
| 병종 비율 조정 (5~15장 범위) | 카드 수집 시스템 |
| 덱 슬롯 저장/불러오기 | 카드 강화/레벨링 |
| 덱 이름 지정 | 희귀도 등급 |
| 전적 통계 | 카드 뽑기/상자 |
| 덱 공유 기능 (향후 옵션) | 유료 카드 팩 |

**기준**: **"매치 간 준비 시간이 매치 시간을 넘지 않는다"** — 이게 "무거운 경영"으로 넘어가는 경계선.

### 12.4 포지셔닝 비교

| 장르 | 비교 | DDworld 포지션 |
|------|------|--------------|
| 순수 심리전 | 체스, 배틀십 | 이쪽에서 출발 |
| 라이트 덱 빌딩 | **매직 리미티드 수준** | ⭐ 여기로 이동 |
| 중간 덱 빌딩 | Slay the Spire (싱글) | 넘지 않음 |
| 헤비 덱 빌딩 | 하스스톤, MTG, 클래시 로얄 | 절대 넘지 않음 |

**DDworld는 "라이트 덱 빌딩"까지만.** 클래시 로얄 수준의 덱 빌딩은 하지 않음.

### 12.5 game-concept.md 업데이트 제안

Anti-Pillar 문구는 **확정 시** game-concept.md에서 수정:

```markdown
- **무거운 경영 게임이 아니다** — 핵심은 매치 내 심리전.
  덱 구성(병종 비율)은 가벼운 메타로 허용하되,
  카드 수집/강화/레벨링/뽑기 시스템은 도입하지 않는다.
```

단, 이 수정은 **프로토타입 검증 후** 정식 반영. 지금은 이 리서치 노트에서 방향만 기록.

## 13. 카드 획득 방식: 상자 뽑기 도입 (확정)

### 13.1 결정 사항

**✅ 상자 뽑기를 메인 카드 획득 방식으로 채택.** 인게임 재화(판돈)로만 구매 가능. 외부 결제 도입 없음.

### 13.2 결정 근거

#### 근거 1: 장기 운영 가능성

PvP 게임이 장기적으로 돌아가려면 **반복 가능한 카드 획득 루프**가 필요. 직접 구매는 "원하는 카드 다 모으면 끝" 구조라 장기 동기 부여가 약함. 상자 뽑기는 매번 새로운 결과로 **무한 반복 가능한 루프**를 만듦.

#### 근거 2: 종족 확장 대응

향후 **종족(덱 구성이 아예 다른) 추가** 같은 대규모 콘텐츠 확장 시, 신규 카드 풀에 대한 획득 시스템이 필요. 직접 구매로는 신규 카드의 등장/홍보 효과가 약함. 상자 뽑기는 신규 카드 도입 시 자연스러운 "탐색 동기"를 만듦.

#### 근거 3: 무료 게임 내 재화 한정

외부 결제 없음 + 인게임 재화로만 구매 = **클래시 로얄식 P2W 비판 회피**. 시간/실력 투자에 따른 보상이지 돈으로 사는 구조 아님.

### 13.3 핵심 설계 방향

#### 플레이어 선택권으로 랜덤 완화

> **"상자에서 뽑고 싶은 카드를 플레이어 본인이 선택해서 확률을 조금 더 높일 수 있다"**

순수 랜덤 상자가 아닌 **"플레이어가 우선순위를 지정하는 가중치 랜덤"** 구조. 예시:

```
플레이어가 "기병 우선" 선택 → 상자 결과: 기병 출현 확률 상향
플레이어가 "함정 우선" 선택 → 상자 결과: 함정 출현 확률 상향
```

이 메커닉의 장점:
- "원하는 카드 안 나오는 좌절" 완화 (확정은 아니지만 의도 반영)
- 플레이어 의도와 결과의 연결성 회복
- 순수 랜덤 상자와 직접 구매의 중간 지점

### 13.4 후속 논의 사항 (스펙 미정)

다음 항목들은 다음 세션 또는 프로토타입 검증 단계에서 결정:

- [ ] 상자 종류 및 가격대 (브론즈/실버/골드 등 티어 구조)
- [ ] 각 상자별 카드 출현 확률
- [ ] 플레이어 우선순위 선택 시 확률 가중치 (예: +10%? +30%?)
- [ ] 중복 카드 처리 방식 (분해 → 다른 카드 교환? 자동 환불?)
- [ ] 보장(pity) 시스템 — 일정 횟수 내 희귀 카드 확정 등장 여부
- [ ] 상자 1개당 카드 수량 (1장? 3장? 5장?)
- [ ] 신규 플레이어 초기 보장 (튜토리얼 보상으로 균형 덱 1세트 자동 지급?)
- [ ] 함정 카드의 희귀도 처리 (현재 덱 5장 vs 다른 병종 10장 비율 반영)

### 13.5 Anti-Pillar 호환성 재검토

상자 뽑기 도입 시점에 Anti-Pillar "랜덤 운 게임이 아니다"와 충돌 가능성. 해석:

```
운의 두 종류 (§10) 프레임 적용:

매치 내 운 = Input Randomness (드로우, 콤보 발현)
  → 판단의 재료, Anti-Pillar 위반 아님

매치 밖 카드 획득 운 = "메타 진행 운"
  → 매치 결과에 직접 영향 없음 (덱은 매치 시작 전 양쪽 공개됨)
  → "한 매치의 승패"에 운이 작용하는 것이 아니라
     "장기 덱 빌딩"에 운이 작용
  → 플레이어 선택권(가중치)으로 완화
  → 외부 결제 없으므로 "공정한 운"
```

**결론**: 상자 뽑기는 **"매치 내 심리전"의 운 요소가 아니라 "메타 진행"의 운 요소**. Anti-Pillar 본문("드로우 운이 아닌 배치 판단이 승패를 결정")이 다루는 영역과 다름. 따라서 충돌 없음.

### 13.6 D-01 자원 싱크 해결

상자 뽑기 도입으로 economy.md의 D-01(자원 싱크 미정의) 완전 해결:

```
판돈 = 매치 승리의 점수 + 상자 구매 통화
```

연쇄 업데이트 필요 항목 (확정 시):
- economy.md Core Rule 5 수정 ("점수 역할만" → "점수 + 상자 구매")
- economy.md Dependencies에 Deck 추가
- deck.md Dependencies에 Economy 추가
- D-01 공식 해결 선언

### 13.7 클래시 로얄 사례에서 배울 점

상자 뽑기 시스템 설계 시 **피해야 할 안티패턴**:

| 안티패턴 | DDworld 회피 방법 |
|---------|----------------|
| 시간 잠금 (대기 시간 후 개봉) | 즉시 개봉. 시간 잠금 없음 |
| 외부 결제로 시간 단축 | 외부 결제 자체 없음 |
| 카드 레벨업 시스템 | 도입 안 함 (Anti-Pillar 유지) |
| 매칭에 카드 레벨 영향 | 카드 파워 동등 유지 |
| FOMO 한정판 상자 | MVP에서는 도입 안 함 (Alpha 이후 재검토) |

다음에 다룰 순서 (제안):

2. **확률 가중치 메커닉** — 플레이어 선택권 구체 설계
3. **중복 카드 처리** — 분해/환불/교환 시스템
4. **보장(pity) 시스템** — 좌절 완화 장치
5. **신규 플레이어 온보딩** — 초기 균형 덱 자동 지급 등
