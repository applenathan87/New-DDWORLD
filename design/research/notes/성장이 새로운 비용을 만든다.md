# 성장이 새로운 비용을 만든다

## 핵심
루프가 계속 돌아가려면 플레이어가 "충분히 벌었다"고 느끼는 순간이 오면 안 된다. 성장할수록 수입이 늘지만, **지출도 같이 늘어나야** 탐험할 이유가 사라지지 않는다.

> **"성장 = 새로운 비용의 시작"이어야 루프가 멈추지 않는다.**

## 레퍼런스: Dave the Diver의 경제 순환

```
[수입]                    [지출]
요리 판매 ──────→ 골드 ──────→ 장비 (단발, 점점 비쌈)
                    │         직원 고용 (단발, 비쌈)
                    │         직원 훈련 (장기, 기하급수적)
                    │         직원 운영비 (매일, 성장할수록 증가)
                    │         소모품 (매일, 선택적)
                    ↓
               항상 부족함
```

### 지출의 세 가지 유형
| 유형 | 특징 | 예시 |
|---|---|---|
| **고정 지출** | 매일 자동으로 빠짐, 성장할수록 증가 | 직원 운영비 |
| **성장 지출** | 단발이지만 다음 단계가 기하급수적으로 비쌈 | 장비·무기 업그레이드, 직원 훈련 |
| **선택 지출** | 없어도 되지만 있으면 편해짐 | 소모품, 인테리어 |

### 왜 작동하는가
- 직원을 많이 뽑으면 편해짐 → but 운영비 증가 → 더 벌어야 함
- 장비를 올리면 효율 증가 → but 다음 업그레이드가 더 비쌈 → 더 벌어야 함
- **편해지는 만큼 새로운 비용이 생겨서**, 플레이어는 항상 "조금 더 벌어야지" 상태에 머무름

## 설계 원칙

1. **수입과 지출이 같이 성장해야 한다** — 수입만 늘면 루프가 멈추고, 지출만 늘면 좌절함
2. **고정 지출로 바닥을 만들어라** — 매일 빠지는 비용이 있어야 "가만히 있으면 안 됨"의 감각이 생김
3. **성장 지출은 기하급수적으로** — 초반에는 쉽게 올리고, 후반에는 한 단계가 무거워야 장기 목표가 됨
4. **선택 지출로 욕심을 자극** — 없어도 되지만, 써보면 안 쓸 수 없게 만들기
5. **"충분하다"는 순간을 최대한 늦춰라** — 새로운 지출처가 주기적으로 열려야 함 (언락 페이싱과 연결)

## 주의할 점
- 지출이 너무 빠르면 "벌어도 벌어도 모자라" → 좌절 → 이탈
- 핵심은 **"약간 부족한" 상태를 유지**하는 것. 넉넉하지도, 쪼들리지도 않은 지점
