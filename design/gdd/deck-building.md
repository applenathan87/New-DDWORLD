## 1. Overview

런 동안 플레이어의 덱이 누적 변화하며 빌드 정체성을 형성하는 시스템. 기존 [deck.md](deck.md)가 이미 "런 단위 덱 — 매치 사이 상점/이벤트에서 카드 추가/강화/패시브 획득"을 정의하고 있으나, **개별 유닛 카드의 강화/진화 방식**이 미정의 영역으로 남아 있다. 이 문서는 그 영역을 탐색한다.

핵심 질문: **"내 덱이 자라난다"는 감각을, 심리전 코어를 깨뜨리지 않고 어떻게 구현할 것인가?**

## 2. Player Fantasy

- **내 덱이 자라난다는 감각** — 런 초반의 경기병이 후반에는 정예 기병대로 성장
- **매 런마다 다른 빌드 서사** — 진화 분기 + 조건부 해금으로 같은 시작 덱에서도 다른 결말
- **새로운 심리전 변수** — 상대의 진화 상태가 시각적으로 드러나 패 읽기의 새 차원이 됨

## 3. Detailed Rules (탐색 노트)

### 3.0 디자인 텐션 (Pre-condition)

강화 시스템은 **Pillar 2(빌드 서사)와 심리전 코어 사이의 텐션**을 안고 있다.

- 강화가 복잡해질수록 → 빌드 서사는 풍부해지나 → 상대 패를 읽기 어려워짐 (심리전 약화)
- 좋은 강화 디자인은 "**상대도 내 진화 상태를 시각적으로 볼 수 있게**" 만들어, 강화 자체가 심리전의 새 변수가 되는 방향

이 원칙이 아래 옵션 평가의 기준점이다.

---

### 3.1 강화의 축 (What is enhanced?)

#### 옵션 A — 병종 진화 (Class Evolution)

- 경기병 → 중기병 → 정예기병, 궁병 → 석궁병 → 공성궁
- **장점**: 직관적, 시각적 차이 명확(모델/색 교체), RPG식 성장 쾌감, 상대도 보면 바로 인지 → 심리전 변수로 활용 가능
- **단점**: 진화 트리가 깊어지면 분기 폭발 / 밸런싱 부담
- **추천 형태**: 2~3단계 + 분기 (중기병에서 → 정예기병 OR 돌격기병 선택). **Bad North 업그레이드 트리** 방식
- **평가**: 메인 축으로 가장 유력

#### 옵션 B — 병사 수 증가 (Soldier Count)

- 1유닛 = 10명 → 15명 → 20명
- **장점**: 강해진 게 시각적으로 압도적
- **단점**: 200 유닛 폴리곤 예산 충돌 가능, 너무 직관적이라 "빌드 서사"가 약함 (그냥 숫자가 늘 뿐)
- **평가**: 메인 축으로는 약함. **진화의 부차 효과**로 (중기병 = 더 큰 말 + 머릿수는 동일/소폭 증가)

#### 옵션 C — 능력 / 태그 부여 (Ability / Tag)

- "돌격 첫 충돌 크리티컬", "생존 시 다음 라운드 +HP", "옆에 같은 태그 있으면 보너스"
- **장점**: 빌드 다양성 폭발, 조합의 재미 (Slay the Spire 렐릭 방식)
- **단점**: 인지 부담 — 상대 카드의 능력을 모두 파악해야 패를 읽을 수 있음 → **심리전 코어와 충돌 가능**
- **평가**: 메인 축은 위험. **보조 축으로**. 능력은 카드 위에 아이콘으로 항상 표시되어야 가독성 확보

#### 옵션 D — 능력치 미세 강화 (Stat Boost)

- HP +20%, ATK +15% 같은 숫자 강화
- **장점**: 구현 간단, 밸런싱 직관적
- **단점**: 빌드 서사가 안 생김, "내 덱이 자라는" 느낌이 약함
- **평가**: 단독으로는 약함. **진화의 부수 효과** 또는 "이번 라운드 한정 부스트" 같은 일시 효과로

---

### 3.2 강화를 얻는 방식 (How obtained?)

| 방식 | 설명 | Pillar 2 적합도 |
|------|------|----------------|
| 선택형 (3개 중 1개) | Slay the Spire 방식 | ★★★ 선택 직접 충족 |
| 자동 부여 | 라운드 클리어마다 자동 | ★ 서사 약함 |
| 조건부 해금 | "기병으로 3승하면 중기병 해금" | ★★★ 발견 직접 충족 |
| 합성 (3장 → 1장) | Hearthstone Battlegrounds 방식 | ★★ 덱 관리 의미 생김 |

**현 방향**: **선택형 + 조건부 해금 조합**. 조건부 해금은 "발견"을, 선택형은 "선택"을 만든다.

---

### 3.3 강화의 범위 (Scope)

- **개별 카드 단위**: 이 경기병 카드 1장만 중기병으로 (덱 안에 경기병/중기병 혼재)
- **병종 단위**: 모든 경기병 카드가 한 번에 중기병으로 변환
- **덱 단위 패시브**: "이 덱의 모든 기병에 +1 ATK"

**현 방향**: **개별 카드 단위**가 가장 흥미로움.
- 덱 구성의 의미가 생김 ("경기병 3장 중 1장만 진화시켜 폭격 카드로 운영")
- 상대도 카드를 보고 진화 정도를 파악 가능 → 심리전 변수
- 분기 트리와 자연스럽게 결합

---

### 3.4 지속성 (Persistence)

- **Run 한정**: 이번 런에서만, 다음 런은 초기화
- **Meta 영구**: 일부 진화는 다음 런으로 이어짐

**현 방향**: **Run 한정 기본**, 런 클리어 시 일부 "영구 해금" (해당 병종을 다음 런부터 덱에 넣을 수 있는 권한 같은 메타 보상).
- P2W 느낌 방지하면서도 장기 동기부여 확보
- BM(monetization) 연구 노트와 충돌하지 않음 (해금이 결제와 무관)

---

### 3.5 현 추천 조합 (Working Recommendation)

| 축 | 선택 |
|----|------|
| **메인 축** | 병종 진화 (개별 카드 단위, 분기 트리, 선택형) |
| **보조 축** | 능력 부여 (조건부 해금, 카드 위 아이콘 1개 표시) |
| **부수 효과** | 진화 시 능력치/병사 수가 자연스럽게 따라옴 (시각적 임팩트) |
| **자원 획득** | TBD — 라운드 클리어 자동 vs 골드 구매 vs 특정 조건 |
| **지속성** | Run 한정 + 일부 영구 해금 |

**기대 효과 자체 평가:**
1. **Pillar 2 충족** — 매 런에서 "내 경기병이 어떤 트리로 자라났나"의 서사 생성
2. **심리전 충족** — 상대 카드의 진화 단계가 시각적으로 보이고, 능력 아이콘 1개로 제약 → 패 읽기 가능
3. **리플레이성 충족** — 분기 트리 + 조건부 해금 = 매 런 다른 빌드

## 4. Formulas

> 탐색 단계 — 옵션 확정 후 정의.
>
> 검토 필요 항목:
> - 진화 시 stat 증가 공식 (e.g. 중기병 = 경기병 HP × 1.5, ATK × 1.3?)
> - 능력 발동 조건/효과 공식 (e.g. "첫 충돌 크리티컬" = 첫 공격 데미지 × 2)
> - 진화 자원 획득률 / Run당 평균 진화 횟수

## 5. Edge Cases

> 탐색 단계.
>
> 후속 정의 필요:
> - 진화한 카드가 매치 중에도 진화 상태 유지되는가? (런 단위 vs 매치 단위)
> - 진화 카드가 덱에서 제거되는 경우 (이벤트로 카드 삭제)
> - 동일 카드 중복 진화 (같은 경기병 3장 보유 시 각각 다른 트리로 진화 가능?)
> - 상대 고스트의 진화 상태가 시각적으로 어떻게 노출되는가
> - 진화 자원 0인 상태로 매치 진입

## 7. Tuning Knobs

> 탐색 단계 — 옵션 확정 후 정의.
>
> 예상 노브:
> - 진화 트리 깊이 (2단계 vs 3단계)
> - 각 단계 분기 폭 (2갈래 vs 3갈래)
> - 능력 풀 크기 (8개? 20개?)
> - Run당 진화 횟수 상한
> - 진화 자원 획득 곡선 (선형 vs 후반 가속)
> - 영구 해금 임계값

## 8. Acceptance Criteria

> 탐색 단계 — 옵션 확정 후 정의.
>
> 예상 AC:
> - 한 Run 내 평균 진화 횟수가 X회 이상이며, 동일 시작 덱에서 5번의 런이 모두 다른 최종 덱 구성을 산출한다
> - 상대 진화 상태가 카드 시각만 보고 100% 식별 가능하다 (심리전 가독성)
> - 능력 아이콘이 한눈에 인지되는 카드 디자인을 만족한다 (UX)
> - 진화 분기에서 도미넌트 전략이 없다 (밸런스 — 각 분기의 승률 차이 < 10%)

## Open Questions (다음 작업에서 논의)

다음 세션에서 이어갈 질문들. 우선순위 순:

1. **진화 트리 깊이/폭** — 2단계 + 2분기 vs 3단계 + 3분기? 깊이가 깊을수록 빌드 다양성 ↑ 밸런싱 부담 ↑
2. **진화 자원의 형태** — 라운드 클리어 시 자동 부여 vs 골드로 구매 vs 특정 조건 충족
3. **능력 풀 크기와 종류** — 보조 축인 능력을 몇 종류까지 풀에 넣을지 (8 / 12 / 20)
4. **Run당 진화 횟수 상한** — 밸런스 안정성과 빌드 서사의 균형
5. **고스트에 진화 상태 노출 방식** — 비동기 PvP에서 상대 진화를 어떻게 보여줄지 (UI/시각)
6. **영구 해금의 범위** — 어디까지를 메타 진행으로 가져갈지 (병종? 능력? 둘 다?)
