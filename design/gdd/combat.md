## 1. Overview

헥사 타일을 "클리어"하는 단위 전투. **적(몬스터) 진형이 100% 공개**된 상태에서, 플레이어가 5x5 그리드 자기 구역에 보유 덱(≤7장 중 ≤5부대)을 **카운터 배치**하고, **레인(열) 기반 자동 전투**로 결판낸다. 마이크로 조작 없음 — 배치가 전부(+ 마법사 액티브·아이템). 내가 키운 군대가 빛을 보는(또는 부서지는) 시험대.

## 2. Player Fantasy

- **"키운 군대로 해치웠다"** — 잘 빚은 빌드가 적 진형을 쓸어버리는 쾌감
- **가벼운 배치 판단** — 공개된 적 진형을 보고 내 패턴을 맞춰 까는 재미 (깊은 두뇌 퍼즐 아님)
- **보는 맛** — 수백 병사 충돌, 기병 인앤아웃 등 역동적 자동 전투
- **Anti-goal**: APM/마이크로 아님. **배치만으로도 이길 수 있어야 함**(baseline). 액티브는 양념.

## 3. Detailed Rules

### 전투 흐름 (PvE)

1. 헥사 타일 진입 → **적(몬스터) 진형 100% 공개**
2. 보유 덱 **≤7장 중 ≤5부대**를 5x5 자기 구역에 **자유 배치**(어느 칸이든)
3. 배치 확정 → 자동 전투 개시
4. 한쪽 전멸 시 종료 (일부 타일은 웨이브 2~3 = 난이도 knob, 보스는 페이즈)
5. 결과: 승리 = 타일 점령·보상 / **잔존 병사 HP 이월**(소모전) / **죽은 병사 소멸**(permadeath)
6. **진입 시 결과 확정**(되돌리기 X) + 오토세이브(수동 리로드 차단) → 세이브스컴 방지, permadeath 긴장 보호

### 공간 / 레인 모델

- 전장 = **5열 그리드**, 세로 진행. 유닛은 **자기 열(레인)을 따라 전진**, 같은 열 적과 교전.
- **열을 넘는 상호작용은 오직 공격 패턴으로** (관통=세로 깊이 / AoE=광역 / 곡사=타 레인 사정 / 넉백 등).
- 일부 유닛은 **고정**(함정, 마법사 후방 고정).

### 이동 모델 (구버전 계승)

- **속도 기반 연속 이동**(칸 점프 아님). 틱 = 시뮬 업데이트 단위(예 0.5s), 이동은 속도 기반.
  `position += direction * move_speed * tick_duration`
- **가속/감속**: 정지→최고속 점진 가속(고정 가속도). 넉백 후 속도 0 리셋 → 재가속.

### 틱 처리 순서 (결정론)

매 틱 모든 유닛 동시 행동: **이동 → 트리거(함정) → 공격 → 사망 → 상태(패닉 등)**. 같은 시드·배치 → 항상 같은 결과(테스트·재현·ADR-003 결정론).

### 이동 원칙 + 연쇄

- 기본 **자기 레인 정면 직진** ("가장 가까운 적 추적" 아님 → 배치가 매칭을 결정).
- **연쇄 재타겟**: 정면 적 전멸 → 가장 가까운 다음 적 탐색·이동 / 정면에 적 없이 끝 도달 → 주변 탐색. (멍하니 서 있지 않음 = "무식한 일자" 방지)

### 데미지

- 병사 **개별 HP·개별 행동**. **방어력 없음** — 데미지 = ATK.
- 밸런스 3요소: **ATK × HP × 병사 수**.

### 넉백

- **전체 넉백은 최소화**(거의 0, 유기적 흔들림 정도). **강한 넉백은 방패병 전용 패턴.**

### 상성

- **유닛 타입 상성표(RPS) 없음** — 우리는 거울 병종이 아니라 **몬스터**를 상대. 유불리는 **내 공격 패턴 × 몬스터 특성/진형**에서 창발 (적 디자인 = Q19).

### 플레이어 개입

- MVP: **마법사 액티브**(쿨 차면 마우스 타겟 메테오) + 사용 아이템(포션 등). 그 외 전부 자동.

### 병종별 공격 특성 (8종) — 핵심 차별화

| 병종 | 티어 | 이동 | 공격 패턴 | 레벨업 효과 |
|------|------|------|-----------|------------|
| **농부** | 브론즈 | 부채꼴 확산 전진 | 단순 근접 평타. **패닉**(분대 50%↓ 시 1초 도주 후 복귀) | 머릿수↑ |
| **사냥꾼** | 브론즈 | 멈춰 사격/없으면 전진 | 짧은 사거리 원거리(명중%). 약한 견제 | 머릿수↑ |
| **함정** | 브론즈 | 고정 | 적 진입 시 **범위 데미지 1회** 후 소멸 | 위력·범위↑ |
| **창병** | 실버 | 정면 전진 | **세로 관통** (앞열 + 그 뒤 적까지 동시 타격) | 머릿수↑ + 단단 |
| **궁병** | 실버 | 멈춰 사격/없으면 전진 | **곡사**(긴 사거리, 뒷열 노림) | 머릿수↑ + 사거리·딜 |
| **기병** | 실버 | **히트앤런** | 돌격(돌격 보너스)→후퇴→재정비→재돌격. 버스트, 후퇴 중 무딜 | 정예화(돌격 위력↑) |
| **마법사** | 실버 | 후방 고정 | **범위(AoE)** + **액티브 메테오**(타겟) | 정예화(위력↑) |
| **방패병** | 실버 | 느린 전진(벽) | **강한 넉백**(접근 적 밀어냄·전진 차단) → 카이팅 enabler | 정예화(넉백 세기·범위) |

> **창발 시너지 예시**: 방패병(넉백) + 궁병/마법사 = "못 붙게 하고 갈아버리는" 빌드 / 창병 관통 = 줄지어 오는 몬스터에 강 / 마법사 AoE = 몬스터 떼에 강 / 기병 = 물렁한 후열 다이브.

## 4. Formulas

- `soldier_damage = attack` (방어력 없음). 분대 총딜 ≈ `alive_count × attack`.
- 이동: `position += direction * move_speed * tick_duration`.
- **미정(프로토타입 튜닝)**: 돌격 보너스 배수·후퇴 거리·재돌격 쿨 / 넉백 거리 / 사거리·명중% / 패닉 임계 / 레벨별 스탯 곡선. (밸런스 = 게임 밸런싱 단계)

## 5. Edge Cases

| 상황 | 처리 | 비고 |
|------|------|------|
| 빈 레인(정면에 적 없음) | 끝 도달 후 주변 탐색·이동(연쇄) | |
| 정면 적 전멸 | 가장 가까운 다음 적 재타겟 | |
| 양측 동시 전멸 | [미정 — PvE 처리 규칙 결정 필요] | |
| 고정 유닛만 남아 서로 사거리 밖(교착) | [미정 — 타임아웃/판정 필요] | |
| 배치 부대 0~4 | 자유(5 강제 X — Q5 자유 편성). 약하게 가는 건 플레이어 선택 | |
| 병사 HP 0 | 카드 소멸(permadeath). 회복 = 건물 재훈련/무덤(확률 부활)/치유소(HP+벤치) | |

## 6. Dependencies

| 시스템 | 관계 | 내용 |
|--------|------|------|
| 로스터/덱 | Combat ← | 병종 데이터(패턴·스탯·레벨), 편성 ≤7/배치 ≤5 |
| 헥사 맵 | Combat ← | 타일 = 전투 컨테이너, 거리별 난이도(Q19) |
| 적/몬스터 | Combat ← | 적 진형·몬스터 특성 (Q19) |
| Economy | Combat → | 승리 보상·소모(HP 이월·permadeath) |
| 렌더/시뮬 | — | [ADR-003](../../docs/architecture/ADR-003-rigid-instancing-crowd-rendering.md) 인스턴싱·결정론 고정 틱(~400 병사) |

## 7. Tuning Knobs

| 파라미터 | 기본/범위 | 효과 |
|----------|-----------|------|
| 그리드 크기 | 5x5 (3x3~7x7) | 전략 복잡도 |
| 배치 부대 수 | ≤5 (덱 ≤7) | 선택 폭 |
| 이동속도/가속 | 병종별 | 전투 템포·역동성 |
| 넉백 강도(방패병) | 미정 | 존 컨트롤 강도 |
| 돌격 보너스/후퇴거리/재돌격 쿨 | 미정 | 기병 히트앤런 밸런스 |
| 사거리·명중%(궁병/사냥꾼) | 미정 | 원거리 강약 |
| 패닉 임계(농부) | 50% | 물량 안정성 |
| 웨이브 수 | 1 (1~3) | 타일 난이도 |

## 8. Acceptance Criteria

- [ ] 적 진형 100% 공개 후 ≤5부대 자유 배치 가능
- [ ] 레인 기반 전진 + 공격 패턴(관통/AoE/곡사/히트앤런/넉백/부채꼴/멈춰쏘기) 동작
- [ ] 병사 개별 HP·연쇄 재타겟·패닉 동작
- [ ] HP 이월 + permadeath(HP0 소멸) 적용
- [ ] 결정론: 같은 시드·배치 → 같은 결과
- [ ] 진입 시 결과 확정 + 오토세이브(수동 리로드 차단)
- [ ] 전투 16.6ms 이내, ~400 병사 처리(ADR-003)
- [ ] 밸런스 값 ScriptableObject (하드코딩 X)
