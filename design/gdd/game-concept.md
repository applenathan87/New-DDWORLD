# DDworld — Game Concept

> **Status**: Approved
> **Author**: nathan
> **Last Updated**: 2026-04-16
> **Origin**: Day 22 데브로그에서 컨셉 확정, Day 24까지 프로토타입 검증

## Elevator Pitch

**"상대 패는 보이지만 배치는 모른다"** — 불완전 정보 속에서 상대를 읽는
심리전 오토배틀러. 5x5 그리드에 병종 카드를 비밀 배치하고, 동시 공개 후
자동 전투로 승부를 가린다.

## Core Fantasy

**"읽었다!"의 쾌감** — 상대의 손패를 보고, 배치를 예측하고, 맞았을 때의 짜릿함.
정보는 있는데 확신은 없는 상태에서 결정을 내리는 두뇌 싸움.

## Game Pillars

### 1. 심리전 — "읽었다!"의 쾌감
상대 손패가 공개되지만 배치는 비밀. 정보를 가지고도 확신할 수 없는 긴장감.
읽기/역읽기/역역읽기의 심리 레이어가 게임의 깊이를 만든다.

### 2. 역전의 희열 — 지고 있어도 뒤집을 수 있는 희망
판돈(Pot) 시스템으로 접전일수록 보상이 커진다. 초반 2패 후 역전하면
누적 판돈을 모두 가져가는 구조. 기권 전략도 유효한 전략적 선택.

### 3. 보는 맛 — 오토배틀의 관전 쾌감
내 판단이 맞았는지 지켜보는 자동 전투의 박진감. 배치 공개 순간의 긴장,
병사들이 부딪히는 전투의 역동성, 역전 드라마가 시각적으로 전달되어야 한다.

### Anti-Pillars (이 게임이 아닌 것)
- **조작 실력 게임이 아니다** — APM이나 반사신경으로 승부가 갈리면 안 됨
- **랜덤 운 게임이 아니다** — 드로우 운이 아닌 배치 판단이 승패를 결정
- **복잡한 경영 게임이 아니다** — 핵심은 매치 내 심리전, 메타 시스템은 보조

## Core Loop

```
드로우 → 상대 손패 확인 → 배치 판단 → 동시 공개 → 자동 전투 → 판돈 정산
  ↑                                                              ↓
  └──────────────── 다음 라운드 (5판 3선승) ────────────────────────┘
```

1. **드로우**: 덱에서 카드를 받는다 (1R: 8장, 2R+: 이월3+드로우5)
2. **읽기**: 상대 손패가 공개된다. 상대도 내 패를 보고 있다
3. **배치**: 5x5 그리드에 5장을 비밀 배치한다
4. **공개**: 양측 배치가 동시에 드러난다 — "읽었다!" 또는 "읽혔다!"
5. **전투**: 병종별 행동 패턴에 따라 자동 전투
6. **정산**: 잔존 병사의 가치가 판돈에 쌓인다. 배치 안 한 3장은 자동 이월
7. **반복**: 3선승할 때까지. 최종 승자가 누적 판돈 획득

| 병종 | 역할 | 핵심 행동 패턴 |
|------|------|---------------|
| 기병 (Cavalry) | 정예 돌격 | 빠른 직진, 돌격 보너스 데미지 |
| 창병 (Spearman) | 방어 진형 | 대돌격 방어, 팔랑크스 |

| 함정 (Trap) | 기습 배치 | 비공개, 적 진입 시 범위 폭발, 1회용 |

## Target Experience

### 한 판의 흐름 (플레이어 감정 곡선)

```
긴장감 ▲
       │          ★ 공개 순간
       │         ╱ ╲
       │   읽기 ╱   ╲ 전투 관전
       │      ╱     ╲
       │ 드로우       ╲ 정산
       │╱               ╲___
       └──────────────────────→ 시간
```

- **드로우**: 기대감 — "이번엔 뭐가 왔지?"
- **읽기**: 긴장 상승 — "상대가 궁병 3장을 들고 있네... 어디에 놓을까?"
- **배치**: 최고 긴장 — "여기다!" 결단의 순간
- **공개**: 피크 — "읽었다!" 또는 "아, 거기였구나"
- **전투**: 몰입 — 내 판단의 결과를 지켜보는 박진감
- **정산**: 이완 — 다음 라운드 준비, 배치 안 한 3장은 자동 이월

### 매치 단위 경험

- 3:0 스윕: 빠른 승리, 적은 판돈 — "깔끔하지만 아쉽다"
- 3:2 접전: 긴 매치, 큰 판돈 — "역전 드라마, 가장 재미있는 매치"
- 기권 포함 매치: 전략적 포기 — "이번 판은 접고 다음에 올인"

## Visual Direction

- **스타일**: HD-2D (픽셀 아트 스프라이트 + 3D 환경 + URP 포스트 프로세싱)
- **톤**: 가볍고 밝은 전장, 하지만 심리전의 긴장감이 느껴지는 연출
- **레퍼런스**: 옥토패스 트래블러(HD-2D), TABS(가벼운 전투), Into the Breach(전략 명확성)
- **에셋 제작**: 직접 제작 + AI 생성 (Midjourney 등) 병행

## Platform & Scope

- **플랫폼**: PC (Steam)
- **멀티플레이어**: 프로덕션에서 온라인 PvP. 프로토타입은 AI 대전
- **개발 규모**: 솔로 인디
- **프로토타입 목표**: 코어 루프 재미 검증 + 디자인 룩(비주얼) 확인

## Concept Evolution

이 컨셉은 3번의 피봇을 거쳐 도달했다:

| 시점 | 컨셉 | 전환 이유 |
|------|------|-----------|
| Day 1~13 | 스킬젬 액션 RPG | "장르가 아닌 경험에서 출발해야" |
| Day 17 | 백지 재기획 | 기획 체계부터 다시 세움 |
| Day 21 | 던전크롤링 + 귀환경영 | 핵심 가치(성장/언락/빌드업) 기반 |
| **Day 22~현재** | **심리전 오토배틀러** | **"읽기의 쾌감"이라는 핵심 경험 발견** |

일관되게 유지된 것: 1인 인디 규모, 연출/경험 중시, 체계적 기획 우선 접근.
