## 용어 (Glossary)

| 용어 | 뜻 |
|------|----|
| **캠페인 (Campaign)** | 게임오버까지의 한 회차. 영토 영구 확장. (= 로그라이트 "런") |
| **Day** | 캠페인 안의 시간 단위. 하루 = 타일 1개. |
| **진격 (Advance)** | 하루에 타일 하나를 치는 행동 (전투/이벤트). |
| **출정·원정 (Phase 2)** | MVP 이후의 깊은 위험지역 탐험 모드. ("출정"은 이 뜻으로만 사용) |
| **MVP** | 코어 재미를 검증할 최소 플레이 가능 버전 (전체 게임 아님). |
| **프로토타입** | MVP보다 작은, 단일 메커니즘 실험. |
| **티어 (Tier)** | 카드의 등급(희귀도/기본 강함). 저티어 vs 고티어. |
| **레벨 (Level)** | 그 카드를 키운 정도(1·2·3). 건물+머지로 ↑. |

## Elevator Pitch

**"적의 배치를 읽고, 내가 키운 군대를 퍼즐처럼 배치해 정복한다."**
성(castle)을 중심으로 헥사 영토를 넓혀가는 **PvE 전술 오토배틀러**. 하루에 한 타일씩 진격하며, 공개된 적 진형에 맞춰 부대를 카운터 배치하고, 자동 전투로 승부를 본다. 다친 군대는 다음 전투로 이어지고(소모전), 아끼던 유닛이 죽으면 영영 사라진다(permadeath).

## Core Fantasy

두 겹의 쾌감:
1. **"풀었다!"** — 적 배치라는 퍼즐을, 내가 키운 빌드로 정확히 카운터했을 때의 짜릿함. (구 "읽었다!" 심리전의 PvE 계승)
2. **내 군대의 서사** — 한 마리 한 마리 키우고, 아끼고, 잃고, 다시 짜는 과정에서 *이번 캠페인만의 군대 이야기*가 쌓인다.

## Game Pillars

### 1. 전술 퍼즐 — "풀었다!"
공개된 적 진형 + 내가 키운 빌드 → "어떻게 풀지" 고민 → 카운터 배치 → 자동 전투. 운이 아닌 **읽기와 배치 판단**이 승패를 가른다.

### 2. 내 빌드의 서사 — 선택·성장·발견 (중심축)
병종 언락, 카드 레벨업, 유물 조합으로 *내 군대*를 빚는다. **소모전·permadeath** 때문에 군대는 소중하고, 잃으면 새 조합을 발견할 기회가 된다. 한 캠페인이 곧 한 편의 군대 서사.

### 3. 보는 맛 — 오토배틀 관전
배치 확정 후 수백 병사가 부딪히는 자동 전투의 박진감. 내 판단의 결과를 지켜보는 긴장.

### Anti-Pillars (이 게임이 아닌 것)
- **조작 실력 게임이 아니다** — APM/반사신경 X. 액티브 개입은 양념이고, **배치만으로도 이길 수 있어야 한다**(baseline).
- **단일 정답 게임이 아니다** — "하나의 최강 덱"으로 끝까지 미는 게 불가능하도록 설계(아래 §Core Tension).
- **무거운 경영 게임이 아니다** — 영토·건물은 코어 전투를 떠받치는 보조. 관리가 전투 재미를 압도하면 안 됨.
- (폐기) 비동기 PvP·고스트·심리전 — PvE 전환으로 제거.

## Core Loop

**게임 전체 = 하나의 연속 캠페인 = 한 판의 "런".** 시간 단위는 **Day**(하루 1**진격**).

```
[헥사 맵 = 전략·성장 공간 + 스테이지 선택(노드맵)]
        │  매일 인접 타일 1개 선택 (전투 / 이벤트 / 상점 …)
        ▼
   전투 타일 → 적 진형 풀공개 → ≤7덱 중 ≤5부대 카운터 배치 → 자동 전투 → 결과
        │  승리 보상: 카드 3중1 + 금화 / 점령 = 영토·수입 영구 획득
        ▼
   베이스 운영(건물 건설·유닛 레벨업·치유·부활) → 다음 Day
        │  (다친 HP는 이월, 죽은 유닛은 소멸 / 매주 일요일 = 이벤트·휴식일)
        ▼
   ……반복하여 영토 확장…… (게임오버 = 캠페인 리셋, 계정 언락은 보존)
```

- **확장 = 정복(전투) 또는 구매(빈 땅)**. 경로 게이팅: 원하는 타일에 닿으려면 사이 전투 타일을 정복해야 함 → "어느 타일 먼저 먹지?"가 전략.
- **쉬는 날 거의 없음** — 매일 어딘가 가야 함(보급 자원 없음). 이벤트 타일 = 전투 없는 날.
- **MVP** = 베이스 + 전투(연속 캠페인)까지. 깊은 위험지역 "출정 런" 레이어는 Phase 2.

## Core Tension — "왜 정답 찾기로 안 떨어지나" (설계의 핵심)

> PvP를 버린 이유: *"칸막이 걷고 배치 까는" 심리전은 동기/대면에서만 성립. 비동기·PvE에선 그냥 "정답 찾기"로 전락*하고, 솔로 인디엔 PvP 인프라(BaaS/고스트/매칭) 리스크도 과하다.

그래서 PvE인데도 **단일 최적 덱 반복이 불가능**하도록 세 장치를 건다:
1. **소모전(HP 이월)** — 연속 전투로 HP가 닳은 채 다음 판에 들어감. 항상 최강 유닛만 쓸 수 없다.
2. **permadeath + 회복 로테이션** — 죽으면 소멸(치유소는 다친 유닛을 N Day 벤치). 다친 부대를 빼고 다른 덱을 써야 한다.
3. **멀티덱 강제** — 위 + 거리별 난이도 + (나중)역습 → 상황마다 다른 덱.

→ **병종을 많이 둘수록 손실에 강해진다**(잃으면 새 조합 기회). **긴장은 초·중반(빈곤)에 front-load**, 후반 부유함은 "클리어를 앞둔 특권". 경제가 부활·치유 비용으로 다시 빠지니 돈으로 죽음을 완전히 무를 수는 없다.

## Combat

- **전장 = 5x5 그리드.** 핵심 = **열(column) 기반 일직선 전진** — 배치한 열이 전투 매칭을 결정(= 배치 읽기 퍼즐). 단 일부 병종은 고정(투석기·스킬 마법사).
- **흐름**: 진입 → **적 진형 100% 공개** → ≤7장 덱 중 **≤5부대 자유 배치**(어느 칸이든) → 확정 → 자동 전투 → 결과.
- **단판 기본.** 일부 타일은 웨이브 2~3(난이도 knob, 보스는 페이즈). 변주(숨김/함정)는 **보스 전용**(공정 원칙: 텔레그래프/정찰/학습, 첫판 gotcha 금지).
- **플레이어 개입(순수 관전 X)**: 액티브 스킬 유닛(쿨 차면 메테오 등) + 사용 아이템(포션). 분량은 자유(올액티브 빌드도 가능, 단 귀한 카드 permadeath 리스크 = 자기 밸런싱).
- 규모: 후반 피크 **~400 병사(양측 합, ADR-003)**. 비대칭 가능(우리 정예 소수 vs 적 물량).

## Units & Cards

- **카드 → 유닛 변환, 병사마다 개별 HP**(Bad North식 — 죽으면 분대가 줄어듦).
- **하이브리드**: 분대 카드(대다수·다수 병사) + 단일/영웅 카드(소수·강력·액티브). 민병=약한 다수 / 액티브=소수.
- **카드 레벨** = 병사 수↑ **또는** 정예화(질↑) — "같거나 커진다". 레벨업 = **건물 패시브 강화(공/방/규모 1·2·3) + 같은 카드 머지(추가 부스트)**.
- **유닛 영구소멸(permadeath)**: 카드 HP는 한정, 0이면 소멸. 회복 = 건물 재훈련(베이스 레벨) / 무덤(재화+확률 부활, 한계) / 치유소(HP 회복+벤치).
- **건물카드**: 건물은 건설카드로 지음. 전투 3중1에서 건물 선택 시 **즉시 건설**(전투 덱과 분리, 들고 다니지 않음).

## Economy & Base

- **금화 단일 통화**(MVP) — 건물·땅·카드팩 모두 금화.
- **헥사 이득 3축**: ①건설 슬롯 ②**패시브 금화 생산**(점령만 해도 Day마다) ③접근/시야.
- **금화 faucet**: 전투 승리 보상 + 헥사 패시브 생산 + 이벤트·일요일 + 시장. **sink**: 카드/건물/땅/부활/치유/레벨업.
- **건물**(건설카드, **본성 레벨별 건설 한도 n개**로 스팸 방지): 훈련소(병종 언락+레벨업), 시장(주간 로테이션 상점 3장 1할인 + 금화), 치유소, 무덤, 유물/아이템 슬롯 등.
- 유닛 굶주림 방지 = **저티어 유닛팩 1~2일마다**.

## Progression

- **카드 획득**: 전투 3중1 / 시장(보고 사는 타겟 구매) / 이벤트 타일 / 일요일 / 설계도팩.
- **성장 축**: ①카드 레벨(건물+머지) ②**유물 = 패시브 버프**(근접/원거리 공격력↑, 저주유물 = 페이오프) ③**아이템 = 액티브 사용** ④유물/아이템 슬롯 = 건물로 확장 ⑤영토 확장 ⑥본성 레벨.
- **유물=패시브 / 아이템=액티브**로 역할 분리.

## Visual Direction

- **스타일**: **Low-poly Voxel 3D** (전체 3D). 근거: [ADR-002](../../docs/architecture/ADR-002-visual-style-low-poly-3d.md). 정점색 voxel(텍스처 거의 X), 디테일은 viewing-distance 기준(잡병 청키 / 히어로 화려) — [research](../art/research/ddworld-voxel-style.md).
- **캐릭터**: MagicaVoxel 부위 분리 → Blender Rigid Voxel 애니(12~24fps 스텝). 대량 렌더 = [ADR-003](../../docs/architecture/ADR-003-rigid-instancing-crowd-rendering.md) 인스턴싱(~400명).
- **톤**: 따뜻한 색감, 미니어처. Tilt-shift + Bloom + DOF + Color Grading. 색 권위 = Unity.
- **레퍼런스**: Bad North(오토배틀·미니어처), Tabletop Tavern(인디 검증), 문명(헥사 확장), Crossy Road(voxel).

## Platform & Scope

- **플랫폼**: PC (Steam) · **개발 규모**: 솔로 인디.
- **멀티플레이어**: 없음(PvE 단일 캠페인). 비동기 PvP는 폐기 — [ADR-001](../../docs/architecture/ADR-001-async-pvp.md)는 Superseded 예정.
- **MVP**: 영구 베이스 + 연속 캠페인 전투(헥사 확장)까지. 깊은 "출정 런" 레이어 = Phase 2. 설계 제약: 덱·전투를 영구 상태에 하드커플 금지(나중에 출정 래퍼 가능하게).

## Concept Evolution

| 시점 | 컨셉 | 전환 이유 |
|------|------|-----------|
| Day 1~13 | 스킬젬 액션 RPG | "장르가 아닌 경험에서 출발해야" |
| Day 17 | 백지 재기획 | 기획 체계부터 다시 |
| Day 21 | 던전크롤링 + 귀환경영 | 핵심 가치(성장/언락/빌드업) 기반 |
| Day 22 | 심리전 오토배틀러 | "읽기의 쾌감" 발견 |
| **2026-06-29** | **PvE 헥사 영토 확장** | 심리전은 동기 PvP에서만 성립 → PvE는 정답찾기 전락 + 솔로 인디 PvP 인프라 리스크. 코어를 "전술 퍼즐 + 소모전 캠페인"으로 재정의 |

일관 유지: 1인 인디 규모, 연출/경험 중시, 체계적 기획 우선.
