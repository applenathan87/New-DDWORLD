## 개요 (Overview)

「마왕성 인사팀」은 판단 게임이다. 뼈대는 케이스(지원자) 데이터를 읽고, 그날 지침에 비추어 근거를 긋고(마킹), 도장으로 판정하는 루프이며, 그 위에 면접(카드·코스트), 가젯, 승진·경제, 하루 구조·결산이 얹힌다. 변주 파트(스케줄링 퍼즐, 리듬·QTE 미니게임)와 밤 파트(미니맵 허브·인물·관계→카드)가 "읽기만 하는 게임"을 막는다. 모든 시스템은 필라 우선순위(마왕성의 상식 → 우리 회사 → 물건 → 승진)를 따르고, 어떤 도구도 합불 정답을 직접 출력하지 않는다.

시스템으로 두지 않은 것: UI·HUD·자막·종이 텍스트 템플릿은 UX 스펙(`/ux-design`)으로, 오디오는 각 GDD의 Visual/Audio 섹션과 사운드 바이블로, 케이스 콘텐츠(지원자·대사) 자체는 M4 콘텐츠 마일스톤으로 다룬다.

### 시스템별 범위 (각 GDD가 담을 것)

1. **케이스 데이터·콘텐츠 파이프라인** — 지원자·JD·지침·카드·대사·해설·사건 문구의 데이터 구조. JSON → 시트 전환 시점(케이스 20건 이상). 로드 시 검증기(결정적 근거 존재, 줄 수 한계 등). 날짜별 풀 태그와 셔플백 뽑기·시드 저장(케이스와 지침에 공통 적용). 텍스트는 전부 키로 참조하고 언어별 표를 둔다(영문 동시 대비).
2. **채용 지침 누적** — 공문 3종(JD, 특별 지침, 종족 지침). 날짜별 지침 풀에서 나와 쌓이고 바뀐다(매일 하나씩은 아니고 없는 날도 있음). 유지·갱신·소멸 규칙. 케이스 × 그날 지침의 정답 모델 — 열린 질문 #11(JD 로테이션)을 여기서 결정(스키마 확정 전). 서랍 표시.
3. **판정(마킹·도장·가젯)** — 이력서·공문 대조, 깃펜 V/X 방향 마킹, 근거 최소 1개, 도장 합불, JD 적합 정답 룰(실제 자질 vs 요구·결격), 3단 채점 근거(적중 / 반전 오독 / 결정타 별도). 가젯(촛불·돋보기·…)의 "정보만 준다" 규칙, 사용 제한, 승진 보상 연결. 열린 질문: 보류 도장, 스탯 패널, 드래그 재배치, 마킹 노브, 돋보기 제한.
4. **데스크 물성·인터랙션** — 잡기·드래그·던지기·놓기·pick-up-to-read·함께 들기(이력서+공문)의 공통 문법. 물성 6종 상한. 도장·카드 손맛(Game Feel 섹션이 심장: 입력 지연, 임팩트, 무게감). 소리·잉크·트윈(짧은 이동·크기 애니메이션) 피드백. 컨셉의 검증 포인트 "도장이 계속 찍고 싶은가".
5. **하루 구조·결산** — 출근 → 공문 → 업무 N건 → 오후 변주 → 퇴근 결산 → 밤 → 취침. 근무 시간(케이스 타이머 없음)과 전부 처리 시 추가 점수. 승진 심사 트리거. 재도전 없음 — 항상 다음 날로. 게임오버 패턴(누적형·해고 등, 데모 완주율과의 균형). 결산 3단 채점 공개, 지연 사고(아침 사건 보고서), 데모 3일 흐름과 엔딩 등급.
6. **승진·경제** — 공적 공식(정확 ×2 + 근거 적중 ×1 + 처리량 보너스), 직급 사다리(수습 → … → 팀장), 승진 보상(업무 교체, 가젯·카드·장소 언락), 일급(기본급 + 보너스 − 청구서), 골드 소비처(싱크). 뇌물·장기 싱크는 본편.
7. **1차 면접(카드·코스트)** — 몬스터 등장·리액션 2종, 손패 4종과 턴당 코스트(데모 포인트 3), 답변 자막·반응 지시문, 진술 마킹(판정 문법 재사용), 결정타 분산 규칙(카드에도 서류에도), 함정 질문 비용, 돋보기 1회. 덱빌딩은 #11.
8. **면접 일정 스케줄링 퍼즐** — 사진 카드·수정구 통화·캘린더 6슬롯, 제약 3층(사진 힌트·통화·슬롯 경고), 위반 허용 → 다음날 사고. 프로토 구현 있음.
9. **밤 파트 허브** — 미니맵 UI(장소·인물 아이콘 클릭, 3D 없음), 일급 정산 화면, 까마귀 상점, 인물 이벤트(호감 은행-인출, 랭크 3에서 5), 관계 → 카드(대체 불가 효과 소수 정예), 인물 로테이션(결정적, 하루 1에서 2명). 데모 = 일급·상점·인물 1명·카드 1장. 바·서브스토리·청탁·석간 신문은 상위 티어. 근거 = [potionomics-night-rapport.md](../research/ref-games/potionomics-night-rapport.md).
10. **리듬·QTE 미니게임** — 오후 변주 파트 1에서 2종, 입력 타이밍·판정 창, 보상(골드·공적 보너스). 형태 미정 — GDD 전에 프로토.
11. **덱빌딩 확장** — 화법·기술 카드, 상점 매매, 뽑기·손패, 게이지·붕괴, 클램프 규칙(정답기 금지). 원문 = [interview_idea.md](../concept/interview_idea.md) v0.3.
12. **세이브·설정** — 데모는 15분 완주라 세이브 없음. 언어·볼륨 설정만 MVP UI에. 세이브·이어하기는 수직 슬라이스.

## 순환 의존 (Circular Dependencies)

- **케이스 데이터 ↔ 지침**: 스키마가 정답 모델(케이스 × 지침)을 알아야 한다 → 지침 GDD의 정답 모델을 먼저 정하고 스키마를 확정. 1·2번을 같이 설계.
- **판정 ↔ 면접**: 진술 마킹은 판정의 문법이고, 면접은 진술을 공급한다 → 판정이 마킹·정답 룰을 소유하고, 면접은 진술을 이력서 줄과 같은 데이터로 넘긴다.
- **승진·경제 ↔ 밤 파트 허브**: 골드 수입은 경제, 소비처는 밤 → 경제가 공식과 잔액을 소유하고, 밤 허브는 거래 목록(가격·효과)만 가진다.
