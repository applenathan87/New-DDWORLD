# 면접 = 전투 — 캐치(CATCH) 아이디어 스케치

> 상태: **아이디어 스케치 v0.1** (2026-08-30) — 자유 아이데이션 단계. 확정 아님, 기존 확정사항과의 충돌 검토는 의도적으로 보류.
> 발단: "면접에 전투 개념을 넣으면?" (2026-08-30 대화) + 사용자의 GPT 대화(미니게임·역전재판·단간론파·CATCH) 검토.
> 형제: [interview_idea.md](interview_idea.md) (덱빌딩 v0.3) · [interview-depth.md](interview-depth.md)
> 관계: **v0.3 대체가 아니라 표현 계층** — 게이지·덱·카드 골격은 그대로, tell의 노출 방식을 바꾸는 층 (§5).

## 1. 핵심 테제

**"면접 = 전투. 단, 잘 싸운다고 좋은 직원을 뽑는 게 아니다 — 싸움이 끝났을 때 확보한 '정보'가 전리품이고, 판단(도장)은 끝까지 플레이어 몫."**

- 전투 = 정보를 캐내는 수단. 승패 ≠ 정답.
- 완벽하게 싸우고도(PERFECT INTERVIEW) 도장을 잘못 찍을 수 있고, 엉망으로 싸웠는데 감으로 맞출 수도 있다 — **이 어긋남이 살아있는 한 전투 프레임을 세게 밀어도 코어(간파·판단)가 안 죽는다.**
- 돋보기 원칙(카드는 정보 채널만 열고 합불을 출력하지 않는다)의 전투 버전.

## 2. 전투 문법 번역표

| 전투 | 면접 |
|---|---|
| 공격 기술 | 질문 카드 (「전 직장」=과거 공격, 「마왕」=충성도 공격, 「돈」=욕망 공격…) |
| 적의 공격 패턴 | 지원자의 발언·태도 ("저는 성실합니다" = 들어오는 공격) |
| **패링** | **캐치** — 발언·표정·행동의 빈틈을 순간 포착 |
| 반격 | 추궁 (캐치 성공 시 추궁 카드/질문 활성화) |
| 피격 | 캐치 놓침 → 지원자가 적응·역공 ("저를 못 믿으시는 겁니까?") |
| 콤보 | 캐치 → 추궁 → 캐치 → 압박 체인 |
| 전리품 | 정보 조각 (수첩에 쌓임) |
| 승리 화면 | 없음 — 도장 판단이 남는다 |

## 3. 캐치 (CATCH) — 간파 순간의 동사화

**설계 동기: 현행 기획에서 유일하게 손맛이 없는 순간이 "알아채는 순간"이다.** 도장 = 쾅, 던지기 = 세기가 있는데, 코어 판타지인 간파는 텍스트 읽기뿐. 캐치 = 그 순간에 몸의 동작을 부여 — **간파라는 코어 판타지에 전용 동사가 생긴다.**

### 3a. 캐치 대상 4종 (GPT 대화 채택)

1. **말실수** — "상사와 **전혀** 문제가 없었습니다" (과도한 부정·과장 단어)
2. **표정** — "마왕님을 존경합니다" 하는 순간 눈썹이 찡그려짐
3. **행동** — 대답하는 동안 책상 밑 손가락 떨기, 꼬리 흔들기
4. **말·행동 모순** — "팀워크 중시" 발언 순간 다른 지원자를 노려봄

### 3b. 신호 설계 — ⚠️ 핵심 미결

"누가 알아채는가: 게임인가 플레이어인가"의 스펙트럼:

- **A. 게임이 다 표시** (단어가 번쩍 → 클릭) — 순수 반응 게임. 간파가 반사신경으로 치환됨 (단간론파의 노란 글씨 비판 지점).
- **B. 신호는 뜨지만 전부 진짜는 아님** — 긴장한 지원자는 거짓말 없이도 눈을 피한다. 신호 중 뭘 물지는 판단. 잘못 물면 비용 (포인트 소모·지원자 경계↑).
- **C. 표시 없음** — 스스로 의심 단어를 찍는 순수 간파. 픽셀헌팅 위험.

**결정 (2026-08-30): 스윗스팟은 A와 B 사이 어딘가 — 케이스를 실제로 저작하면서 위치를 잡는다.** (신호의 밀도·가짜 신호 비율·오캐치 비용이 노브)

### 3c. 캐치의 물성 번역 (클릭 → 책상 물건)

- **수첩에 받아적기** (펜 쾅) — 캐치마다 책상 위에 메모가 쌓임 = 정보 확보의 시각화 (전리품의 물성)
- 서류 해당 항목에 밑줄 긋기 / 돋보기 순간 들이대기
- "말풍선 단어 클릭" 자체도 "받아적는다"로 픽션화 가능

### 3d. 표정 캐치 × 복셀풍

미세한 눈썹 떨림은 블로키 캐릭터에서 안 읽힘 → **과장되게, 그러나 짧게** (눈이 왕만해졌다가 0.5초 복귀). 복셀풍 코미디 톤과 정합. Papers, Please가 저해상도 픽셀로 같은 걸 해낸 선례.

## 4. 지원자의 에이전시 — 놓치면 역공

캐치를 계속 놓치면 지원자가 **적응·역공**한다:
- "그 질문은 이미 대답한 것 같은데요?" (질문 무력화)
- "저를 믿지 못하시는 겁니까?" (면접관 압박)

→ 별도의 적 턴 시스템 없이 "내 실수 = 상대의 공격"이 되는 구조. (첫 대화의 "지원자에게 턴을 준다" 문제의식을 턴 없이 해결)

관련 아이디어 (첫 대화, 병렬 후보):
- **역질문** — 같은 축 연속 2회 찌르면 되받아침, 대응 실패 시 페널티
- **지원자 유형 = 전투 스타일** — lieType 매핑의 전투 문법 재해석 (뻥튀기=유리대포·은폐=위장형·스파이=카운터형·경력위조=서류전). 간파 = 정찰.
- **보스 면접** — 리터럴 전투 이벤트 (책상 뒤엎기 → 경비 버튼 = 물성 QTE 1순위 후보)

## 5. 기존 v0.3(덱빌딩·게이지)와의 관계

**대체가 아니라 얹히는 층.** tell 데이터(tellTemp 태깅)는 이미 있고, 캐치는 그 tell의 노출 방식을 "읽기" → "실시간 포착"으로 바꾸는 **표현 계층**:

- 게이지·붕괴·범위 랜덤 → 그대로 (온도 창이 캐치 가능 순간을 만드는 조건)
- 덱·카드 → 그대로 (카드 = 공격, 캐치 = 그 대답에서 발생)
- §6-8 보류안(B안: 창 안에서 질문해야 누설)과 설계 공간 겹침 — 같이 결정
- ⚠️ 단 자유 아이데이션 산물이므로, 채택 시점에 충돌 전수 검토 필요 (특히 "실시간 타이머 없음" 확정과 캐치의 실시간성)

### 실시간성의 강도 — 단간론파의 교훈

단간론파의 실시간은 **관대한 가짜 실시간** (발언 루프 반복 재생, 몇 바퀴 돌며 생각할 여유). 그런데도 액션 감각이 남. → 캐치도 "한 번 놓치면 끝"이 아니라 관대함을 설계할 것. 미니게임이 추리를 **표현**할 때는 사랑받고, 추리와 무관한 손재주 검사가 되면 욕먹는다 — 이 선을 지킨다.

## 6. 별도 축 — "지원자가 수행한다" (미니게임 검증, GPT 대화)

캐치와 별개의 새 검증 채널: 말·서류·반응에 이어 **"실제 시켜본다"** 4번째 채널.
- "침착하다면서요? 해보세요" → 진술 vs 수행의 불일치 = 간파와 같은 결
- 종족 변주 코미디 (좀비 체력 테스트 → 팔 떨어짐)
- ⚠️ **저작 비용 폭발 주의**: 미니게임 × 종족 변주 조합 비용을 GPT 대화는 계산 안 함. 넣는다면 3계열(판단형·조작형·심리형) 상한 + 결과는 점수가 아닌 관찰 기록(돋보기 원칙).
- 이 문서에선 후보 메모만 — 캐치와 별도로 판단.

## 레퍼런스 메모

- **역전재판**: 증언 → PRESS(추궁) → 새 정보 → 증거 PRESENT → 모순 격파. "정답 맞히기"가 아니라 "이상한 부분을 캐서 파기". 단 필수 증거 미발견 = 게임오버 구조는 반면교사 (우리는 "잘할수록 정보가 많을 뿐").
- **단간론파**: 논스톱 디베이트 — 흐르는 발언 + 약점 조준 사격. "알아챔"에 조준·발사의 몸동작을 입힌 원형. 가짜 실시간의 관대함, 노란 글씨(신호 A안)의 비판 지점, 미니게임 릴레이의 호불호까지 통째로 교재.
- **Contradiction: Spot the Liar!**: 진술 간 모순 대조 인터뷰 게임 — 캐치의 탐정 버전.
- Dragon Age(마주 보는 대화 연출) · Aviary Attorney(진지한 시스템 + 황당 캐릭터 코미디 톤).
