# 면접 뎁스 아이디어 — 카드 심문을 입체로

> 상태: **Draft v0.1** (2026-07-11) · 부모: [mvp-design.md](mvp-design.md) §4b·§7
> ⚠️ **v1 구현은 롤백됨 (2026-07-14)** — 기획을 먼저 확정하고 재구현하기로. 아래 "v1 구현 스펙"은 시안으로 보존 (당시 코드 = 커밋 8c2c10e).
> 발단: "카드로 질문하는 것만으로는 뎁스가 약하다" — 카드 심문이 **일방향 조회**(쿼리→응답)라서
> 지원자에게 상태가 없고, 행동 순서에 의미가 없다. 뎁스 = ①상대의 상태 ②행동 간의 상호작용.

## 아이디어 카탈로그 (7종)

| # | 아이디어 | 한 줄 | 뎁스의 근원 | 비용 |
|---|---|---|---|---|
| ① | **던지기 세기 = 질문 톤** ⭐ | 카드를 살살 놓으면 정중, 휙 던지면 압박 | 같은 카드가 톤에 따라 다른 행동이 됨 — 물성이 곧 화법 | 반나절 (기존 드래그에 속도 추적만) |
| ② | **긴장 온도계** ⭐ | 지원자에게 긴장도 상태 — 달구면 실수, 풀면 본색 | 카드 순서·톤 배분이 전략이 됨 (심문 = 조작) | 시스템 1개 (v1 라이트 구현) |
| ③ | **모순 잇기** | 깃펜으로 모순되는 진술 두 줄을 선으로 연결 → "모순!" | 단서 쌍의 조합 공간 (역전재판의 물성 번역) | 케이스별 모순 쌍 저작 필요 |
| ④ | **소지품 검사** | 지원자 가방을 쏟아 물건 단서 획득 | 단서 삼각형 → 사각형 (서류·진술·반응·물건) | 물건 오브젝트+케이스 데이터 |
| ⑤ | **미끼 서류** | 가짜 정보 서류를 슬쩍 놓고 컨닝 관찰 | 능동적 함정 설치 ("대본 훔쳐보기" tell의 능동태) | 저렴 (기존 tell 확장) |
| ⑥ | **종족별 심문 규칙** | 슬라임은 거짓말하면 색 탁해짐(촛불 필요), 해골은 무표정 | 종족 = 퍼즐 규칙 변주, 가젯 재사용 | 종족당 규칙 1개씩 저작 |
| ⑦ | **지원자의 역습** | 역질문·뇌물 슬쩍·협박 — 면접이 쌍방향 | 관찰자 → 당사자 전환 이벤트 | 이벤트 스크립트 |

## 조합 구조 — 온도계가 공통 기반

```
② 긴장 온도계 (상태)
 ├ ① 던지기 세기 = 온도의 주 입력 (압박↑ / 정중↓)
 ├ ③ 모순 잇기 = 적중 시 온도 급상승 (결정타)
 ├ ⑤ 미끼·④ 소지품 = 온도 무관 보조 채널 (과열로 막혔을 때 우회로)
 └ ⑦ 역습 = 온도 극단에서 발생하는 이벤트
```

## v1 구현 스펙 (S3b — ①+②라이트, 프로토 선적용)

**규칙 3줄:**
1. **반응 지시문(tell)은 긴장 ≥ 50일 때만 드러난다** — 평온한 지원자는 능숙하게 숨긴다. (달굴 이유)
2. 카드 드롭 속도로 톤 판정: **압박(빠름) = 긴장 +30 / 정중(느림) = 긴장 −10.** 시작 긴장 25.
3. **긴장 ≥ 85에서 또 압박하면 발끈** — 답변 거부, 질문 포인트만 소모. (과열의 리스크)

**의도된 플레이 패턴**: 달군다(압박 1~2방) → tell을 수확한다 → 식힌다(정중) → 다시 판단.
질문 포인트 3개 안에서 "언제 달구고 언제 식힐까"가 매 면접의 소전략이 된다.

**튜닝 노브**: 시작 25 / 압박 +30 / 정중 −10 / tell 노출선 50 / 발끈선 85 / 드롭 속도 경계 1.5m/s
— 전부 GameFlow 상수. 플레이 후 조정.

**v1에서 뺀 것 (다음 단계):**
- **선함 은폐형의 역규칙** ("편안할 때 본색이 샌다" — 낮은 긴장에서만 드러나는 tell): 케이스에 거짓 유형 태그 필요 → 시트 스키마 확장과 함께
- 차 주전자(정중의 물성 강화판 — 긴장 −30 소품), 온도계의 다이어제틱 표현 (지원자 땀방울·꼬리 떨림 — 지금은 HUD 숫자)
- ③⑤⑥⑦ 전부 — v1 반응 확인 후 우선순위 결정

## 열린 질문

1. 긴장이 도장 판정에도 영향을 줘야 하나? (발끈한 채 합격 도장 = 첫인상 나쁜 입사?) — 지금은 무관
2. 함정 질문 카드(★★)는 자동으로 압박 취급? — v1은 던지기 속도만으로 판정
3. 모순 잇기(③)의 저작 비용 — 케이스당 모순 쌍 1개면 충분한가, 시트 열 설계
4. 2차 면접(비전)과의 관계 — 압박 면접의 완성형은 2차 무대로 (2026-07-11 대화: 2차 = 실기 시연 + 조건 협상 방향)
