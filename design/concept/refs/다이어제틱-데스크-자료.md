## 🎯 우리와 가장 닮은 게임 — Strange Horticulture (설계 교본)

식물 가게 카운터에서 손님 의뢰를 받아, **책상 위 물건을 뒤지며** 정답 식물을 찾는 오컬트 퍼즐(2022). **우리 "마왕성 면접"의 사촌.**

- [⭐ Deep Dive: Strange Horticulture (Game Developer)](https://www.gamedeveloper.com/design/deep-dive-strange-horticulture) — 개발자 설계 회고. **"보드게임에서 영감 → 촉각적 UI 채택"**.
- [Finding the right plant for the job (Game Developer)](https://www.gamedeveloper.com/design/finding-right-plant-job-strange-horticulture) — "빈 자리에 맞는 것 찾기" 매칭 설계 (우리 직무 매칭과 통함).
- [A Detective Game About Plants (Xbox Wire)](https://news.xbox.com/en-us/2023/08/04/strange-horticulture-a-detective-game-about-plants/)
- [게임 메커니즘 정리 (Oortrain)](https://www.oortrain.com/strange-horticulture/strange-horticulture-explained)

**훔쳐올 것**:
- 화면 UI 대신 **물리적 물건** — 지도를 서랍에서 꺼내 책상에 펼치고, 책을 넘기고, 라벨을 붙임.
- **만족스러운 피드백** — 애니메이션 + 소리(종이 바스락). 물성은 시청각 피드백이 절반.
- **교차 대조 게임플레이** — 손님 설명 ↔ 두꺼운 도감 ↔ 지도 대조. → 우리: 몬스터 진술 ↔ 이력서 ↔ 서랍 속 채용 규칙 대조.

## 우리 게임에 대입 (요약)

- **책상 = 놀이터**: 이력서(집어 촛불에 비춤) · 도장(드래그해 쾅) · 서랍(규칙·도구) · 질문카드(던짐) · 버튼(경비).
- **교차 대조가 코어**: 몬스터 진술 ↔ 이력서 ↔ 서랍 규칙 → 거짓/과장 간파 (Strange Horticulture의 도감 대조를 "거짓말 간파"로 변주).
- **피드백에 투자**: 도장 쾅 소리, 종이 바스락, 서랍 드르륵 — 물성의 절반은 시청각.
