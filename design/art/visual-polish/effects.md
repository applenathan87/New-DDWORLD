## 1. 캐릭터 이동 먼지 (Dust)

### 디자인 의도

빠르게 이동하는 병사 발 아래에서 먼지가 짧게 일었다 사라진다. 디오라마 미감을 강화하고, 속도감을 시각적으로 전달한다.

### 트리거 조건

캐릭터의 현재 속도(0 ~ 1, 0=정지 / 1=풀스피드)가 **0.6 이상일 때만 발동**.

- 0.6 미만 (정지/저속): 먼지 없음 — 교전 중, 공격 중, 패닉 직후 회복 중 등 시각 노이즈 감소
- 0.6 ~ 1.0: 속도 비례 빈도로 발동
- 풀스피드 (기병 돌격 등): 최대 빈도

### 빈도 (속도 비례)

```
emitRate = (currentSpeed - 0.6) / 0.4 * maxRate
// 0.6 이하: 0
// 1.0: maxRate
```

→ 임계값 부근에서 갑자기 켜지는 어색함 없이 부드럽게 증가.

### 시각 사양

- **형태**: Low-poly 작은 큐브 2개 정도 (메쉬 파티클)
- **색**: 환경 톤에 맞는 흙색 (잔디 위면 약간 갈색/노란색)
- **수명**: 짧게 (0.3~0.5초 추정, 실측 후 조정)
- **이동**: 발 아래에서 살짝 위로 솟았다가 사라짐
- **크기**: 캐릭터 발의 1/3 ~ 1/2

### 위치

캐릭터 발 위치 또는 그 바로 뒤. 좌우 발 구분 없이 한 지점에서 발생.

### 페이드 처리

- 속도가 0.6 아래로 떨어져도 이미 발생 중인 먼지는 정상적으로 수명 다할 때까지 유지
- 즉시 끊지 말 것 (어색함)

### 구현 노트

- **방법 권장**: Object Pool + 단순 큐브 메쉬 + GPU Instancing
- 또는 공용 ParticleSystem 1개로 모든 병사의 먼지를 emit
- 200명 활성 시 동시 활성 파티클 100~300개 수준 추정 (실측 안 함)
- 매 0.1~0.2초 emit 빈도가 적절할 것으로 추정
