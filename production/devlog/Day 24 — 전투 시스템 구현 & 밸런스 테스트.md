### 프로토타입 — 전투 시뮬레이션
- **BattleSimulator**: 병사 리스트 관리, 승패 판정
- **Soldier 자율 행동**: 독립 이동/타겟팅/공격
- **레인 기반 전투**: 행 직진 → 적 3열째 도달 후 자유 추적
- 교전 경험 후 타겟 사망 시 바로 자유 추적 전환
- 아군 간 겹침 방지 (separation force, 반경 0.3)
- **기병 돌격**: 풀스피드(90%+) 시 돌격 공격 + "돌격 공격!" 텍스트
- **창병 반사**: 기병 돌격에 6만 받고 12 반사 + "돌격 방어!" 텍스트
- **함정**: 적으로 인식 안 됨, 밟으면 타일 범위 폭발(10뎀) + 넉백 + 빨간 네모
- **궁병 화살**: 포물선 투사체, 75% 명중, 빗나가면 바닥에 꽂힘
- 넉백: 순간이동 → 속도 기반 부드러운 밀림 + 감쇠
- 가속/감속: 고정 가속도 1.5, 넉백 후 속도 리셋
- HP바: 피격 시 표시, 빌보드, 크기 확대
- 사거리 바닥 원형 표시 (모든 유닛)
- 방향 화살표: 타겟 향한 실시간 표시
- 전투 통계: 병종별 딜/피해/처치 로그 + 화면 결과표
- 전투 중 핸드 숨김

### 프로토타입 — 병종별 진형
- 기병: 쐐기(V자) 진형 — 적 방향 뾰족
- 창병: 팔랑크스(방패벽) — 전열 넓게, 후열 촘촘
- 궁병: 4-3-3 지그재그 역삼각형
- 민병: 4×5 그리드
- `EnemyDir` 프로퍼티로 방향 규칙 통일

### 밸런스 테스트 씬
- **독립 밸런스 테스트 씬**: R 배치, B 전투, P 일시정지
- 프리셋 매치업 1~6번 (기병vs창병, 궁병vs기병, 창병5vs궁병ㄴ자, 기병5vs궁병3, 민병+기병vs궁병3, 함정+기병vs궁병3)
- 카메라 자유 이동 (우클릭 드래그 + 단계별 줌)
- 전투 시작 시 전장 전체 → 1.5초 후 1단계 줌인
- 자유 추적 전환 라인 (하얀 세로선)
- 전장 경계 (초록 사각형)

### 밸런스 조정
- **상성 데미지 배수 제거** → 행동 패턴으로 차별화 (향후 크리티컬 확률로 보완)
- **방어력 제거** → 데미지 = 순수 ATK. 밸런스 = ATK × HP × 병사 수
- 스탯 조정: 기병 HP28/ATK12, 창병 HP22, 궁병 ATK6/12명/사거리1.5, 민병 HP10
- 궁병 사거리 3→1.5칸, attackRange int→float
- 창병 반사 데미지 16→12
- 랜덤 배치 시 함정은 col 3~4에만

### 카메라 & 연출

- 딤 오버레이 위치/회전 조정
- 드로우 카드 크기 애니메이션 (OutBack)

## 배운 것
- 상성 데미지 배수보다 **행동 패턴 차별화**가 심리전 게임에 맞음
- DPS 계산만으로는 밸런스를 볼 수 없음 — 개별 ATK vs 개별 HP 비율이 핵심 (1방킬 여부)
- Unity OnMouseDrag/OnMouseUp은 처음 클릭한 오브젝트에서만 발생 → Update 기반으로 전환
- 레인 기반 전투에서 "이동은 X직진, 공격은 인접행 포함"이 자연스러움

## 막힌 것
- 딤 오버레이 Z 위치가 반복적으로 문제 — 3D UI 레이어링이 까다로움
- 기병 돌격 판정: 공격 시 currentSpeed=0 리셋 때문에 판정 안 됨 → lastSpeedBeforeAttack으로 해결
