# 데브로그 인덱스

> 새 데브로그: `Day XX — 제목.md` 형식으로 데브로그 폴더에 생성

---

## 전체 통계

```dataview
TABLE WITHOUT ID
  length(rows.Day) as "총 작업일",
  round(sum(rows.작업시간), 1) + "h" as "누적 작업시간"
FROM "데브로그"
WHERE Day != null
GROUP BY true
```

---

## 전체 목록

```dataview
TABLE Day, 날짜, 작업시간 + "h" as 작업시간, 상태
FROM "데브로그"
WHERE Day != null
SORT Day ASC
```
