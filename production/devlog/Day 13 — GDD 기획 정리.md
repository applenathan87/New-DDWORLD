# Day 13 — GDD 기획 정리 (스킬젬 시스템 & 적 전투 구조)

## 한 일
**스킬 시스템 설계**
- 쿨다운 기반, Q/W/E/R 슬롯 순차 해금
- 스킬젬 시스템: 전장 루팅 + 스토리 해금으로 획득
- 전장 진입 전 젬 장착 (덱 방식)

**적 전투 구조 설계**
- 적 타입 6종: 돌격 / 원거리 / 탱커 / 자폭 / 정예 / 보스
- 감지: 전방 반원 반경, 발견 시 ! 스프라이트
- 공격 예고: 일반 적은 스퀴즈 연출, 정예/보스는 별도 차징 애니메이션

- Notion MCP 연결 설정 (Claude Code ↔ Notion 자동 업데이트 구축)
