# Day 29 — 마왕성 인사팀 S2b 면접 루프 & 케이스 풀

> 작업 시간은 커밋 기록 기반 추정 (17:30경~20:25, /세션시작 미실행).

## 한 일

### 1. 프로토 코드 리뷰 → 7건 반영
- 유니티·UI 스페셜리스트 병렬 리뷰. **빌드 지뢰 2건** 제거: URP Lit 셰이더 스트리핑 대비(Always Included Shaders), InputSystemUIInputModule `AssignDefaultActions()` 명시
- 데이터 안전화: 스케줄링 태그 사전 TryGetValue, `GameDataValidator` 신설(JSON 누락 → 시작 화면 에러)
- 승진 기준 데이터화, 이력 3줄 한계 명시, **16:10 우측 잘림 해소**(CanvasScaler 폭 고정)
- 당장 안 고치는 우려점 8건 + 첫 빌드 체크리스트를 프로토 README에 기록

### 2. 콘텐츠 구조 v0.3 — 날짜별 풀 + 셔플백
- 핵심 요구 = **게임오버 재도전 시 동일 문제 반복 금지** (간파는 답을 알면 죽는 재미)
- 지원자 **7→17건** (신규 10 — 역반전 '쿠키할멈', 미믹·켈베로스·도플갱어·나태악마 등)
- 풀 뽑기 구현: 매 판 7건, 미출현 우선 셔플백, 물컹이 첫 슬롯 고정(미출현 시), 시드 로그
- **쿼터(최소 통과 인원) 폐지** — 승진 = 정확도 단독

### 3. 시트 저작 파이프라인
- `tools/cases_sheet.py` — gamedata.json ↔ CSV 왕복 변환기 (검증·백업, 무손실 확인)
- `tools/case-sheet-guide.md` — 구글 시트 워크플로 + **비주얼 3층 분류**(종족ID/변형 부착물/초상화)
- 아트 방향 확정: **종족 통폐합 안 함** — 종족별 복셀 모델 최대 제작, 미제작 폴백 = 기본 몸통+색

### 4. 보상 경제 3축 + 공적 게이지
- 설계 확정(mvp-design #13): **공적**(누적 승진 게이지, 다이어제틱 "인사기록 카드") / **직급**(레벨) / **골드**(소비 — 뇌물이 두 축 연결). XP 별도 축 없음, 싱크 없는 화폐 선지급 금지
- 결산에 **공적 게이지 구현**: 0→100 바 + 중앙 카운터 동기, 만땅 = 번쩍+샤라랑(승진), 승진 판정을 `meritGoal`(공적 기준)로 전환 — 근거 적중이 승진에 실질 기여(#10 부분 결정)

### 5. S2b — 1차 면접 루프 (계획 7/5보다 하루 앞당김) ⭐
- 책상 너머 **몬스터 그레이박스** 등장 (종족색 + 마법 버스트, 리액션 2종: 긴장/안도)
- **질문 카드 4종 = 3D 물성**: 잡아 지원자에게 던지면 발동 (★1~2, 면접당 포인트 3)
- 답변 = HUD 자막 + 반응 지시문 → **이력서 '진술 기록'에 단서로 쌓여 V/X 마킹** (단서 삼각형의 진술 축 가동)
- Day 2 진입 = **승진(게이지 100) 연동**, 미달 = Day 1 재도전(새 뽑기). 면접자 4명 (결정타를 카드 4종에 분산)
- 패치: 가독성(월드 말풍선→HUD 자막, 몬스터 프레임 인, 카드 확대), 퇴장 코루틴 레이스 버그, **몬스터 콜라이더**(던진 물건 튕김+움찔)

## 배운 것

- **싱크 없는 화폐 선지급 금지** — 쓸 곳 없는 골드는 보상이 아니라 "의미 없는 숫자" 학습
- **XP와 승진(직급)은 축 중복** — 이 게임의 레벨 = 직급, 게이지 = 공적, 화폐 = 골드로 역할 분리
- **월드스페이스 텍스트의 가독성 한계** — 대사는 HUD 자막이 정답 (물성 vs 가독성의 우선순위)
- **코루틴 레이스 컨디션** — 전역 참조를 쓰는 지연 코루틴은 그 사이 상태가 바뀔 수 있다 → 시작 시점 지역 캡처로 방어
- **빌드에서만 터지는 유니티 함정**: 런타임 Shader.Find는 스트리핑됨 / 런타임 AddComponent는 Reset() 미호출(Input 액션 빈 채)

## 막힌 것

- 면접 2번째 지원자부터 몬스터 소멸 + 질문 불능 → 퇴장 코루틴이 다음 몬스터를 지우는 레이스 → **순서화 + 자기 몬스터만 처리로 해결**
- 월드 말풍선 글씨가 안 보임 → HUD 자막으로 전환하여 해결
